01 概述

DeepSpeed（微软）、FSDP（PyTorch 原生）和 Megatron-LM（NVIDIA）是当前大模型分布式训练的三大主流方案。前两者基于 ZeRO 分片思想，Megatron-LM 以 Tensor Parallelism + Pipeline Parallelism 为核心，三者实现路径和适用场景各有不同。

适用场景中大模型训练、RLHF中等规模、PyTorch 原生超大规模预训练（百B~T级）

02 DeepSpeed

微软开发的分布式训练库，以 ZeRO（Zero Redundancy Optimizer）为核心，通过渐进式分片策略降低显存占用，支持 CPU/NVMe 卸载。

2.1 ZeRO 三阶段

ZeRO Stage 1
仅分片 Optimizer States
显存节省 ~33%
ZeRO Stage 2
分片 Optimizer + Gradients
显存节省 ~50%
ZeRO Stage 3
分片 Optimizer + Gradients + Parameters
显存节省 ~87% (8卡)
内存占用参考（7B 模型，Adam，单卡）
Baseline (DDP):     ~120 GB/卡
ZeRO-1:             ~80 GB/卡
ZeRO-2:             ~60 GB/卡
ZeRO-3 (8卡):       ~15 GB/卡

03 FSDP

PyTorch 原生的 Fully Sharded Data Parallel，无需额外安装，与 HF Accelerate 深度集成，配置最为简洁。

3.1 分片策略

from torch.distributed.fsdp import ShardingStrategy

ShardingStrategy.FULL_SHARD       # 等价 ZeRO-3：完全分片
ShardingStrategy.SHARD_GRAD_OP    # 等价 ZeRO-2：仅分片梯度和优化器状态
ShardingStrategy.NO_SHARD         # 等价 DDP：不分片
ShardingStrategy.HYBRID_SHARD     # 节点内完全分片 + 节点间复制（多机推荐）

3.2 PyTorch 原生 API

import torch.distributed as dist
from torch.distributed.fsdp import FullyShardedDataParallel as FSDP
from torch.distributed.fsdp import MixedPrecision
from torch.distributed.fsdp.wrap import transformer_auto_wrap_policy
from functools import partial

dist.init_process_group("nccl")
local_rank = int(os.environ["LOCAL_RANK"])

mp_policy = MixedPrecision(
    param_dtype=torch.bfloat16,
    reduce_dtype=torch.bfloat16,
    buffer_dtype=torch.bfloat16,
)

from transformers.models.llama.modeling_llama import LlamaDecoderLayer
auto_wrap_policy = partial(
    transformer_auto_wrap_policy,
    transformer_layer_cls={LlamaDecoderLayer},
)

model = FSDP(
    model,
    sharding_strategy=ShardingStrategy.FULL_SHARD,
    mixed_precision=mp_policy,
    auto_wrap_policy=auto_wrap_policy,
    device_id=local_rank,
    use_orig_params=True,      # 兼容 torch.compile
    limit_all_gathers=True,    # 降低内存峰值
)

3.3 Accelerate 集成（最简洁）

accelerate_config.yaml 推荐
compute_environment: LOCAL_MACHINE
distributed_type: FSDP
fsdp_config:
  fsdp_auto_wrap_policy: TRANSFORMER_BASED_WRAP
  fsdp_transformer_layer_cls_to_wrap: LlamaDecoderLayer
  fsdp_sharding_strategy: FULL_SHARD
  fsdp_backward_prefetch: BACKWARD_PRE
  fsdp_state_dict_type: FULL_STATE_DICT
  fsdp_use_orig_params: true
  fsdp_cpu_ram_efficient_loading: true
  fsdp_sync_module_states: true
mixed_precision: bf16
num_processes: 8
# 训练脚本极简
from accelerate import Accelerator
accelerator = Accelerator()
model, optimizer, dataloader = accelerator.prepare(model, optimizer, dataloader)

for batch in dataloader:
    loss = model(**batch).loss
    accelerator.backward(loss)
    optimizer.step()
    optimizer.zero_grad()

# 启动
accelerate launch --config_file accelerate_config.yaml train.py

3.4 FSDP2（PyTorch 2.4+）

FSDP2：基于 DTensor，与 torch.compile 深度集成
from torch.distributed.fsdp import fully_shard

for layer in model.layers:
    fully_shard(layer)
fully_shard(model)

model = torch.compile(model)   # 原生编译支持

04 Megatron-LM

NVIDIA 的大规模分布式训练框架，核心优势在于多维并行组合（TP/PP/SP/EP/CP），在百B至T级模型预训练中吞吐最优。

4.1 六大并行策略

TP
Tensor Parallelism
矩阵运算层内切分
必须单机内 (NVLink)
PP
Pipeline Parallelism
模型层间流水线
可跨机 (P2P 通信)
SP
Sequence Parallelism
LayerNorm/Dropout 序列维切分
须与 TP 同时启用
DP
Data Parallelism
+ Distributed Optimizer
(等价 ZeRO Stage 1)
EP
Expert Parallelism
MoE Expert 分片
CP
Context Parallelism
超长序列维并行

    --pipeline-model-parallel-size 4 \
    --sequence-parallel \
    --use-distributed-optimizer \
    --recompute-activations

4.4 并行策略详解

Tensor Parallelism (TP)

将 MLP 的列并行 + 行并行，Attention 的 head 分片。TP 必须在单机内（NVLink 高带宽），通常 TP ≤ 8。参数和激活都按 TP 分片，单卡内存 ≈ 总内存 / TP。

Pipeline Parallelism (PP)

将模型层分段，不同段放不同卡，用 micro-batch 流水线减少气泡。默认 1F1B 调度（气泡率 ≈ (PP-1)/micro_batches），Interleaved 1F1B 更低。PP 可跨机（P2P 通信量小，仅传激活）。

Sequence Parallelism (SP)

在 TP 区域之外（LayerNorm、Dropout），沿序列维度切分。非 TP 区域的激活内存从 batch×seq×hidden 降到 batch×(seq/TP)×hidden。必须与 TP 同时启用。

4.5 并行策略组合建议

单机 8 卡训练 7B:
  TP=1, PP=1, DP=8 + Distributed Optimizer (≈ FSDP FULL_SHARD)

单机 8 卡训练 13B:
  TP=2, PP=1, DP=4 + SP + Distributed Optimizer
  或 TP=4, PP=1, DP=2 + SP

多机训练 70B (32卡):
  TP=8, PP=2, DP=2 + SP + Distributed Optimizer

多机训练 175B+ (128+ 卡):
  TP=8, PP=8, DP=2 + SP + Interleaved Pipeline

4.7 Megatron 独有优化

高级优化技巧
# 1. 交错式流水线调度（减少气泡）
--num-layers-per-virtual-pipeline-stage 4

# 2. FP8 训练（H100/H200，吞吐提升 ~50%）
--fp8-format hybrid --fp8-margin 0 --fp8-interval 1

# 3. 分组 GEMM（MoE 模型加速）
--moe-grouped-gemm

# 4. 通信计算重叠
--overlap-p2p-communications    # PP 通信与计算重叠
--overlap-param-gather          # 参数 all-gather 与计算重叠

# 5. 异步梯度累积
--gradient-accumulation-fusion  # 需安装 fused kernels

05 选型决策

根据模型规模、训练阶段和硬件条件选择最合适的方案。

5.1 按模型规模

< 1B 参数:      DDP 或 FSDP NO_SHARD（单机多卡即可）
1B - 7B:        FSDP FULL_SHARD 或 DeepSpeed ZeRO-2（单机 8 卡）
7B - 13B:       DeepSpeed ZeRO-3 / FSDP FULL_SHARD / Megatron TP=2+DP
13B - 70B:      DeepSpeed ZeRO-3 + Offload / Megatron TP=4~8+PP
70B+:           Megatron-LM TP+PP+DP（多机集群首选）
175B - 1T+:     Megatron-LM 3D/4D 并行 + Interleaved PP

5.2 按场景选择

场景推荐方案原因
LLaMA 微调 (LoRA)FSDP + Accelerate配置简单，HF 生态完善
全参数训练 13B+DeepSpeed ZeRO-3内存效率最优
超大规模预训练 (70B+)Megatron-LMTP+PP 吞吐最优
RLHF 流水线DeepSpeedDeepSpeed-Chat 成熟
PyTorch 原生工作流FSDP无额外依赖
显存极度受限DeepSpeed ZeRO-OffloadCPU/NVMe 卸载
FP8 训练 (H100/H200)Megatron-LMTransformer Engine 原生支持
MoE 模型训练Megatron-LMExpert Parallelism 原生支持

5.4 最佳实践：分阶段组合

业界常见模式：预训练用 Megatron，SFT/RLHF 用 DeepSpeed/FSDP

预训练阶段 — Megatron-LM，充分利用 TP+PP 的大规模吞吐优势
SFT 阶段 — DeepSpeed ZeRO-2/3 或 FSDP，配置简单，快速迭代
RLHF/DPO 阶段 — DeepSpeed（DeepSpeed-Chat 成熟）或 FSDP + TRL

框架组合注意事项

Megatron-LM + DeepSpeed：Megatron 提供 TP+PP，DeepSpeed 提供 ZeRO DP，可进一步降低显存
Megatron-LM + FSDP：较少组合，Megatron 自有的 DP 已足够
DeepSpeed + FSDP：通常二选一，不混合使用

06 常见问题与排查

6.1 显存 OOM

# 1. 开启梯度检查点
model.gradient_checkpointing_enable()

# 2. 减小 micro batch，增加 gradient accumulation
per_device_train_batch_size=1
gradient_accumulation_steps=16

# 3. DeepSpeed: 启用 CPU offload
# 4. FSDP: 使用 limit_all_gathers=True
# 5. Megatron: 增大 TP 或启用 SP

6.2 训练速度慢

# 1. 确保 use_cache=False（ZeRO-3/FSDP 下 KV cache 与分片冲突）
# 2. 开启 overlap_comm（DeepSpeed）
# 3. 使用 BF16 而非 FP16（A100+ 无需 loss scaling）
# 4. FSDP: 使用 HYBRID_SHARD（多机场景）
# 5. Megatron: 增加 prefetch_bucket_size，启用 SP

6.3 Loss 不收敛 / NaN

# 1. 梯度裁剪: gradient_clipping=1.0
# 2. 降低学习率: lr=1e-5
# 3. 增加 warmup: warmup_ratio=0.1
# 4. 检查 loss scaling（FP16 场景）
#    DeepSpeed: initial_scale_power=12
#    FSDP/Megatron: 使用 BF16 避免此问题

6.4 多机通信问题

export NCCL_DEBUG=INFO
export NCCL_SOCKET_IFNAME=eth0   # 指定网卡

# DeepSpeed: 确认 hostfile SSH 免密
# FSDP: 确认 MASTER_ADDR / MASTER_PORT 一致
# Megatron: 确认 torchrun --master_addr / --master_port / --node_rank 正确

训练脚本

from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments, Trainer
from peft import LoraConfig, get_peft_model, TaskType

model_name = "meta-llama/Llama-2-7b-hf"
tokenizer = AutoTokenizer.from_pretrained(model_name)
tokenizer.pad_token = tokenizer.eos_token

model = AutoModelForCausalLM.from_pretrained(
    model_name, torch_dtype="auto", use_cache=False,
)

lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=16, lora_alpha=32,
    target_modules=["q_proj", "v_proj", "k_proj", "o_proj"],
    lora_dropout=0.05, bias="none",
)
model = get_peft_model(model, lora_config)
model.print_trainable_parameters()  # ~0.3% 参数

training_args = TrainingArguments(
    output_dir="./lora_output",
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,
    num_train_epochs=3,
    learning_rate=2e-4,
    warmup_ratio=0.03,
    bf16=True,
    deepspeed="ds_lora_config.json",
    gradient_checkpointing=True,
    optim="adamw_torch_fused",
)

trainer = Trainer(
    model=model, args=training_args,
    train_dataset=dataset, tokenizer=tokenizer,
)
trainer.train()
model.save_pretrained("./lora_checkpoint")
# 启动
deepspeed --num_gpus=8 train_lora.py
