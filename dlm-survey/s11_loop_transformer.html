11 Looped Transformer 与 Latent Reasoning

本章聚焦于一条与扩散语言模型深度交叉的新兴路线：循环 Transformer（Looped Transformer）。其核心思想是让少量 Transformer 层反复执行多次，在不增加参数的前提下实现动态计算深度，从而在隐空间中完成"latent reasoning"（隐式推理）。覆盖 30+ 篇论文（2019–2026）。

11.1 核心直觉：参数复用 vs 参数堆叠

一句话总结

标准 Transformer 像拥有 $L$ 个不同"顾问"的团队，每人只看一遍问题；Looped Transformer 像只有 $k$ 个顾问（$k \ll L$），但他们会反复讨论 $T$ 轮，每轮重新审视并改进上一轮的结论。两种方案计算量相近（$k \times T \approx L$），但循环方案的参数量只有 $k/L$。

定义：$(k \otimes T)$ Looped Transformer

给定 $k$ 层 Transformer block $M_\theta$，循环执行 $T$ 次：

$$F^{(T)}(\mathbf{x}) = \text{LMHead} \circ \underbrace{M_\theta \circ M_\theta \circ \cdots \circ M_\theta}_{T\text{ 次}} \circ \text{Embed}(\mathbf{x})$$

每次循环产生一个隐状态 $h^{(t)} = M_\theta(h^{(t-1)})$，可以理解为一次"latent thought"（隐式思考）。整个循环过程在不增加任何参数的前提下，将有效深度从 $k$ 扩展到 $kT$。

Standard Transformer
$L$ 层独立参数
Params = $L \times$ per-layer
FLOPs = $L \times$ per-layer
每层处理一次，信息单向传递
Looped Transformer $(k \otimes T)$
$k$ 层共享参数，循环 $T$ 次
Params = $k \times$ per-layer
FLOPs = $k \times T \times$ per-layer
每步精炼隐状态，迭代收敛

11.2 数学框架与核心理论

Theorem 5.1：群组合（ICLR 2025, Saunshi et al.）

定理

对于任意有限群 $G$ 和 $n$ 个元素的组合 $g_1 \circ g_2 \circ \cdots \circ g_n$，1 层 Transformer 循环 $\lceil \log_2 n \rceil$ 次即可精确计算。Embedding size $d = 3(\lceil \log_2 |G| \rceil + \lceil \log_2 n + 1 \rceil)$，2 个 attention head。

核心技巧是迭代平方（binary lifting）：每步将有效组合窗口加倍。例如计算 8 个飞镖得分总和：第 1 轮两两相加（4 个结果），第 2 轮再两两相加（2 个结果），第 3 轮得到总和。3 轮 = $\log_2 8$ 步完成，每轮用同一个加法操作。

Theorem 5.4：循环模拟 CoT（ICLR 2025）

定理

$L$ 层非循环 Transformer 的 $m$ 步 CoT 可被 $(L + O(1))$ 层的 looped transformer 用 $m$ 次循环模拟。核心构造：(1) masking all-but-one 维护循环计数器 $t$；(2) shift-by-one 将当前步输出移动到下一步输入位置；(3) token decoding 的 MLP 模拟编码-解码过程。

意义：循环步数等价于隐式 CoT 步数——但每个循环步更新的是所有 $d$ 维隐状态（而非仅生成 1 个 token），信息带宽远大于文本 CoT。

Effective Depth 实验

关键发现：循环比新参数更有效

定义有效深度 $D = k \times L$。精度随 $\log(D)$ 对数增长：$\text{Acc} = \alpha \cdot \log(D) + \beta$。在推理任务上 $\alpha_{\text{loop}} / \alpha_{\text{base}} = 1.19$。

Expressive Power（Xu & Sato, ICML 2025）

从近似论角度定义了三种循环模型特有的连续性模量：Token 连续性模量 $\omega_f^{\text{tok}}(\delta)$、上下文连续性模量 $\omega_f^{\text{cont}}(\delta)$、序列连续性模量 $\omega_f(\delta)$。Theorem 3.6 证明近似误差随 $r$ 以 $r^{-1/((N+1)d+1)}$ 衰减。但 Lemma 4.1 揭示了固有限制：weight-tied FFN 无法精确记忆标签。

Timestep Encoding (TMLT) 引入 step-dependent scaling $\eta(t) \odot \text{FF}(X)$ 消除上述限制，Theorem 4.2 证明可实现零误差精确记忆。实验效果：Sudoku 从 65.6% 提升到 80.2%（$r=16$），edit distance 从 32.6% 提升到 57.3%（$r=50$）。

11.3 复杂度类分析：为什么 CoT 不够

这是理解 looped transformer 意义的理论核心。基于 Merrill & Sabharwal（NeurIPS 2025）和 Svete & Sabharwal（ICLR 2026 Oral）的综合分析：

模型类型复杂度类能力边界
固定深度 TransformerTC⁰无法处理正则语言、图连通性
CoT（$O(\log n)$ 步）TC⁰仍受限于常数深度电路
Looped TF（$O(\log n)$ 次循环）TC¹可解图连通性（NL-complete）
MDM（对数步掩码扩散）NC¹可识别正则语言，严格 > CoT
核心结论

CoT 的 $O(\log n)$ 步仍在 TC⁰ 内，只有超对数级 CoT 才能突破 TC⁰。而循环是退出 TC⁰ 最高效的路径——$O(\log n)$ 次循环即可达到 TC¹。进一步，Svete & Sabharwal 证明 $\text{CoT}[\log N] \subsetneq \text{MDM}[\log N, N]$，掩码扩散模型（MDM）严格超越 CoT，可达 NC¹ 复杂度类。

11.4 与扩散模型的形式类比

Looped transformer 与扩散模型共享一个深层结构：从初始状态出发，经过迭代精炼到达目标状态。

Looped Transformer
$h^{(t)} = M_\theta(h^{(t-1)})$
确定性迭代，每步用相同参数 $M_\theta$
隐状态 $h^{(t)}$ 逐步精炼
最终步解码为 token
扩散模型（ODE 视角）
$x_{t-\Delta t} = x_t + \Delta t \cdot v_\theta(x_t, t)$
沿速度场 $v_\theta$ 迭代去噪
连续隐空间保留不确定性
最终步解码为 token

LoopFormer（ICLR 2026）显式利用了这个类比：将循环步类比为扩散模型中的去噪步，通过 time/step conditioning 让模型感知当前处于轨迹的哪个位置。Huginn（NeurIPS 2025 Spotlight）更进一步——从随机噪声 $s_0 \sim \mathcal{N}(0, \sigma^2 I)$ 出发，在输入条件引导下逐步收敛到答案。

三条路线的统一视角

无论是循环 Transformer、连续扩散还是 COCONUT 的 continuous thought，它们都在做同一件事：在隐空间中执行迭代计算，用连续状态而非离散 token 传递中间推理结果。区别仅在于迭代机制（weight-tied forward / ODE 采样 / hidden state 回灌）和监督信号（最终步 / 每步 / 课程学习）。

11.5 核心论文：Ouro / LoopLM

arXiv:2510.25741 ByteDance Seed / UCSC / Mila 2025
Scaling Latent Reasoning via Looped Language Models

作者：Rui-Jie Zhu (UCSC), Zixuan Wang (Princeton), Kai Hua / Ge Zhang (ByteDance Seed co-leads), Yoshua Bengio (Mila) 等

核心贡献：提出 LoopLM 范式，将 loop depth 确立为继参数量和数据量之后的"第三条 scaling axis"。开源 Ouro 系列模型（1.4B / 2.6B），在推理密集任务上匹敌 8B–12B 级别标准 LLM。

架构设计

标准 decoder-only Transformer，但层栈以 weight-tied 方式循环执行 $t$ 次。每步产生独立的 LM head 输出和 cross-entropy loss。引入 exit gate（sigmoid + survival function）实现自适应计算深度，通过阈值 $q$ 控制推理时的循环步数。

知识容量 vs 知识操纵

Capo task 证明循环不增加知识存储（~2 bits/param），但显著提升知识操纵能力（Mano modular arithmetic 任务全面优于 iso-parameter 和 iso-FLOP baseline）。MMLU 分类分析：推理重的类别提升巨大（Elementary Mathematics +155.6%），知识重的类别提升微小（Global Facts +8.3%）。

忠实性分析：LoopLM vs 标准 CoT

标准 CoT 模型的 thinking trace 对最终答案几乎没有修正作用（ROC AUC 0.99 = 后验合理化）。而 LoopLM 的中间步真正在修正决策——step-2 与 step-4 答案一致率仅 36.1%，说明循环过程中确实在推翻并重新推导结论。安全性随循环步数单调提升，即使在外推区域（$T > 4$）依然如此。

Scaling Law：建立总 loss 和 step-wise loss 两套 scaling law（$R^2 = 0.96$ / $0.79$–$0.89$），跨模型大小、训练数据量和循环步数均可预测。

RL 尝试（DAPO/GRPO）未成功——动态 early-exit 与 vLLM/SGLang 固定执行路径不兼容。

11.6 核心论文：CCDD

arXiv:2510.03206 MIT / Microsoft Research ICML 2026
Make Your Diffusion Language Model a Latent Reasoner

作者：Cai Zhou (MIT / Microsoft Research), Dinghuang Zhang (Microsoft Research) 等

核心贡献：提出 CCDD 框架，在连续隐空间 $Z$ 和离散 token 空间 $X$ 上定义联合多模态扩散过程，统一了连续扩散模型（CDM）、离散扩散模型（DDM）和循环 Transformer 三种范式。

理论层级

表达力严格排序
$$\text{CDM} \;\supset\; \text{Loop Transformer} \;\supset\; \text{DDM}$$
  • Theorem 1（CDM 严格支配 DDM）：离散扩散的轨迹族严格包含于连续扩散的轨迹族。DDM 每步做"logits → sample → embed"量化（丢失完整 logit 几何），CDM 做"logits → logits"连续传播。
  • Proposition 2（CDM 泛化 Loop Transformer）：任何 looped transformer 的 rollout 都可以被连续扩散 ODE 采样器精确模拟（显式 Euler，步长 $1/T$）。反之不然——确定性循环 rollout 无法模拟非退化随机 SDE 路径（Theorem 9）。

CCDD 方法

前向过程在离散空间用 CTMC（masked noise），连续空间用 VP-SDE，两者独立。反向过程由单个 time-conditioned Transformer 处理双模态输入，通过 cross-modal conditioning 注入耦合。三种架构变体：

MDiT
混合后处理
单套参数处理双模态
MMDiT
交错处理
参数量翻倍，双套 attention
MoEDiT
共享注意力 + 分离 MLP
参数不翻倍，推荐方案

关键技术创新：

  • 异步噪声调度：连续噪声衰减慢于离散噪声，使反向过程中隐表示先生成（充当隐式规划），再引导 token 解码。
  • 上下文嵌入：使用预训练 Qwen3-Embedding 的 contextualized 层输出作为连续空间目标，提供序列级语义和隐式知识蒸馏。
  • CFG：连续模态作为条件、离散-only 作为无条件，训练时随机 drop 连续嵌入（$p = 0.15$）。

11.7 扩散语言模型中的 Latent Reasoning（2024–2026）

11.7.1 理论：MDM 的表达力

arXiv:2510.13117 ETH Zurich / AI2 ICLR 2026 Oral
On the Reasoning Abilities of Masked Diffusion Language Models

dLLM 推理能力最重要的理论工作。核心结论：(1) MDM 等价于并行叶树（PLT）；(2) 对数步 MDM 可识别正则语言；(3) 严格分离 $\text{CoT}[\log N] \subsetneq \text{MDM}[\log N, N]$——MDM 可达 NC¹ 而 CoT 卡在 TC⁰；(4) $\text{MDM}[O(\log^d N), \text{poly}(N)] = AC^d$。为"离散扩散天然具备隐式推理能力"提供了最严格的理论背书。

11.8 Looped Transformer 深度解析

11.8.1 历史脉络：从 Universal Transformer 到现代 LoopLM

2019 · ICLR
Universal Transformer (UT)：循环 Transformer 的奠基工作。Weight-shared block 迭代 $K$ 次 + ACT 自适应停止。UT 存在 ACT 不稳定性（标准初始化导致 token 在 ~2 步即 halt）和高方差问题。
2023 · ICML
Looped Transformers as Programmable Computers：13 层 encoder 配合循环即可模拟指令集计算机（Turing 完备）。
2024 · ICLR
Looped Transformers are Better at Learning Algorithms：input injection $Y_{t+1} = M(Y_t + P)$ 防止输入影响随 $t \to \infty$ 衰减。以不到 10% 的参数匹配 12 层标准 Transformer。
2025 · ICLR / NeurIPS
理论突破：Reasoning with Latent Thoughts（循环 = 隐式 CoT）、COCONUT（Chain of Continuous Thought）、Huginn（从噪声到答案的循环收敛）。
2026 · ICLR / ICML
架构成熟：LoopFormer（弹性深度）、ChainGPT（双 reasoning）、MoDr（多分支路由）、Equilibrium Reasoners（吸引子学习）、LoopMoE（MoE + 循环）。

11.8.3 LoopFormer 技术细节

Shortcut Modulation（AdaLN-style）

时间/步长编码经 sinusoidal Fourier features + 2 层 MLP 生成条件向量 $c = e_t + e_\Delta$。$c$ 通过 AdaLN 调制每个 block：$\gamma$ 参数对 RMSNorm 输出做乘法缩放（before MHSA/FFN），$\alpha$ 参数对残差做 gating（after MHSA/FFN）。

关键：调制 MLP 的最后一层零初始化，确保训练初始时 looped block 退化为无调制的标准 Transformer。

$$\mathcal{L} = \mathcal{L}_L + 0.1 \cdot \mathcal{L}_S + 0.1 \cdot \|\text{stopgrad}(h^{(L)}) - h^{(S)}\|_2^2$$

弹性推理时指定预算 $M \leq L$ 和 schedule $\Delta_M$。最优 schedule 模式：早期粗步 + 后期细步（类比扩散模型的去噪策略）。

表示坍缩分析

Naive early-exit baseline 呈现：(1) 平坦曲率——方向不变；(2) 高各向异性——token 坍缩到相同方向；(3) 高 CKA 相似度——后续步几乎不改变表示。LoopFormer 在所有度量上均显示逐步演化，证明 shortcut-consistency loss 有效防止了坍缩。

11.8.4 COCONUT：Chain of Continuous Thought

核心机制：将 LLM 最后一层隐状态 $h_t \in \mathbb{R}^d$ 直接回灌为后续位置的输入嵌入。用特殊 token <bot> 进入 latent mode、<eot> 退出。训练使用多阶段课程学习，从标准 CoT 渐进过渡到全 continuous thought。

关键发现——隐空间 BFS：continuous thought 在连续空间中可编码多个候选推理路径的叠加，COCONUT 在 latent 空间隐式执行 breadth-first search，而非标准 CoT 的 depth-first search。

实验结果（GPT-2 scale）：ProsQA 上 COCONUT 达 97.0% accuracy / 14.2 tokens（vs CoT 77.5% / 49.4 tokens）。去掉课程学习导致灾难性崩溃（97.0% → 52.4%）。

11.8.5 Huginn：从噪声到答案

架构——Prelude-Recurrent-Coda：Prelude $P$（2 层）将输入嵌入；Recurrent Core $R$（4 层, weight-shared）迭代 $r$ 次，$s_i = R(A[e; s_{i-1}])$；Coda $C$（2 层）输出分布。状态初始化为随机噪声 $s_0 \sim \mathcal{N}(0, \sigma^2 I)$。

$r=32$ 时有效深度 = $2 + (4 \times 32) + 2 = 132$ 层。3.5B 模型在 GSM8K/MATH 上匹敌 OLMo-7B。涌现行为：数值推理在 latent 空间产生轨道轨迹（orbital trajectories）——状态在结构化流形上做 2D 旋转，类似计数器/时钟。

11.8.6 Loop, Think, & Generalize（2026）

三阶段 grokking：(1) 记忆 → (2) 同分布泛化 → (3) 系统泛化（OOD 组合）。循环是到达阶段 3 的关键。Overthinking 现象：随 $R$ 增加，logit margin 先增后降——存在最优 $R^*$。关键发现——中间监督有害：intermediate supervision 导致 shortcut learning，silent thinking（仅最终步监督）优于逐步监督。

11.10 与 dLLM 项目的关联启示

启示 1：CCDD 为 dLLM 提供了理论锚点

CCDD 证明连续扩散 > looped transformer > 离散扩散（表达力层级），而 dLLM 项目（Plan Corrector）利用的正是离散扩散的"surgical editing"能力。这意味着 dLLM 的优势不在表达力而在可控性和精确编辑——这是一个互补而非竞争的定位。

启示 2：循环 vs 扩散的中间监督问题

Looped transformer 的核心训练难题（中间步无监督 → OOD）恰好是扩散模型的优势——扩散路径上的每个时间点都有重建目标。dLLM 的 RL 路线（SPG → GDSD → DMPO）可以借鉴 looped model 的 entropy regularization（Ouro Stage I）和 trajectory-level reward（"Prioritize the Process"）。

启示 3：自适应深度是关键差异化能力

SWE-bench 等 agentic 任务中，不同 edit 的复杂度差异极大（单行 fix vs 跨文件重构）。LoopFormer 的 elastic depth 和 MoDr 的 multi-branch routing 为 dLLM agent 提供了按任务难度动态调节"思考深度"的架构范式。

启示 4：MoE + 循环是潜在的组合创新点

dLLM 项目中不同编辑类型可能需要不同的"专家"（如 code generation expert vs code deletion expert），LoopMoE 的 iteration-conditioned modulation 思路可直接迁移。

核心技术主题总结
  1. 表达力层级共识正在形成：MDM 可达 NC¹（严格超越 CoT 的 TC⁰），连续扩散 > Loop Transformer > 离散扩散。
  2. 训练稳定性是核心瓶颈：几乎所有 looped model 工作都报告了 loss spike、梯度振荡和外推退化。当前最大可稳定训练的循环步数约为 4–8 步。
  3. 自适应深度已成标配：2025 后的 looped model 都引入了某种形式的自适应计算（exit gate / consistency / routing / halting）。
  4. 循环不增加知识容量但增强操纵能力：Ouro 的 Capo/Mano 实验提供了清晰的实验证据。
  5. RL 对齐是两线的共同未解问题：Ouro 的 DAPO/GRPO 尝试失败，dLLM 的 RL 路线仍处于早期。
  6. MoE + 循环的融合是新方向：LoopMoE、CCDD-MoEDiT、Sparse Layers are Critical 均表明稀疏专家路由与循环计算的组合可同时获得参数效率和推理深度。
  7. 忠实推理 vs 后验合理化：LoopLM 的中间步是真正的"思考"（step-2 vs step-4 一致率仅 36.1%），而非 CoT 的后验合理化。
