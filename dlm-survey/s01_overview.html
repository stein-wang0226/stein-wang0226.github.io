01 扩散语言模型全景概述与四大流派

1.1 为什么需要扩散语言模型？

自回归 (AR) 语言模型（GPT、LLaMA 等）是当前的主流范式，但存在三个结构性局限：

AR 的局限具体表现DLM 如何解决
串行瓶颈 生成 $N$ 个 token 需要 $N$ 次前向推理，吞吐量受限于单步延迟。GPU 算力大量闲置（memory-bandwidth bound） 扩散模型可并行生成整个序列或块，一次前向产生多个 token，充分利用 GPU 并行性
单向生成偏置 严格的左到右生成导致方向性偏差：学会了"A 是 B 的作者"却无法推断"B 的作者是谁"（Reversal Curse） 扩散模型使用双向注意力，对所有位置同时建模，无方向性偏置
缺乏全局规划 每步只看已生成的前缀，无法"先想好整体结构再填细节"。长文本中容易出现结构不连贯 扩散模型的迭代去噪过程天然支持"粗到细"的全局规划——先确定整体结构，再逐步细化 token

但 DLM 也有明确劣势：Token 效率低于 AR（达到同等质量需要更多计算）、缺乏成熟的 KV cache 机制、Chain-of-Thought 推理能力弱、RL 对齐（RLHF/GRPO）因 ELBO bias 而困难。因此当前的共识是：DLM 不是要取代 AR，而是在特定场景（高吞吐、并行生成、投机解码）提供互补优势。

1.2 四大流派概览

根据底层建模空间和生成策略的不同，当前 DLM 可分为四大流派：

🎭
离散空间扩散
在 token 词汇表上做状态转移
D3PM → MDLM → LLaDA → Seed
🧱

宏观 AR + 微观块内并行扩散
DFlash / Nemotron / TiDAR
🌊

COLA / CADD / ELF / CCDD

1.3 四大流派的关系与演化

技术路线演化脉络（2020—2026）

阶段一：理论奠基（2020—2022）

  • 连续扩散：DDPM (2020) → Score-based SDE (2021) → Flow Matching (2022) 建立了连续空间扩散的完整理论
  • 离散扩散：D3PM (2021) 首次将扩散推广到离散状态空间，探索了 uniform/absorbing/distance 三种转移矩阵
  • 文本扩散：Diffusion-LM (2022) 首次将连续扩散应用于文本生成，开创了可控文本生成路线

阶段二：路线分化（2023—2024）

  • 离散路线胜出：MDLM (2024) 将离散扩散简化为加权 MLM，证明吸收态（mask）是文本的最优转移矩阵
  • 块扩散诞生：SSD-LM (2023) 提出半自回归框架，BD3LM (2024) 建立 AR↔Diffusion 精确插值理论
  • 第四范式：SEDD (2024) 开辟比率估计路线，证明离散扩散不必走 mask prediction

阶段三：规模化验证（2025—2026）

  • 大规模 DLM：LLaDA 8B → 100B MoE、Dream 7B、Seed Diffusion，证明 DLM 可以 scale 到 LLM 级别
  • 投机解码爆发：DFlash (6x)、Nemotron（三模态统一）、Trajectory-Level SD (7-14x)，DLM 找到了最务实的落地路径
  • 连续路线复兴：ELF、COLA、LangFlow、Plaid 证明连续 Flow Matching 在语言建模中可行
  • RL 训练突破：SPG、GDSD 开始解决 ELBO bias 问题，让 dLLM 也能做 RL 对齐
  • 商业落地：Mercury 2 成为首个商用 dLLM，Google 发布 Gemini Diffusion

核心判断

DLM 的当前定位：不是取代 AR，而是在三个方向提供互补价值——(1) 投机解码加速器（DFlash/Nemotron，为 AR 模型提速 4-14x）；(2) 高吞吐生成（Mercury 2，1196 tok/s，占据 AR 无法触及的速度区间）；(3) 数据高效训练（Super Data Learners，数据受限场景下优于 AR）。复杂推理任务仍是 AR 的领地，但 SPG/GDSD 正在缩小 RL 差距。
