07 DLM 投机解码：DFlash vs MTP 深度分析

7.0 投机解码基础概念

什么是投机解码 (Speculative Decoding)？

投机解码（又称推测解码）是一种无损加速大语言模型推理的技术。核心思想：用一个小而快的 draft 模型并行"猜测"多个 token，再用大而准的 target 模型一次性验证——接受正确的猜测，拒绝错误的。

基本流程

  1. Draft 阶段：小模型快速生成 $B$ 个候选 token $\hat{x}_1, \hat{x}_2, \ldots, \hat{x}_B$
  2. Verify 阶段：大模型一次前向同时计算所有 $B$ 个位置的概率 $p_{\mathrm{target}}(x_i | x_{
  3. Accept/Reject：从 $i=1$ 开始逐个检查，若 $\hat{x}_i$ 被接受则继续，否则从 $i$ 位置用 target 模型重新采样，丢弃 $\hat{x}_{i+1:B}$

无损性保证

接受-拒绝采样保证了最终输出的分布严格等于 target 模型的分布——不损失任何生成质量。每个 draft token $\hat{x}$ 的接受概率为：

$P_{\mathrm{accept}}(\hat{x}) = \min\!\left(1, \frac{p_{\mathrm{target}}(\hat{x})}{q_{\mathrm{draft}}(\hat{x})}\right)$

当 draft 和 target 分布越接近，接受率越高，加速比越大。极端情况下 $p = q$ 时，所有 draft token 都被接受。

为什么能加速？

关键洞察：大模型的单次前向处理 1 个 token 和 $B$ 个 token 的耗时几乎相同（GPU 并行性）。因此：

  • 不用投机：生成 $B$ 个 token 需要 $B$ 次大模型前向 → 耗时 $B \times t_{\mathrm{target}}$
  • 使用投机：1 次 draft（极快）+ 1 次 target 验证 → 耗时 $t_{\mathrm{draft}} + t_{\mathrm{target}} \approx t_{\mathrm{target}}$，但产出了 $k$ 个有效 token（$k$ 为接受长度）

加速比 ≈ 平均接受长度 $\bar{k}$，典型值 2-6x。

DLM 做 Draft 的天然优势

传统投机解码使用小 AR 模型做 draft（如 EAGLE），但 AR draft 需要$B$ 次串行前向才能生成 $B$ 个 token。扩散模型的并行生成能力使其成为理想的 draft 模型——一次前向即可并行输出整个 block（MIMO 范式），draft 开销从 $O(B)$ 降至 $O(1)$。这正是 DFlash 的核心思路。

投机解码接受率的数学分析

投机解码的无损性保证基于接受-拒绝采样。给定 draft 分布 $q(x)$ 和 target 分布 $p(x)$，每个 draft token 的接受概率为：

$P_{\mathrm{accept}}(x) = \min\!\left(1, \frac{p(x)}{q(x)}\right)$

对于长度为 $B$ 的草稿块，期望接受长度为：

$\mathbb{E}[\text{accepted}] = \sum_{k=1}^{B} \prod_{i=1}^{k} \mathbb{E}_{x_i \sim q}\!\left[\min\!\left(1, \frac{p(x_i|x_{<i})}{q(x_i|x_{<i})}\right)\right]$

加速比的上界为 $\frac{B}{1 + B - \mathbb{E}[\text{accepted}]}$。当 draft 和 target 分布完全一致时（$p = q$），接受长度为 $B$，加速比趋近 $B$。实际中 DFlash 的 $\mathbb{E}[\text{accepted}] \approx 6.5$（$B=16$），加速比约 4.9x（受 target 验证开销影响）。

7.2 投机系统中 AR vs DLM 的发散性分析

能否利用 DLM 的强拟合解决 AR 发散问题？

AR Draft Model 的发散问题

  • 路径依赖：AR 的每个 token 都依赖前一个，误差逐步累积
  • 误差累计：长序列中，早期的小偏差会导致后期完全偏离 teacher 分布
  • 高方差：与 teacher model 的 output distribution 更容易不 match，variance 大
  • 低重合概率：draft 和 teacher 的生成路径重合概率随长度指数下降

AR 发散的数学分析

令 $p$ 为 target 分布，$q$ 为 AR draft 分布。AR draft 在第 $k$ 步的条件分布为 $q(x_k | x_{<k})$。由于 AR 的严格路径依赖，draft 和 target 的联合分布 KL 散度随长度线性增长：

$D_{\mathrm{KL}}(p(\mathbf{x}_{1:B}) \| q(\mathbf{x}_{1:B})) = \sum_{k=1}^{B} \mathbb{E}_{\mathbf{x}_{<k} \sim p} \left[ D_{\mathrm{KL}}(p(x_k | \mathbf{x}_{<k}) \| q(x_k | \mathbf{x}_{<k})) \right]$

每步的局部 KL 散度 $\delta_k = D_{\mathrm{KL}}(p(\cdot|x_{<k}) \| q(\cdot|x_{<k})) > 0$（除非两分布完全一致），导致总散度 $\geq B \cdot \bar{\delta}$。更关键的是，draft 的采样路径 $\mathbf{x}_{1:k}$ 是从 $q$ 而非 $p$ 中采样的——这意味着条件 KL 的期望本身也在漂移，实际散度比线性增长更快。

结果：draft 和 teacher 的路径重合概率（即所有 $B$ 个 token 都被接受的概率）以指数衰减：

$P(\text{all accepted}) = \prod_{k=1}^{B} \mathbb{E}_{x_k \sim q} \!\left[\min\!\left(1, \frac{p(x_k|x_{<k})}{q(x_k|x_{<k})}\right)\right] \leq (1 - \bar{\delta}/2)^B \to 0$

DLM Draft Model 的潜在优势

  • 并行生成：一次性生成整个 block，没有逐步的误差累积——KL 散度不再随 $k$ 线性增长
  • 全局视图：block 内双向注意力提供了更丰富的上下文
  • 更强的 teacher 拟合：过拟合特性使其更精确地模拟 teacher 分布
  • 更长的接受长度：DLM draft 可能得到与 AR 端到端更长的 accepted length（draft 代价低，overlap 长度更 matter）

7.3 Block Diffusion 做投机的精度问题

精度争议：训足够久可以比 AR 更好？
  • 初始精度差：block diffusion drafter 在训练初期精度不如 AR drafter
  • 长期训练可弥补：讨论认为训练足够久后，block diffusion 可以达到甚至超越 AR 的精度
  • 连续扩散做投机效果差：用连续扩散预测 hidden state + MSE loss 的实验结果"还是非常差"——因为 hidden 空间缺乏离散监督信号
  • 何恺明的解决方案：在 $t=0$ 加 loss 强行收敛，而且是在 logit 空间上做（交叉熵），不是 hidden 空间（MSE）

Trajectory-Level SD 的数学原理

传统投机解码在 token 空间推测：猜测"接下来的 $B$ 个 token 是什么"。Trajectory-Level SD 在去噪轨迹空间推测：猜测"接下来的 $S$ 步去噪路径是什么"。

标准 dLLM 去噪需要 $T$ 步迭代：$\mathbf{x}_T \to \mathbf{x}_{T-1} \to \cdots \to \mathbf{x}_0$。Trajectory-Level SD 的核心思想：

$\text{Draft}: \hat{\mathbf{x}}_{T-S} = \mathrm{FastDenoise}(\mathbf{x}_T, S \text{ steps}) \quad \text{vs} \quad \text{Verify}: \mathbf{x}_{T-S} = \mathrm{FullDenoise}(\mathbf{x}_T, S \text{ steps})$

快速去噪（如大步长 ODE 求解器、低精度模型）产生草稿轨迹 $\hat{\mathbf{x}}_{T-S}$，完整去噪验证其正确性。接受判据基于轨迹置信度而非逐 token 比较：

$P_{\mathrm{accept}} = \min\!\left(1, \frac{p_{\mathrm{full}}(\hat{\mathbf{x}}_{T-S} | \mathbf{x}_T)}{p_{\mathrm{fast}}(\hat{\mathbf{x}}_{T-S} | \mathbf{x}_T)}\right)$

置信度分层树探索：构建多条候选轨迹的二叉树，按置信度排序探索。高置信度分支优先验证，若接受则跳过后续分支；若拒绝则探索下一分支。块级并行评估使得多条轨迹可在单次前向中同时验证。

结果：7-14x 加速（Fast-dLLM 基线），远超 token-level 投机（~4-6x）。这代表了从"token 投机"到"轨迹投机"的范式跃迁——利用了 dLLM 去噪过程的结构化特性。

投机解码两大范式

范式 A：Diffusion-as-Drafter for AR（DFlash, DiffuSpec, Spec Diff Decoding）：扩散模型并行生成多 token 草稿，AR 模型验证。优势：drafting 阶段本身并行化。

范式 B：Accelerating dLLM Inference（Fast-dLLM, S2D2, SimSD, Trajectory-Level SD, Self-Spec）：直接加速扩散语言模型的推理。减少去噪步数或在去噪过程中并行 commit token。

最新趋势：Trajectory-Level SD 代表了从"token 投机"到"轨迹投机"的范式跃迁——不再猜测"下一个 token 是什么"，而是猜测"接下来的去噪路径是什么"，实现 7-14x 加速。
