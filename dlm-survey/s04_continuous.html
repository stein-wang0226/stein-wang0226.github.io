这一派认为，既然图像领域的连续扩散（如 DiT）已经成熟，只要把离散文字变成连续向量，即可套用视觉大模型架构。核心问题是如何桥接离散文本和连续空间。根据"在哪里做扩散"，可细分为三条路线：

4.0 Diffusion-LM：连续文本扩散的奠基之作

arXiv: 2205.14217 Stanford · NeurIPS 2022
Diffusion-LM Improves Controllable Text Generation

首个基于连续扩散的非自回归语言模型。核心思路：

  • 前向过程：将词向量序列逐步加噪为高斯噪声 $\mathbf{x}_0 \to \mathbf{x}_T \sim \mathcal{N}(0, I)$
  • 反向过程：神经网络学习逐步去噪，从高斯噪声恢复词向量
  • Rounding 机制：去噪得到连续向量后，通过学习的 softmax 分布映射回离散 token（非简单最近邻）
  • 可控生成：中间状态连续可微，可通过梯度引导 $\lambda \log p(x_{t-1}|x) + \log p(c|x_{t-1})$ 实现结构化约束

采用 $\epsilon$-prediction（预测噪声），直接在 DDPM 框架上操作。在语法控制、结构化约束等可控生成任务上显著优于此前方法。开创了"连续空间文本扩散"路线。

4.1 COLA：字节跳动的连续隐空间扩散

arXiv: 2605.06548 字节跳动 Seed + HKU + ANU · 2025.05 ~2.3B 参数
Cola DLM: Continuous Latent Diffusion Language Model

COLA 采用两阶段架构，将高层语义规划与底层 token 合成解耦：

三大组件

  • Text VAE (~500M)：将离散 token 序列编码为连续 embedding，保持序列长度不变，encoder 使用严格因果处理，MLM 目标训练
  • Block-Causal DiT (~1.8B)：在 VAE 输出的连续隐空间上运行 Flow Matching。将序列分块——块内双向注意力、块间因果注意力。训练通过 flow matching 学习条件分布，推理时通过 ODE 积分从噪声生成连续隐表示
  • Conditional Decoder：从去噪后的连续隐变量重建离散 token

核心优势："先规划说什么（语义级），再决定怎么说（token 级）"——避免了 AR 的严格逐 token 顺序。

训练目标：Block-Causal Flow Matching

COLA 的 DiT 组件使用条件 Flow Matching (CFM) 在 VAE 的连续隐空间上训练。给定 VAE 编码后的隐表示 $\mathbf{z}_0$，前向过程为线性插值：

$\mathbf{z}_t = (1-t)\,\mathbf{z}_0 + t\,\boldsymbol{\epsilon}, \quad \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I}), \quad t \in [0,1]$

DiT 网络 $v_\theta(\mathbf{z}_t, t)$ 学习预测条件速度场 $u_t = \boldsymbol{\epsilon} - \mathbf{z}_0$（从数据到噪声的方向）。训练损失为：

$\mathcal{L}_{\mathrm{COLA}} = \mathbb{E}_{t, \boldsymbol{\epsilon}} \left[ \| v_\theta(\mathbf{z}_t, t) - (\boldsymbol{\epsilon} - \mathbf{z}_0) \|^2 \right]$

Block-Causal 注意力：DiT 内部将序列按固定块大小分割，块内使用双向注意力（允许块内所有位置互相看到），块间使用因果注意力（每个块只能看到之前的块）。这使得推理时可以按块 AR 生成，每块内部并行去噪。

VAE 训练使用重建损失 + KL 正则化：$\mathcal{L}_{\mathrm{VAE}} = \mathcal{L}_{\mathrm{recon}} + \beta \cdot D_{\mathrm{KL}}(q(\mathbf{z}|\mathbf{x}) \| p(\mathbf{z}))$。

COLA 是首个在 few-shot 基准上接近同等规模 AR 模型的连续隐空间扩散 LM。Scaling 实验在 ~2000 EFLOPs 下展现出持续的 loss 下降趋势。

讨论观点：是否需要 VAE/RAE 映射到隐空间？

连续扩散的关键选择：是否引入 VAE/RAE 做隐空间映射。优点是可以利用图像领域成熟的加速技术（consistency distillation、progressive distillation 等实现 few-step 解码），但引入了额外的编解码误差。RAE (Regularized AutoEncoder) 是比 VAE 更稳定的选择。

4.2 Apple CADD：连续增强离散扩散

arXiv: 2510.01329 Apple AI/ML Research · 2025.10 7B 模型已开源
CADD: Continuously Augmented Discrete Diffusion

解决离散扩散的"信息真空"问题：标准 MDM 将所有未观察到的状态统一映射到 [MASK]，彻底摧毁语义信息。CADD 引入两条同步并行的加噪路径：

  • 离散路径：标准 masking（token → [MASK]），提供 mode-seeking 行为（精确性）
  • 连续路径：在 embedding 空间同步注入高斯噪声，遵循线性 flow matching 轨迹，提供"软语义提示"（多样性）

双路径加噪的数学形式化

离散路径（标准 mask 扩散）：每个 token 位置 $i$ 独立地以概率 $t$ 变为 [MASK]：

$q_{\mathrm{disc}}(x_t^i | x_0^i) = (1-t)\,\delta_{x_t^i = x_0^i} + t\,\delta_{x_t^i = \mathrm{MASK}}$

连续路径（embedding 空间 flow matching）：同时将 $x_0^i$ 的词向量 $\mathbf{e}_0^i = \mathrm{Emb}(x_0^i)$ 沿线性插值路径加噪：

$\mathbf{e}_t^i = (1-t)\,\mathbf{e}_0^i + t\,\boldsymbol{\epsilon}^i, \quad \boldsymbol{\epsilon}^i \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$

两条路径使用相同的时间步 $t$ 和相同的随机种子结构（耦合采样），保证离散 mask 位置和连续噪声位置的语义对齐。

融合方式：模型的输入由离散 embedding 和连续 flow 向量逐元素相加构成：

$\mathbf{h}_t^i = \begin{cases} \mathbf{e}_t^i & \text{if } x_t^i \neq \mathrm{MASK} \text{ (未被 mask，使用 flow 后的 embedding)} \\ \mathbf{e}_{\mathrm{MASK}} + \mathbf{e}_t^i & \text{if } x_t^i = \mathrm{MASK} \text{ (mask + 连续噪声 hint)} \end{cases}$

关键洞察：被 mask 的位置不再是纯零信息的 [MASK] embedding，而是叠加了来自连续路径的"软语义 hint" $\mathbf{e}_t^i$。这为模型在 mask 位置提供了关于 $x_0^i$ 的连续线索，解决了纯 mask 扩散的信息真空问题。

训练损失仅使用标准 token-level 交叉熵（预测离散 token），连续路径不引入额外损失——连续信号纯粹作为辅助输入。采样时可通过调节连续路径的采样次数控制精确性（少采样）vs 多样性（多采样）。

反向去噪时，连续隐向量作为"软语义 hint"引导离散 token 去噪。可通过采样连续路径的次数调节精确性 vs 多样性。

架构零修改：与现有 mask diffusion backbone 参数量相同，连续信号和离散 embedding 通过逐元素加法融合后进入网络。使用标准 token-level 交叉熵损失训练。在文本生成、图像合成、代码建模三个模态上一致超越纯 mask-based diffusion baseline。7B 模型（CADD-Base-7B）已在 HuggingFace 开源。

4.3 何恺明团队：从 Diffusion Loss 到 ELF ⭐

ELF: 2605.10938 · MAR: 2406.11838 · Back to Basics: 2511.13720 MIT CSAIL · 何恺明团队
ELF: Embedded Language Flows (连续时间 Flow Matching 语言模型)

何恺明团队的三步演进路线，从图像到语言，从 per-token 到全序列：

Step 1: MAR — Diffusion Loss（NeurIPS 2024）

在 AR 图像生成中，用Diffusion Loss 替代交叉熵分类头，消除 VQ (Vector Quantization) 依赖。每个 token 位置独立地用小扩散过程拟合连续分布。ImageNet 256×256 FID 1.55。

Step 2: Back to Basics（CVPR 2026）

关键洞察：让去噪模型直接预测干净数据 $x_0$，而非噪声 $\epsilon$。因为真实数据在低维流形上，预测干净目标让"看似欠容量"的网络在高维空间中也能成功。

Step 3: ELF — Embedded Language Flows（2025.05）

  • 将 Token 通过冻结 T5 encoder (~35M) 映射到连续 embedding 空间
  • 建立高斯噪声到干净 embedding 的线性插值路径（flow matching）
  • 网络预测干净目标 embedding（$x_0$-prediction），直接继承"Back to Basics"原则——"预测干净 embedding 与预测干净离散 token 的目标天然对齐"
  • 同一共享权重网络同时负责去噪和 token 投影，无需独立解码模块
  • 训练交替使用 MSE（连续 flow 对齐）+ 交叉熵（最终 token 映射）
  • 支持 ODE（确定性）和 SDE（随机性）两种采样 schedule

ELF 的 Flow Matching 推导

Embedding 映射：给定离散序列 $\mathbf{x}_0 = (x_0^1, \ldots, x_0^N)$，通过冻结 T5 encoder 映射为连续 embedding 序列 $\mathbf{e}_0 = (\mathbf{e}_0^1, \ldots, \mathbf{e}_0^N) \in \mathbb{R}^{N \times d}$。

条件流路径：采用线性插值（flow matching 的标准选择），从先验噪声 $\mathbf{z} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$ 到目标 embedding $\mathbf{e}_0$：

$\mathbf{e}_t = (1-t)\,\mathbf{z} + t\,\mathbf{e}_0, \quad t \in [0, 1]$

对应的条件速度场（conditional vector field）为 $u_t(\mathbf{e}_t | \mathbf{e}_0) = \mathbf{e}_0 - \mathbf{z}$，与 $t$ 无关（线性路径的导数为常数）。

训练目标：网络 $v_\theta(\mathbf{e}_t, t)$ 学习近似条件速度场。交替使用两种损失：

$\mathcal{L}_{\mathrm{MSE}} = \mathbb{E}_{t, \mathbf{z}} \left[ \| v_\theta(\mathbf{e}_t, t) - (\mathbf{e}_0 - \mathbf{z}) \|^2 \right]$
$\mathcal{L}_{\mathrm{CE}} = \mathbb{E}_{t \to 0} \left[ \sum_i -\log p_\theta(x_0^i | v_\theta(\mathbf{e}_t, t)_i) \right]$

$\mathcal{L}_{\mathrm{MSE}}$ 保证 flow 轨迹的连续性，$\mathcal{L}_{\mathrm{CE}}$ 在 $t \to 0$（接近干净数据）时强行锚定到正确的离散 token。后者在 logit 空间而非 hidden state 空间计算——实验证明 hidden state MSE 缺乏离散监督信号，效果极差。

推理：从 $\mathbf{z} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$ 出发，沿学习到的速度场 $v_\theta$ 积分 ODE：$\frac{d\mathbf{e}_t}{dt} = v_\theta(\mathbf{e}_t, t)$，最终通过词汇矩阵将 $\mathbf{e}_0$ 投影回离散 token。仅需 32 步 Euler 积分即可获得 PPL ≈ 24。

仅 105M + 35M T5 参数，PPL≈24（32 步采样），在 45.2B tokens 上训练。在无条件文本合成、机器翻译、摘要三个任务上验证。

讨论观点：t=0 加 loss 在 logit 上做而不是 hidden

何恺明的关键技巧：在 $t=0$（最接近干净数据的时刻）额外加一个 loss，强行让模型收敛到正确的离散 token 分布。这个 loss 是在 logit 空间上做（交叉熵），而不是在 hidden state 空间上做（MSE）。实验证明，连续扩散做投机如果用 MSE 在 hidden 上预测效果非常差，因为 hidden 空间缺乏离散的监督信号。

4.4 CCDD：连续-离散联合扩散

arXiv: 2510.03206
CCDD: 连续 + 离散联合扩散 (非何恺明一作)

在模型架构内打通连续和离散的鸿沟，允许在连续特征空间里平滑演化，但在每个时间步动态注入离散 Token 约束。支持 latent reasoning（隐空间推理），但可训练性较差。核心发现：连续表达力 > 离散，但联合优化的工程难度大。

4.5 LangFlow：连续扩散首次匹敌离散

arXiv: 2604.11748 2025.04 PPL 24.6 on OWT
LangFlow: Continuous Diffusion Rivals Discrete in Language Modeling

首次提供明确证据证明连续扩散在语言建模中是可行且有竞争力的。核心创新：

  • Bregman 散度连接：证明 embedding 空间扩散通过 Bregman 散度与 Flow Matching 相连，交叉熵损失保证了"后验匹配"——优化器始终恢复真实的条件 token 概率
  • ODE-based NLL bound：引入理论扎实的似然估计，包含反向轨迹的体积变化
  • Information-uniform scheduling：用"对数噪声-信号比"替代均匀时间调度，将求解器迭代按信息增益分布
  • Self-conditioning：将前步预测作为辅助输入，打破累积误差——与离散扩散不同，连续扩散的 self-conditioning 能同时提升质量和似然（PPL 下降 19.0）

Bregman 散度连接的数学推导

LangFlow 的核心理论贡献：证明 embedding 空间扩散与离散 token 预测之间存在精确的数学联系。

令 $\mathbf{e}_0^i = \mathrm{Emb}(x_0^i)$ 为 token $x_0^i$ 的 embedding，$p_\theta(x | \mathbf{e})$ 为从连续向量 $\mathbf{e}$ 映射到词汇分布的 softmax 投影。定义 Bregman 散度：

$D_F(\mathbf{e}_0^i \| \mathbf{e}_t^i) = F(\mathbf{e}_0^i) - F(\mathbf{e}_t^i) - \langle \nabla F(\mathbf{e}_t^i), \mathbf{e}_0^i - \mathbf{e}_t^i \rangle$

其中 $F$ 是严格凸函数。LangFlow 证明：当 $F$ 选择为与交叉熵对偶的负熵函数时，最小化 embedding 空间的 MSE 去噪损失等价于最小化离散 token 的交叉熵损失（在 Bregman 散度意义下）。

这意味着：连续扩散模型在 embedding 空间优化 MSE，隐式地在离散 token 空间优化交叉熵——两者通过 Bregman 散度精确连接。这是连续扩散能在语言建模中匹敌离散扩散的理论基础。

Self-conditioning 的作用：将前步预测 $\hat{\mathbf{e}}_0$ 作为额外输入传入网络，即 $v_\theta(\mathbf{e}_t, t, \hat{\mathbf{e}}_0)$。这打破了去噪过程中的累积误差——每一步都可以"修正"前步的偏差，而非在错误的基础上继续。在离散扩散中 self-conditioning 仅提升质量不提升似然，但在连续扩散中同时提升二者。

130M 参数双向 Transformer。预测 token 概率分布（非直接估速度），通过词汇矩阵期望重建连续去噪器。LM1B PPL 30.0，OpenWebText PPL 24.6。在 7 个 held-out 数据集中的 4 个上零样本超越标准 AR 模型。

4.6 TextLDM：视觉 DiT 配方迁移语言

arXiv: 2605.07748 2025.05
TextLDM: Language Modeling with Continuous Latent Diffusion

证明视觉 DiT 的架构配方可以直接迁移到语言，几乎无需修改。

架构：VAE + DiT 两阶段

  • 第一阶段 VAE：Encoder 将 token 序列压缩为连续隐向量 $\mathbf{z} = \mathrm{Enc}(\mathbf{x}) \in \mathbb{R}^{L' \times d}$（$L' < L$，实现序列压缩），Decoder 从隐向量重建 token 序列
  • 第二阶段 DiT：在 VAE 隐空间上做 Rectified Flow matching，生成骨干与视觉 DiT 架构完全相同（AdaLN-Zero、Patchify、全双向注意力）
  • REPA 对齐：VAE 中间层表征与冻结预训练 LM（如 T5）对齐，通过 Representation Alignment loss 改善条件去噪质量——作者指出"仅靠重建保真度不够，需要对齐中间表征"

训练目标

VAE 阶段：重建损失 + KL 正则 + REPA 对齐损失：

$\mathcal{L}_{\mathrm{VAE}} = \underbrace{\sum_i -\log p_{\mathrm{dec}}(x_i | \mathbf{z})}_{\text{重建 CE}} + \beta \cdot D_{\mathrm{KL}}(q(\mathbf{z}|\mathbf{x}) \| \mathcal{N}(0,I)) + \gamma \cdot \underbrace{\| \mathbf{h}_{\mathrm{enc}} - \mathrm{sg}(\mathbf{h}_{\mathrm{LM}}) \|^2}_{\text{REPA: 与冻结 LM 对齐}}$

其中 $\mathrm{sg}(\cdot)$ 表示 stop-gradient，$\mathbf{h}_{\mathrm{LM}}$ 是冻结预训练 LM 的中间层表征。

DiT 阶段：标准 Rectified Flow matching 损失：

$\mathcal{L}_{\mathrm{DiT}} = \mathbb{E}_{t \sim \mathcal{U}[0,1],\, \boldsymbol{\epsilon} \sim \mathcal{N}(0,I)} \left[ \| v_\theta(\mathbf{z}_t, t) - (\mathbf{z}_1 - \mathbf{z}_0) \|^2 \right], \quad \mathbf{z}_t = (1-t)\mathbf{z}_0 + t\mathbf{z}_1$

其中 $\mathbf{z}_0 \sim \mathcal{N}(0,I)$ 是噪声起点，$\mathbf{z}_1 = \mathrm{Enc}(\mathbf{x})$ 是数据端点。

关键实验结果（Text Continuation，OpenWebText2 训练）

TextLDM 在 text continuation 任务上评估，使用 ROUGE/BERTScore/MAUVE 而非 PPL（因为 VAE 隐空间扩散无法直接计算似然）。

4.7 Plaid：连续 DLM 的首个 Scaling Law ⭐

arXiv: 2605.18530 NeurIPS 2025 相关工作
Plaid: Continuous Diffusion Scales Competitively with Discrete Diffusion for Language

建立了连续扩散语言模型的首个 scaling law，证明连续 DLM 可以匹敌离散 DLM。

架构与训练目标

Plaid 在 embedding 空间做 Flow Matching（非 VAE 隐空间），使用与 ELF 类似的框架但做了关键改进：

  • Embedding 精化：不使用原始 embedding，而是通过可训练的投影层 $\mathbf{e}'_i = W_{\mathrm{proj}} \mathbf{e}_i$ 创建"结构化几何"——让不同 token 的 embedding 在流匹配空间中分布更均匀
  • 自适应噪声调度：通过调优噪声调度参数，使信息损失（交叉熵）随时间 $t$ 线性变化——这保证了每个时间步提供均匀的训练信号
$\mathcal{L}_{\mathrm{Plaid}} = \mathbb{E}_{t, \boldsymbol{\epsilon}} \left[ \| v_\theta(\mathbf{e}_t, t) - (\mathbf{e}_1 - \boldsymbol{\epsilon}) \|^2 \right] + \lambda \cdot \mathrm{CE}(\mathbf{x}_0, \mathrm{round}(\hat{\mathbf{e}}_0))$

其中第一项是标准 Flow Matching 速度场 MSE，第二项是 rounding CE（将连续向量映射回离散 token 的交叉熵监督，类似 ELF 的设计）。

Scaling Law 发现

Plaid 在 0.04B - 1.3B 参数规模上系统性地拟合了 scaling law，发现：

$L_{\mathrm{Plaid}}(N, D) = \frac{A}{N^{\alpha}} + \frac{B}{D^{\beta}} + C$

其中 $N$ 是参数量、$D$ 是训练数据量。关键发现：连续 DLM 的 scaling exponents 与离散 DLM 相当接近——说明连续路线并非天然劣势。

核心结论：(1) 连续 DLM PPL 22.1 是所有扩散语言模型（连续 + 离散）的新 SOTA；(2) 与 AR 的计算差距仅 ~20x，远小于此前假设的数量级差距；(3) Embedding 精化和噪声调度优化是关键——消融实验显示去掉任一均导致 PPL 上升 3-5 点；(4) 连续 DLM 的 scaling law 斜率与离散 DLM 相当，证明连续路线有长期竞争力。

连续 DLM 的三条路线总结

Embedding 空间扩散（Diffusion-LM → ELF → LangFlow）：直接在词向量空间做 flow matching，理论上最优雅（Bregman 散度连接 CE↔MSE），但需要额外的 rounding 机制将连续向量映射回离散 token。ELF 通过冻结 T5 encoder + logit 空间 CE 损失解决了这一问题。VAE 隐空间扩散（COLA → TextLDM → Plaid）：先压缩再扩散，完全复用视觉 DiT 架构，但 VAE 编解码引入额外误差，scaling 尚未证明超越离散。连续增强离散扩散（CADD → CCDD）：不抛弃离散本质，用连续信号辅助离散去噪，架构零修改，是"最小侵入"的混合方案。核心未解决问题：连续 DLM 与 AR 的 ~20x 计算差距能否通过 consistency distillation 等加速技术弥合？
