03 块扩散与半自回归 (Block / Semi-AR)

块扩散认为没必要一上来就生成全篇纯噪声让模型去解——可以一段一段做扩散。宏观自回归保证长文本可控性，微观块内并行去噪提供速度优势。

3.1 BD3LM：AR 与 Diffusion 的精确插值 ⭐

arXiv: 2503.09573 Cornell Tech · ICLR 2025 Oral
Block Diffusion: Interpolating Between Autoregressive and Diffusion Language Models

BD3LM 是块扩散的理论基础工作，建立了 AR 与 Diffusion 之间的精确插值框架。

核心思想：块级分解

将序列 $\mathbf{x}$ (长度 $L$) 划分为 $B$ 个大小为 $L'$ 的块 ($B = L/L'$)。联合分布分解为：

$\log p(\mathbf{x}) = \sum_{b=1}^{B} \log p(\mathbf{x}_b | \mathbf{x}_{<b})$

每个条件 $p(\mathbf{x}_b | \mathbf{x}_{<b})$ 用离散扩散（mask 加噪 + 迭代去噪）建模，而非标准的分类预测。

插值的两个极限

块大小 $L'$等价模型特点
$L' = 1$标准 AR（next-token prediction）最强似然，完全串行
$L' = L$全序列离散扩散 (MDLM/D3PM)完全并行，似然较弱
$1 < L' < L$BD3LM（插值区间）AR 跨块 + 扩散块内，两全其美

插值的数学证明

定理：BD3LM 的似然下界随块大小 $L'$ 单调递减，在两个极限处分别退化为 AR 和全序列扩散。

证明。将联合分布 $\log p(\mathbf{x})$ 通过链式法则分解为块级条件概率之和：

$\log p(\mathbf{x}) = \sum_{b=1}^{B} \log p(\mathbf{x}_b | \mathbf{x}_{<b})$

每个块条件 $p(\mathbf{x}_b | \mathbf{x}_{<b})$ 用离散扩散建模，其对数似然有 ELBO 下界：

$\log p(\mathbf{x}_b | \mathbf{x}_{<b}) \geq \mathbb{E}_{q(\mathbf{x}_{b,t} | \mathbf{x}_b)} \left[ -\mathcal{L}_{\mathrm{diff}}(\mathbf{x}_{b,t}, t, \mathbf{x}_{<b}) \right] := \mathcal{L}_{\mathrm{BD3LM}}^{(b)}$

总似然下界为 $\mathcal{L}_{\mathrm{BD3LM}} = \sum_b \mathcal{L}_{\mathrm{BD3LM}}^{(b)}$。

  • 当 $L' = 1$ 时，每块仅含 1 个 token，离散扩散退化为确定性分类预测 $p(x_b | x_{<b})$，ELBO 变为精确似然——完全等价于 AR
  • 当 $L' = L$ 时，$B = 1$，整段序列为一个块，块级 AR 消失——完全退化为 MDLM/D3PM 的全序列扩散
  • 当 $1 < L' < L$ 时，跨块依赖通过 AR 精确建模（无信息损失），块内通过扩散并行建模（有 ELBO gap），总体似然介于二者之间

关键推论：AR 成分贡献精确似然，扩散成分贡献 ELBO gap。$L'$ 越大 → 块内扩散 gap 越大 → 总似然越低，但并行度越高。这构成了一个似然-速度 Pareto 前沿。

Clipped 噪声调度

BD3LM 引入"截断"噪声调度，将 masking 率限制在 $[\alpha_{\min}, \alpha_{\max}]$ 区间，避免极端 masking 率导致训练不稳定。截断阈值通过验证集网格搜索动态更新。

实验结果 (OpenWebText)

比 MDLM PPL 改善最高 13%，且需要更少的采样函数评估次数。支持生成超过训练上下文长度的序列——这是纯扩散模型做不到的。

3.2 SDAR：AR 预训练 → 块扩散适配

arXiv: 2510.06303 上海 AI Lab + 浙大 + 清华 · 2025.10
SDAR: A Synergistic Diffusion-AutoRegression Paradigm

SDAR 的核心洞察：不要从头训练块扩散模型，直接轻量适配预训练 AR 模型。

三阶段训练

  1. 标准 AR 预训练：使用 Qwen3 基础模型 (1.7B, 4B, 8B, 30B-A3B MoE)
  2. 块扩散继续预训练：在开放语料上用块扩散目标继续训练
  3. SFT 适配：块大小可从默认 4 增大到 8/16/32/64

关键特点：不需要注意力退火或 logit 偏移。训练仅需几十 billion tokens（非几百 billion）即可完成适配。

关键结果

  • 通用 benchmark (MMLU 等) 匹配 AR 基线
  • Science-tuned 30B-A3B 在 GPQA 和 ChemBench 上超越 AR-30B（ChemBench 72.8）
  • 87.2 on HumanEval (30B-A3B)
  • 自适应解码比静态方法快 >2x 吞吐量
  • 更大模型容忍更大块——30B 可以用 block size 64 而不降质
BD3LM vs SDAR：理论 vs 实用

BD3LM 建立了 AR↔Diffusion 插值的理论框架（ICLR'25 Oral），但从零训练成本高。SDAR 则走实用路线：以 AR 为高效训练基础，在推理时提取扩散的并行性优势。两者的共同核心：块间 AR 保证似然和 KV cache，块内扩散提供并行 token 生成。

3.3 SSD-LM：半自回归扩散的先驱

arXiv: 2210.17432 UW · ACL 2023
SSD-LM: Semi-autoregressive Simplex-based Diffusion Language Model

最早的块扩散语言模型之一。两个关键设计：

  • 半自回归：迭代生成 token 块（而非单 token），支持灵活长度和本地双向上下文
  • Simplex-based：直接在词汇概率 simplex 上做扩散（非 embedding 空间），可用现成分类器做 modular controllable generation

Simplex 扩散的数学框架

SSD-LM 的核心创新是将扩散过程定义在词汇概率单纯形 $\Delta^{K-1} = \{\mathbf{w} \in \mathbb{R}^K : w_i \geq 0, \sum_i w_i = 1\}$ 上，而非连续的 embedding 空间。

前向过程：将 one-hot 编码 $w_0 = \mathbf{e}_{x_0}$ 逐步加噪为 simplex 上的分布：

$q(\mathbf{w}_t | \mathbf{w}_{t-1}) = \mathcal{N}_{\Delta}(\mathbf{w}_t; \sqrt{\alpha_t}\,\mathbf{w}_{t-1} + (1-\sqrt{\alpha_t})\mathbf{u},\; \sigma_t^2 \mathbf{I}_\Delta)$

其中 $\mathbf{u} = \frac{1}{K}\mathbf{1}$ 是均匀分布（simplex 的中心），$\mathcal{N}_{\Delta}$ 表示投影到 simplex 上的高斯分布。直观理解：每个 token 的 one-hot 编码逐渐向均匀分布收缩，同时添加 simplex 上的噪声。

反向过程：神经网络 $f_\theta$ 预测 simplex 上的去噪结果，输出仍为概率分布 $\hat{\mathbf{w}}_0 \in \Delta^{K-1}$。最终生成时通过 $\arg\max$ 或采样得到离散 token。

关键优势：模块化可控生成。由于模型输出在 simplex 上（而非 embedding 空间），可以直接用现成分类器 $c(\mathbf{w})$ 的梯度引导生成：

$\hat{\mathbf{w}}_0^{\mathrm{guided}} = \hat{\mathbf{w}}_0 + \lambda \nabla_{\mathbf{w}} \log c(y | \mathbf{w}_t)$

这避免了 embedding 空间扩散中"连续向量无法直接分类"的问题，实现了无需微调的 modular controllable generation。

在质量和多样性上匹配或超越 GPT-2，在引导生成任务上大幅优于扩散基线。

3.4 Blockwise SFT 与 BlockGen：训练与采样优化

块扩散的训练与采样方法论

Blockwise SFT (arXiv: 2508.19529, 2025.08)：识别出块扩散模型的训练-测试不一致问题——训练时随机 mask 整个 response，推理时按顺序块进行。

训练-测试不一致的数学描述

标准块扩散训练的损失函数为：

$\mathcal{L}_{\mathrm{standard}} = \mathbb{E}_{b \sim \mathrm{Uniform}(1,\ldots,B),\, t,\, q(\mathbf{x}_{b,t}|\mathbf{x}_b)} \left[ \mathrm{CE}\!\left(\mathbf{x}_b,\; p_\theta(\cdot | \mathbf{x}_{b,t}, \mathbf{x}_{\neq b})\right) \right]$

其中所有其他块 $\mathbf{x}_{\neq b}$ 在训练时对模型完全可见。但推理时，块按从左到右顺序生成，当前块 $b$ 只能看到前文 $\mathbf{x}_{<b}$，看不到后续块 $\mathbf{x}_{>b}$。

Blockwise SFT 的修复方案：

$\mathcal{L}_{\mathrm{B-SFT}} = \mathbb{E}_{b,\, t,\, q(\mathbf{x}_{b,t}|\mathbf{x}_b)} \left[ \mathrm{CE}\!\left(\mathbf{x}_b,\; p_\theta(\cdot | \mathbf{x}_{b,t}, \mathbf{x}_{<b}, \underbrace{\mathrm{MASK}(\mathbf{x}_{>b})}_{\text{后续块不可见}})\right) \right]$

即训练时每次只 mask 一个块，锁定前文 $\mathbf{x}_{<b}$ 为上下文，阻断后续块 $\mathbf{x}_{>b}$ 的访问，使训练分布与推理分布对齐。损失仅在活跃块 $b$ 上计算。

BlockGen (arXiv: 2606.02241, ICLR 2026)：在混合块大小上训练（而非固定块大小），实现 AR↔Diffusion 的平滑似然插值。引入 AR-informed predictor-corrector 采样 (ARPC)：融合 AR 和扩散预测来识别并重新生成低似然段。发现：简单采样下 uniform-state 扩散领先；但用 ARPC 高步数采样时，masked diffusion 反超。

3.5 DFlash：扩散投机解码的里程碑 ⭐

arXiv: 2602.06036 Z Lab 6x 无损加速 EAGLE-3 的 2.5x
DFlash: Block Diffusion for Flash Speculative Decoding (MIMO)

DFlash 的关键洞察：与其让扩散模型独立生成文本，不如让它充当 AR 模型的"草稿机"。使用 5 层 Transformer 构建轻量块扩散 draft 模型，在一次前向传播中并行生成 16 个 token 的草稿块。

核心技术

  • MIMO (Multiple-In Multiple-Out) 范式：AR 草稿是 MISO（多次前向才出一批 token），DFlash 单次前向并行输出整个 block，GPU 效率远高于串行
  • Target Context Feature 注入：从目标 AR 模型均匀抽取 5 层隐藏状态，经投影融合后注入 draft 模型每一层的 K-V 投影中（非仅输入 embedding），使 draft 模型成为目标模型的"扩散适配器"
  • 训练技巧：随机采样锚点位置构建训练 block、指数衰减 loss 权重（前序 token 更重要）、共享 embedding / LM head

训练目标：块扩散 MLM

DFlash 的 draft 模型使用掩码语言建模目标训练。给定锚点位置 $a$ 和块大小 $B=16$，构建训练块 $\mathbf{x}_{a:a+B}$。在训练中，随机 mask 块内 token（mask 率 $\sim \mathcal{U}[0,1]$），模型预测被 mask 的 token：

$\mathcal{L}_{\mathrm{draft}} = -\sum_{i \in \mathcal{M}} w_i \log p_\theta(x_{a+i} | \mathbf{x}_{a:a+B}^{\setminus \mathcal{M}}, \mathbf{c}_{\mathrm{target}})$

其中 $\mathcal{M}$ 是 mask 位置集合，$w_i = \gamma^i$ 是指数衰减权重（$\gamma \approx 0.95$，前序 token 更重要），$\mathbf{c}_{\mathrm{target}}$ 是从目标模型注入的 context features。

验证机制：Block-wise Verification

AR 目标模型一次性验证整个草稿块（非逐 token）：

  1. Draft 模型并行生成块 $\hat{\mathbf{x}}_{1:B}$
  2. Target 模型计算 $p_{\mathrm{target}}(x_i | \mathbf{x}_{<i}, \hat{\mathbf{x}}_{1:i-1})$ for all $i \in [1,B]$（单次前向，因果注意力）
  3. 从 $i=1$ 开始逐 token 检查：若 $\hat{x}_i$ 被接受（基于典型接受或随机接受），继续检查 $i+1$；否则拒绝 $\hat{x}_{i:B}$，从 $i$ 位置重新采样

关键优势：即使只接受前 $k$ 个 token（$k < B$），target 模型也只需一次前向即可完成验证 + 生成第 $k+1$ 个 token。而 AR draft 需要 $B$ 次前向才能生成同样长度的草稿。

为什么块扩散优于 AR 草稿？

维度AR Draft (EAGLE-3)Block Diffusion Draft (DFlash)
生成方式串行：$B$ 次前向并行：1 次前向
GPU 利用率低（memory-bound）高（compute-bound）
草稿多样性确定性或低温度采样天然随机性（扩散采样）
接受长度~3.4 tokens~6.5 tokens
Draft 模型大小~1B (EAGLE-3)~50M (5 层)

理论洞察：AR draft 的串行生成导致 GPU 计算单元闲置（每次前向只处理 1 个 token），而块扩散的单次前向处理 16 个 token，充分利用 GPU 并行性。此外，扩散采样的随机性提供了更多样的草稿路径，增加被 target 模型接受的概率。

DFlash 的范式意义

DFlash 证明了扩散模型的最佳用途可能不是独立生成文本，而是作为 AR 模型的加速器。这种"扩散草稿 + AR 验证"的范式绕过了扩散模型的两个弱点（长距离依赖弱、生成慢），同时保留了其核心优势（并行采样、多样性）。未来方向：将 DFlash 与 Nemotron 的自投机结合，用同一模型做草稿和验证。

3.6 NVIDIA Nemotron-Diffusion：三模态统一 ⭐

NVIDIA · 26 位作者 3-4x 加速
Nemotron-Labs-Diffusion: Tri-Mode Language Model (AR + DLM + Self-Speculation)

NVIDIA 的核心思路：一个模型，三种解码模式，仅切换注意力 pattern。

三种解码模式

  • AR 模式：标准因果注意力，逐 token 生成，与普通 LLM 完全一致
  • Diffusion 模式：block 内双向注意力 + block 间因果注意力，并行去噪生成整个 block
  • Self-Speculation 模式：同一模型先用 Diffusion 模式生成草稿 block，再用 AR 模式验证——无需独立 draft 模型，共享 KV cache

训练目标：多任务联合训练

Nemotron 在同一训练过程中同时优化 AR 和 Diffusion 两个目标：

$\mathcal{L}_{\mathrm{Nemotron}} = \mathcal{L}_{\mathrm{AR}} + \lambda \cdot \mathcal{L}_{\mathrm{Diff}} = \sum_{i} -\log p_\theta(x_i | x_{<i}) + \lambda \cdot \mathbb{E}_{t} \left[ \sum_{i \in \mathcal{M}_t} -\log p_\theta(x_i | \mathbf{x}_t^{\mathrm{block}}) \right]$

其中 $\mathcal{L}_{\mathrm{AR}}$ 使用因果注意力 mask，$\mathcal{L}_{\mathrm{Diff}}$ 使用 block 内双向 + block 间因果的混合注意力 mask。两个损失共享所有模型参数，仅注意力 mask 不同。可选 LoRA 增强 drafter 质量。

关键实验结果

硬件模式吞吐量 (tok/s)加速比 vs AR
DGX Spark (8B)AR41.81.0x
DGX Spark (8B)Self-Speculation1122.7x
GB200AR2541.0x

核心结论：(1) 三模态统一可行——同一模型同时具备 AR 和 Diffusion 能力，无质量损失；(2) Self-Speculation 消除了独立 draft 模型的部署开销；(3) 搭配 custom CUDA kernel 可在 GB200 上达到 1015 tok/s。

3.7 TiDAR：扩散思考 + 自回归说话

arXiv: 2511.08923 NVIDIA Research
TiDAR: Think in Diffusion, Talk in Autoregression

序列级混合架构：在同一次前向传播中，通过结构化注意力掩码实现"扩散草拟 + AR 精修"。

核心机制：序列内模式混合

将序列分为思考段（Diffusion）和输出段（AR）。思考段使用 block 内双向注意力并行生成多个 token 的草稿；输出段使用因果注意力逐 token 精修。两段共享同一模型权重，通过结构化注意力掩码实现模式切换：

$\mathbf{A}_{ij} = \begin{cases} 1 & \text{if } i,j \in \text{同一 Diffusion block（双向）} \\ 1 & \text{if } j \leq i \text{ 且 } i \in \text{AR 段（因果）} \\ 0 & \text{otherwise} \end{cases}$

关键实验结果

模型方法吞吐量加速比质量保持
8B纯 AR1.0x—
8BTiDAR4.71x - 5.91x✅ 无损

核心结论：无需独立 draft/target model 即可实现 ~5x 加速。与 Nemotron 的区别：Nemotron 在模型级切换模式，TiDAR 在序列级混合两种模式（同一次前向传播内同时包含 Diffusion 和 AR token）。

3.8 DiffuSpec / DART / PARD：投机解码家族

DiffuSpec · DART · PARD

DiffuSpec (arXiv: 2510.02358, 清华+OPPO)：将 DLM 的并行草稿转化为因果一致性路径 (CPS)，自适应草稿长度 (ADL)，3x 加速，无需额外训练。

DART (arXiv: 2601.19278)：在目标模型 hidden states 上添加单个轻量级层，直接并行预测多个未来 masked 位置的 logits，2.03x-3.44x 加速，超越 EAGLE3 达 30%。证明了 diffusion 思想即使只用单层也有效。

PARD (arXiv: 2504.18583)：一次 forward pass 中预测多个未来 token，构建在现有高精度小模型上，通过 parallel draft adaptation 降低 drafting 成本。

3.9 Fast-dLLM 系列 (NVIDIA)

v1: 2505.22618 · v2: 2509.26328
Fast-dLLM: 高效块扩散 LLM

v1：块级近似 KV Cache + 置信度感知并行解码，免训练，吞吐量提升最高 27.6x。

v2：将预训练 AR 模型适配为块扩散模型，仅需 ~1B token 训练数据（比 Dream 少 500x），互补注意力掩码 + 分层缓存 + 并行解码，比标准 AR 快 2.5x。

块扩散的理论演进脉络

SSD-LM (2023) 开创了块扩散范式：在 simplex 上半 AR 生成，证明了块级扩散的可行性。BD3LM (2025) 建立了 AR↔Diffusion 的精确插值理论，证明块大小 $L'$ 控制似然-速度 Pareto 前沿。Blockwise SFT 识别并修复了训练-推理不一致问题。DFlash 则将块扩散重新定位为 AR 模型的加速器（投机解码），用 MIMO 并行草稿实现 6x 无损加速。Nemotron/TiDAR 进一步将 AR 和扩散统一在同一模型内，通过注意力 pattern 切换实现模式转换。核心公式：块间 AR（精确似然 + KV cache）+ 块内扩散（并行生成 + 多样性）。
