五条速览
  • 开源主线 = 更大 MoE + 极致降本：Kimi K3 把开源模型推到 3T 级（KDA 注意力 + LatentMoE），DeepSeek-V4.1-Flash 用 CED + CSA2 + FP4 KV 把每 token KV 压到 890B（约 V4-Flash 的 1/4）；DSA/MLA 稀疏注意力仍是共识。

  • RL 的增量在「修偏」：GSPO（序列级重要性，稳 MoE）、Dr.GRPO（去长度偏置）、Clip-Cov/KL-Cov（抗熵坍缩）。

DeepSeek-V4.1-Flash（DeepSeek，2026-09-10，MIT，含技术报告）FACT

多模态 MoE，骨干 552B、1M 上下文，原生图文输入、自回归生成；HF deepseek-ai/DeepSeek-V4.1-Flash 已开放权重（MIT）。核心是 Causal Encoder-Decoder（CED）：40 层 = 20 层因果编码器 + 20 层解码器，解码器全局 KV 由编码器末层隐状态投影而来，因而 prefill 仅激活 8B、decode 激活 16B，对输入密集的 agentic 负载显著降本。叠加 CSA2（Full/Reindex/Reuse 三静态模式跨层共享 KV 与 indexer）+ 分层稀疏 indexer + FP4 主 KV 缓存，每 token 全局 KV 压到 890B（约 V4-Flash 的 1/4）；SWA Bounded Replay 把持久化 KV 再降到约 1/8。另含 Single-Pass mHC、Engram 条件记忆（196B，token 查表稀疏访问）、DSpark 投机解码；MoE 为 1 共享 + 384 路由专家、每 token 激活 6 个。预训练 45T token（稀疏注意力 @64K，34T 处扩到 1M）；后训练沿用 SFT→RL→OPD，改动集中在 agent 任务/环境的大规模自动合成，并支持 1–100 连续可调推理强度。

来源：DeepSeek-V4.1 技术报告 PDF（51 页） · HF 模型卡 · DeepSeek 官方发布。基准「优于 V4-Pro / V4-Flash」为厂商自报 SELF-REPORT。

3.1 循环深度潜空间推理（Recurrent Depth）FACT

Geiping et al.《Scaling up Test-Time Compute with Latent Reasoning: A Recurrent Depth Approach》（arXiv:2502.05171，NeurIPS 2025）提出模型 Huginn：3.5B 参数、800B token 预训练，由单个循环块反复迭代构成，测试时可展开到任意深度——最多相当于 50 步迭代，达到「相当于 50B 参数模型的算力负载」。权重已开源（tomg-group-umd/huginn-0125）。

与思维链（CoT）的本质区别

推理发生在连续潜空间而非离散 token 序列；无需专门的推理训练数据（不用 R1 式 RL/蒸馏）；可在很小上下文窗口内完成深度计算；test-time compute 的扩展维度从「生成更多 token」变为「迭代更多层」。代价是潜空间推理不可被 CoT 监控，可解释性与安全监督更难——这正是它在 GPT-6 传闻中被反复提及的原因。

⚠️ 3.2 「GPT-6(Astra) 使用 Looped Transformer」= 传闻 RUMOR

2026-09-01 The Information 报道 Astra 使用「constrained recurrent depth」，但 OpenAI 发布文档与 system card 均未提及。首席科学家 Pachocki 称前沿模型（含 Astra）计算图深度与 GPT-4 在 2 倍以内，并批评相关报道「混乱」（见 Sebastian Raschka 2026-09-09 分析）。学术上循环深度的最强公开实证仍是 Huginn。本页按未证实处理。

04 优化器：Muon 与后 Adam 时代

Muon 是 2024–2026 最受关注的新型优化器，已从 NanoGPT speedrun 走进万亿参数生产模型。

4.1 核心思想 FACT

Muon = MomentUm Orthogonalized by Newton–Schulz，由 Keller Jordan 于 2024-10/11 提出。直觉分三步：① 照常计算 SGD 动量缓冲；② 对每个 2D 权重矩阵的动量做正交化——用 Newton–Schulz 迭代（约 5 步五次多项式 X ← aX + b(XXᵀ)X + c(XXᵀ)²X，系数由 Jeremy Bernstein 调优）近似 UVᵀ，即把更新矩阵的所有奇异值拉平到 ≈1；③ 效果是所有方向的更新幅度均等，避免「少数主方向垄断学习率」，等效于谱范数下的最速下降（Bernstein & Newhouse《Old Optimizer, New Norm》arXiv:2409.20325）。Muon 只用于隐藏层 2D 矩阵；embedding、输出头与 1D 参数仍用 AdamW。

4.2 规模化与工业落地 FACT

Moonlight（Moonshot AI，arXiv:2502.16982）：加权重衰减 + 对齐每参数更新尺度(RMS) → 开箱即用；同算力最优训练下相对 AdamW 约 2× 计算效率；训练 Moonlight-3B/16B MoE（5.7T token）；开源内存最优的分布式 Muon（每参数显存与带动量 SGD 同阶，远低于 Adam 的两份状态）。

Kimi K2（arXiv:2507.20534，1T MoE）：使用 MuonClip = Muon + QK-clip——在 >1T token 训练中 Muon 会引发注意力 logit 爆炸，QK-clip 对 Q/K 投影做受控缩放化解，实现全程零 loss spike。这是 Muon 首次在万亿参数级生产模型上被官方确认使用。

NanoGPT speedrun 官方记录表中的可核验里程碑：Muon 谱系从 12.0min（2024-10-18）推进到 8.2min（2024-11-06）、3.142min（2025-01-13）；2026-01-04 的混合精度 Muon / Adam 交织方案为 1.878min，到 2026-08-30 的 ANVIL 优化器栈记录为 0.665min。后者是整套训练栈的结果，不应单独归因于 Muon。

05 Agent 最新进展

2026-10-20
RSI / 自进化 Agent：从“反思提示词”走向可验证的自我改写闭环PREPRINT

本页此前没有单列 RSI（recursive self-improvement，递归自我改进）/ 自进化主题。2025–2026 的实质进展并不是“通用模型已能无限自我提升”，而是几个受控闭环开始可复现：Darwin Gödel Machine 让 coding agent 在沙箱中改写自身工具/工作流、用任务得分保留更优后代；SEAL / Self-Adapting LLMs 训练模型为自己生成微调数据与 update directives；MetaSkill-Evolve 把“任务 skill”快循环与“改进 procedure / meta-skill”慢循环分开，尝试真正递归地优化“如何改进”；AI research agent RSI 则报告研究 agent 能通过自改进提升研究效率并迁移到未见任务。

  • Deep-Research 型 agent 产品化：OpenAI deep research（2025-02-02，基于 o3）自主多步浏览 + 工具 + 合成带引用长报告；范式是把「检索→阅读→反思→再检索」的长程闭环交给 agent 规划，而非单轮 RAG。
  • Computer-Use / GUI 原生 agent：字节 UI-TARS（arXiv:2501.12326）只以截图为输入直接输出键鼠动作，端到端感知-推理-操作，不依赖 DOM/无障碍树 → GUI agent 从「结构化 API 编排」转向「像素级原生」。
  • Agentic RL 成独立方向：综述 arXiv:2509.02547（v5 2026-04）提出双维分类（agent 能力 × 任务域）；方法论从「单轮答案对错奖励」转向 agentic rollout（多轮环境交互轨迹）+ 环境交互奖励，在 SWE / τ-bench / OSWorld / 终端沙箱里采样给分。
  • 软件工程 RL 落地：SWE-RL（arXiv:2502.18449，Meta FAIR）用轻量规则型奖励（与真值补丁相似度）在开源软件演化数据上做 RL。

常规化：工具调用、ReAct 规划、RAG。真正前沿：原生 GUI agent、多轮环境奖励 RL、Deep-Research 长程闭环、多 agent 协作+联合 RL（仍早期）。

07 OPD（On-Policy Distillation）提要

站内 Agentic RL 全景指南 已有 OPD 独立长章节，此处仅作提要 + 互链。

2026-06-30
MOPD：多教师 OPD，把单教师压缩扩展为多领域能力整合PREPRINT

MOPD: Multi-Teacher On-Policy Distillation for Capability Integration in LLM Post-Training 将 OPD 从“一个 teacher → 一个 student”扩展为多领域 RL teacher → 统一 student：先分别训练 Math / Instruction Following / SWE / Tool Use 等领域 teacher，再让 student 在自身 rollout 上按领域路由 teacher 信号做 on-policy distillation。论文在 Qwen3-30B-A3B 上报告 MOPD 优于 Mix-RL、Cascade RL、Off-Policy Finetune 与 Param-Merge，并称继承了各 teacher 的大部分能力；还披露已用于 MiMo-V2-Flash 的工业级后训练。

来源：arXiv:2606.30406 · HF Papers 索引。Qwen3-30B-A3B normalised score、MiMo-V2-Flash 部署等为论文作者自报，尚无独立复现 SELF-REPORT。

原理（Thinking Machines Lab 博客，Kevin Lu，2025-10-27）：让学生模型自己采样轨迹，再由更强的教师模型对每个 token 逐一打分（以 reverse-KL 作 per-token 惩罚）。学习发生在「学生真实会到达的状态」上，因此能纠正学生自身的失败模式。

  • vs SFT / off-policy 蒸馏：后者模仿教师产出，学生看不到自己会犯的错误分布；OPD 在学生自采样状态上监督。
  • vs RL：RL 也是自采样，但奖励是稀疏的结果级信号；OPD 是稠密的 per-token 教师监督，样本效率高得多。

成本效益：博客称达 RL 相当推理能力成本仅「一小部分」（9–30×，自蒸馏 50–100×）——厂商单方数据，未独立复现。定位：OPD 打底 + RLVR 冲高，互补。

08 训练策略

一手来源：Qwen3 技术报告（arXiv:2505.09388）、DeepSeek-V3 技术报告（arXiv:2412.19437）。与站内 分布式训练指南 互链。

  • 三段式预训练：① 通用阶段 ~30T token / 4096 序列；② mid-training（中段训练） ~5T 高质量 token，偏 STEM/代码/推理/合成数据；③ 长上下文阶段（4096→32768）。Qwen3 总 36T token / 119 语言。mid-training 在 2025 年已从模糊说法变为技术报告里的正式阶段。
  • 长上下文扩展：RoPE base 10,000 → 1,000,000，配合 YaRN 与 Dual Chunk Attention，支持 128K（报告未宣称 1M）。
  • 现代后训练管线：Long-CoT Cold Start（长思维链冷启动）→ RL；行业通用为 SFT → 奖励建模/RLVR(PPO/GRPO) + 拒绝采样(RFT/STaR) + 课程学习。
  • 效率：DeepSeek-V3（671B/37B）配 MLA + auxiliary-loss-free 负载均衡 + 多 token 预测(MTP)，仅用 2.788M H800 GPU-hours，FP8 混合精度全量训练；Qwen3 MoE 128 专家激活 8、global-batch 负载均衡。

领域 RL 何时有效：一条经验法则

Cao et al.（arXiv:2510.01571）在抗菌肽设计、激酶变体优化、抗体工程、逆折叠四域系统配对 RL 与 PLM，结论：收益由 任务余量 × 奖励保真度 × 策略容量 三因子交互决定；瓶颈是奖励保真度而非策略规模 → 先做奖励建模与校准，再扩策略规模。对任何领域 LLM 团队可直接迁移。
