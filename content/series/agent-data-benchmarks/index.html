合成什么数据，才能测到真正的 Agent 能力

沿一条任务生命周期学习：生产可执行任务，明确科学操作，筛选训练轨迹，最后在独立任务上评测。本页既讲合同与统计原理，也保留来源和实验边界。

在合同、评测和对照方法之后，前沿数据合成与迁移审计继续比较NexForge、EvoSyn、ProgramGym等工作，解释它们分别扩展了什么生成空间。

核心判断：可运行环境、独立验收、受控校准和固定留出集，是任务合成与评测共有的基础。更多任务、更高通过率或更长轨迹，都需要结合覆盖、预算和验证器质量解释。
  • 生产：来源、输入、环境、任务合同与独立verifier。
  • 理解：生物学重复、配对NB模型、contrast、BH与可复算产物。
  • 比较：研究组切分、单因素实验、配对差异、pass@k和失败分母。

来源访问截止2026-11-14。前两章共用本页52项引用，编号独立于《LLM研究地图》；新增科学与集群两章分别记录来源。研究设计、论文数字和个人简历陈述分开；没有执行科学任务、任务合成、训练或benchmark。

“DeepSWE”是特别需要拆开的名字：Datacurve的v1.1是benchmark；Together / Agentica的DeepSWE-Preview是RL模型与配方。两者分别见第02章。

读完应能做到

  • 写出合同：可见输入、输出、合理路径、独立验收与坏控制。
  • 复算统计：offset和配对design、对比方向、BH四检验例。
  • 解释结果：pass@k与pass^k、研究组切分、配对胜负和成本分母。
  • 定位失败：任务歧义、数据语义、科学设计、verifier、环境和预算。
