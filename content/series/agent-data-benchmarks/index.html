合成什么数据，才能测到真正的 Agent 能力

数据生产的单位可能是文本、task、environment或trajectory；评测的对象可能是模型、agent系统或完整工作产物。先固定对象，再讨论规模、训练收益和榜单。本系列把任务工程接到CPT / SFT / RL，并把经典与前沿benchmark放进同一张能力地图。

核心判断：可运行环境、独立验收、受控校准和固定留出集，是任务合成与评测共有的基础。更多任务、更高通过率或更长轨迹，都需要结合覆盖、预算和验证器质量解释。

阅读主线按任务生命周期展开：可执行任务 → 科学统计合同 → 训练准入与对照 → 独立Benchmark。先修执行状态与工具环境；最终产物是任务、verifier、切分、轨迹和失败记录。

读之前先分清四类对象

对象实例适合回答不能直接推出
训练资源 / 环境SWE-Gym、R2E-Gym、CoderForge、ScienceIDE怎样获得任务、reward与可学习轨迹等量任务具有同样难度，或所有报告数据均已公开
固定或滚动benchmarkSWE-bench、TB、DeepSWE、LiveCodeBench固定协议下的成功、泛化与成本脱离版本、harness、预算后的纯模型排名
运行框架 / registryHarbor / Harbor Hub统一执行、任务迁移、artifact和结果管理所有adapter语义一致，或所有入库任务均可靠
评测组织 / 综合指数Artificial Analysis / Intelligence Index多项测量的加权总体表现每个专业任务的表现，或私有评测全部可复现

“DeepSWE”是特别需要拆开的名字：Datacurve的v1.1是benchmark；Together / Agentica的DeepSWE-Preview是RL模型与配方。两者分别见第02章。
