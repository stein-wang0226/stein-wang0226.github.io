任务难度来自科学判断，答案由冻结数据支持

以RNA-seq差异表达为贯穿案例：Agent需要识别计数与样本单位、建立配对统计设计、完成归一化 / 多重检验，并交付可复算的结果。来源、公共问题、私有评估与训练数据是四种不同产物；论文结论提供研究动机，不充当答案oracle。

交付状态：研究设计。本章提供合同、schema、来源图与验收方案。未下载FASTQ或计数包、未运行科学分析、未产生reference / oracle / 容差 / 盲测分数，尚不是可发布的Harbor benchmark。

统计单位是供体的生物学重复。同一供体的处理前后有依赖；样本列数、测序run数和独立受试者数不能互换。

GSE52778 与 airway：同一研究，输入层并不相同

GEO记录是四名供体的原代human airway smooth muscle细胞，四种处理，共16样本：untreated、Dex、albuterol、二者同时处理；处理为1μM、18小时。GEO指向PRJNA229998 / SRP033351，补充文件是FPKM矩阵与作者Dex差异结果。[1]

任务族不是同一数据任意改写题面后得到的独立样本。共享供体、reads、计数和研究结论的变体应进入同一来源组。小型airway适合解释合同与诊断路径；大模型训练需要未来扩展并审计多个独立研究，当前没有“已合成若干万题”的事实。

本文分析：相比指定必须用某R包，公开科学操作与输出语义更能测量决策能力。若跨方法的合理结果无法统一校准，应拆成不同评分协议，而不是随意放大容差或要求匹配论文叙事。

分析要求：先固定比较对象与统计单位

从count到均值：离散度与offset

\[ K_{gj}\sim\operatorname{NB}(\mu_{gj},\alpha_g),\qquad \operatorname{Var}(K_{gj})=\mu_{gj}+\alpha_g\mu_{gj}^2. \]

\(g\)为gene，\(j\)为sample，\(\alpha_g\)为离散度。Poisson方差等于均值；NB允许生物学重复有更大波动。教学取均值100、离散度0.1，方差为\(100+0.1\times100^2=1100\)，标准差约33.2；不能按Poisson标准差10判断同样的数据波动。

\[ \mu_{gj}=s_j\exp(x_j^\top\beta_g),\qquad \log\mu_{gj}=\log s_j+x_j^\top\beta_g. \]

\(s_j>0\)是方法估计的相对有效库大小，\(\log s_j\)作为已给定的offset、系数固定为1；它不是待自由拟合的处理效应。若样本2的有效库大小为样本1的两倍，即便表达相同，其期望count也两倍。归一化因子不一定等于原始总counts比例。

配对design：在同一供体内估计共同处理效应

设计~ donor + condition，以供体A、untreated为基线。每个gene有截距、B/C/D供体项和共同Dex项，以下8行×5列：

样本截距供体B供体C供体DDex
A untreated10000
A Dex10001
B untreated11000
B Dex11001

C Dex10101
D untreated10010
D Dex10011
\[ \begin{aligned} \log\mu_{gj}&=\log s_j+\beta_{g0}\\ &\quad+\beta_{gB}I(B)+\beta_{gC}I(C)\\ &\quad+\beta_{gD}I(D)+\beta_{g,\rm Dex}I(\rm Dex). \end{aligned} \]

可识别性：四对能估计共同效应；若加入每个供体各自的处理交互会耗尽这8行的残差自由度。batch与处理完全共线时，加一列batch也不能分开效应。

Contrast：从自然对数系数到log2FC

\[ \begin{aligned} \log\frac{\mu_{g,\rm Dex}/s_{\rm Dex}} {\mu_{g,\rm untrt}/s_{\rm untrt}}&=\beta_{g,\rm Dex},\\ \log_2\operatorname{FC}&=\frac{\beta_{g,\rm Dex}}{\log2}. \end{aligned} \]

同供体相除使截距和供体项消掉。教学取\(\beta_{\rm Dex}=\log2\)，归一化后FC=2、log2FC=1；若Dex库大小又大两倍，原始期望count比是4。反转contrast则log2FC变为−1。方向和offset都要核对，不能直接把raw count比当处理效应。方法依据见DESeq2与edgeR[3][4]。

DESeq2路径可采用size-factor与dispersion估计、Wald对比；edgeR路径可采用TMM、同一设计矩阵和QL F-test。QL不由2009年的两组exact-test文章单独证明，另见2016 workflow及edgeR v4官方方法说明。[5] [6]。本轮固定候选版本DESeq2 1.52.0、edgeR 4.10.7，但未验证依赖或运行数值结果。

对未检验、全零、过滤、不可估计基因分别定义状态；缺失p值不置0，也不伪造fold change。LFC收缩值与未收缩估计是不同对象。本合同主字段选择未收缩log2FC；若另交付shrunken LFC，应另列字段 / 版本。输入gene宇宙、预过滤和BH集合必须公开冻结。

BH：控制一组声明的错误发现率

固定m个参与校正的检验，把p值从小到大排为\(p_{(1)},\ldots,p_{(m)}\)。在阈值q下，找最大的\(k\)满足\(p_{(k)}\le kq/m\)，将前k项声明显著；没有满足项则不声明。adjusted p通过从后往前取累计最小值获得：

\[ p^{\rm adj}_{(i)}=\min\left(1,\min_{j\ge i}\frac{m\,p_{(j)}}{j}\right). \]
教学四检验例：m=4，q=0.05，非airway实测
排序ip值i·q/mBH padj显著

第三项未校正p<0.05，校正后不显著。FDR是重复实验中错误发现比例的期望控制，不表示每个显著gene有5%概率错误。标准BH保证依赖有效p值、独立或适当正依赖条件；任意相关性不能直接套保证。实际过滤、缺失和adjustment集合依公开方法协议冻结。

完整输出字段公开；数值结果保持未知

候选公共输入为gene×sample非负整数counts.tsv、配对元数据samples.tsv及包含版本 / hash / 计数和注释语义的manifest。输出TSV必须UTF-8、首行字段名、每个gene / sample唯一；NA表示缺失，0表示实测零。JSON用null表示缺失，拒绝NaN / Infinity。可下载schema描述TSV解析后的row对象与summary，跨行 / 科学约束见序列化合同。

切分与污染：研究组是独立单位

首先按BioProject / GEO研究、供体与source lineage归组，重复FASTQ或同一counts的变体不能跨train / held-out。基因、不同提示词或同供体的另一处理并不自动独立。随机切分现有8列会破坏配对设计，也不能证明跨研究泛化。

未来评估层留出方式能回答什么
同分布新研究独立研究group held-out；去重reads / fixture / 答案相似操作与统计合同的迁移
科学压力测试新物种 / assay / paired structure / 注释版本数据语义与适用性边界；不能混为同一主榜
来源熟悉度已知公开教学研究另列；联网 / 离线分轨记忆答案或搜索lookup的污染风险
私有终评reference / scorer隔离，版本冻结后新Agent盲测协议可用性与真实失分原因；不是预训练未见数据的证明

公开airway是常见教学数据；离线和oracle隔离只降低评估时泄漏，不能证明模型预训练没见过结论。去除gene标识来“防污染”会改变真实科学任务，须另外说明其目标与代价。当前各split数量为未知。

理解检查与研究门槛

为什么作者差异结果不能直接成为公共输入？

它已包含任务想检验的目标判断，容易变成lookup。公共输入应该保留需要Agent自行完成的统计链；论文结果只能作为维护者的待验证研究背景。

两个统计包结果不同，应该放宽同一个容差吗？

先固定单位、gene宇宙、方向和方法协议，区分实现错与合法方法差异。无法共同校准的对象分轨评分；没有实测spread时不能编造容差。

一份研究生成千种题面能证明泛化吗？

它们共享来源与答案线索，只增加条件表达覆盖。跨研究、物种与assay迁移须另有独立held-out与统计。

Dex的raw count是对照四倍，为什么log2FC可能只有1？

raw ratio同时包含有效库大小和生物效应。若size factor比为2，去掉offset后FC为2、log2FC为1；还要在同供体和声明模型下比较。
