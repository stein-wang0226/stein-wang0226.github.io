任务难度来自科学判断，答案由冻结数据支持

以RNA-seq差异表达为贯穿案例：Agent需要识别计数与样本单位、建立配对统计设计、完成归一化 / 多重检验，并交付可复算的结果。来源、公共问题、私有评估与训练数据是四种不同产物；论文结论提供研究动机，不充当答案oracle。

交付状态：研究设计。本章提供合同、schema、来源图与验收方案。未下载FASTQ或计数包、未运行科学分析、未产生reference / oracle / 容差 / 盲测分数，尚不是可发布的Harbor benchmark。

先修：任务合成、评测对象、执行与状态。下一章将同一合同接到工业SFT / RL方案。

GSE52778 与 airway：同一研究，输入层并不相同

GEO记录是四名供体的原代human airway smooth muscle细胞，四种处理，共16样本：untreated、Dex、albuterol、二者同时处理；处理为1μM、18小时。GEO指向PRJNA229998 / SRP033351，补充文件是FPKM矩阵与作者Dex差异结果。[1]

来源层已经核对的事实任务使用策略
SRA reads原始序列有SRA入口；未下载只有研究问题涉及上游QC / 计数时，另设计raw任务；不把文件体积当难度
GEO FPKMAll_Sample_FPKM_Matrix是归一化表达值不能转名为raw counts后直接送入整数count模型
GEO gene_exp.diff作者差异分析，携带目标答案线索维护者审计背景；不放Agent公共fixture
airway data(airway)1.32.0 / BioC3.23文档打印63,677×8的gene count对象；4细胞系，Dex与untreated选择它作为下游统计合同的候选near-raw层；不是完整16样本
airway其它对象包另含Salmon量化演示与gse对象、计数语义与tximeta处理另列，不能和airway混用

airway vignette描述STAR对GRCh37 / Ensembl75比对，summarizeOverlaps(mode="Union", singleEnd=FALSE, ignore.strand=TRUE, fragments=TRUE)形成gene counts；这是已处理的上游计数层，不是FASTQ。package标LGPL，研究数据再分发和derived fixture许可须另审计。本轮仅给链接，没有重新发布数据包。[2]

来源页面本身也可能有冲突

BioC3.23网页中，按GEO列位置重命名再生成的中间表显示16行且dex全为untrt；同页冻结data(airway)却打印正确8样本与四组配对。这一可见冲突不能靠“官方教程”消除。本文采用冻结对象的文档作为候选范围，未来需核对实际包内sample_table.csv、colData(airway)与逐GSM字段，以字段语义取值，不能照抄位置式解析。

本轮只观察了网页内容，未运行GEOquery，也未确认冲突的运行根因；“元数据字段变化导致位置解析失效”是待核验解释。

三类任务共享研究组，但检验不同能力

任务族不是同一数据任意改写题面后得到的独立样本。共享供体、reads、计数和研究结论的变体应进入同一来源组。小型airway适合解释合同与诊断路径；大模型训练需要未来扩展并审计多个独立研究，当前没有“已合成若干万题”的事实。

本文分析：相比指定必须用某R包，公开科学操作与输出语义更能测量决策能力。若跨方法的合理结果无法统一校准，应拆成不同评分协议，而不是随意放大容差或要求匹配论文叙事。

科学合同先固定对比和统计单位

K_gj ~ NB(μ_gj, α_g)，Var(K_gj)=μ_gj+α_g μ_gj² log μ_gj = log s_j + β_g0 + donor效应 + β_g,Dex · I(Dex) 本合同方向：Dex / untreated；log2FC = β_g,Dex / log(2) BH-adjusted pvalue ≤ q 才进入声明的显著集合（本文选择q=0.05）

配对用~ donor + condition表达，不把八个样本当八名独立受试者。四对样本能够估计共同Dex效应，不能可靠支撑任意供体×处理交互。批次若与处理完全共线，仅加入一个batch项不能恢复不可识别的生物效应。DESeq2与edgeR的NB模型提供原始方法依据。[3] [4]

DESeq2路径可采用size-factor与dispersion估计、Wald对比；edgeR路径可采用TMM、同一设计矩阵和QL F-test。QL不由2009年的两组exact-test文章单独证明，另见2016 workflow及edgeR v4官方方法说明。[5] [6]。本轮固定候选版本DESeq2 1.52.0、edgeR 4.10.7，但未验证依赖或运行数值结果。

对未检验、全零、过滤、不可估计基因分别定义状态；缺失p值不置0，也不伪造fold change。LFC收缩值与未收缩估计是不同对象。本合同主字段选择未收缩log2FC；若另交付shrunken LFC，应另列字段 / 版本。输入gene宇宙、预过滤和BH集合必须公开冻结。

完整输出字段公开；数值结果保持未知

候选公共输入为gene×sample非负整数counts.tsv、配对元数据samples.tsv及包含版本 / hash / 计数和注释语义的manifest。输出TSV必须UTF-8、首行字段名、每个gene / sample唯一；NA表示缺失，0表示实测零。JSON用null表示缺失，拒绝NaN / Infinity。可下载schema描述TSV解析后的row对象与summary，跨行 / 科学约束见序列化合同。

产物完整字段语义和规则
sample_qc.tsvsample_id, donor_id, condition, library_assigned_counts, detected_genes, normalization_factor每输入sample一行；库大小是assigned gene counts总和；检测量=count>0基因数；factor为方法声明的相对有效库大小，几何均值归一至1
gene_stats.tsvgene_id, log2_fc, lfc_se, pvalue, padj, status, direction, significant每输入gene一行；status= tested / filtered / all_zero / not_estimable；方向按LFC符号；显著按finite padj≤q，缺失不显著
summary.jsoncontract_version, fixture_sha256, method, method_version, design, contrast, fdr_threshold, adjustment, counts, artifact_sha256contrast明确Dex / untreated；counts是汇总一致性；hash对应真实输入和两个TSV。方法字段是复算路由，不评分解释文采

输出schema · 完整字段 / 状态 / 跨行规则 · 公开题面草案。文件包含合同与类型，未填造科学结果。

公开前仍须补全：冻结fixture / container摘要、实际数据hash、预过滤政策、允许方法列表、经验容差、超时 / 内存和离线依赖。草案中的待冻结项是公开发布阻塞项，不能作为隐藏规则交给Agent。

独立 verifier：从可解析到科学复算

切分与污染：研究组是独立单位

首先按BioProject / GEO研究、供体与source lineage归组，重复FASTQ或同一counts的变体不能跨train / held-out。基因、不同提示词或同供体的另一处理并不自动独立。随机切分现有8列会破坏配对设计，也不能证明跨研究泛化。

未来评估层留出方式能回答什么
同分布新研究独立研究group held-out；去重reads / fixture / 答案相似操作与统计合同的迁移
科学压力测试新物种 / assay / paired structure / 注释版本数据语义与适用性边界；不能混为同一主榜
来源熟悉度已知公开教学研究另列；联网 / 离线分轨记忆答案或搜索lookup的污染风险
私有终评reference / scorer隔离，版本冻结后新Agent盲测协议可用性与真实失分原因；不是预训练未见数据的证明

公开airway是常见教学数据；离线和oracle隔离只降低评估时泄漏，不能证明模型预训练没见过结论。去除gene标识来“防污染”会改变真实科学任务，须另外说明其目标与代价。当前各split数量为未知。

轨迹把数据、Harness与训练连接起来

每次动作记录task / fixture / contract / harness / policy版本、角色、工具参数、观察、exit / timeout、artifact hash、token spans、行为logprob与终止原因。工具输出是条件信息；assistant动作才是策略产生的目标。mask=0不会让模型看不到观察，也不代表上游参数没有梯度。

SFT准入至少要求科学artifact通过独立验收、模板一致、动作可执行、隐私 / 许可明确，以及逐步监督范围正确。终局成功的轨迹仍可能有错误动作，需区分保留可解释修复和无条件模仿错误。RL准入还要求环境能复现、奖励有区分度、故障可识别、超时政策固定；环境故障不能简单归为负科学reward。

轨迹schema设计提供结构，不包含伪造rollout。CPT混合策略见Midtraining，角色目标见SFT，结果反馈见RL。

理解检查与研究门槛

为什么作者差异结果不能直接成为公共输入？

它已包含任务想检验的目标判断，容易变成lookup。公共输入应该保留需要Agent自行完成的统计链；论文结果只能作为维护者的待验证研究背景。

两个统计包结果不同，应该放宽同一个容差吗？

先固定单位、gene宇宙、方向和方法协议，区分实现错与合法方法差异。无法共同校准的对象分轨评分；没有实测spread时不能编造容差。

一份研究生成千种题面能证明泛化吗？

它们共享来源与答案线索，只增加条件表达覆盖。跨研究、物种与assay迁移须另有独立held-out与统计。

来源轨迹与当前阻塞项可下载study-audit.json。下一步研究方案见训练与终评；检索证据和信任边界见Agent系统。
