两层A–E对照不要共用含糊标签

原训练系列的Harbor A–E研究CPT / 初始化与额外SFT预算。本章另命名sci-posttrain-A…E，研究可靠SFT之后的反馈和预算。日志保存完整ID，避免同一个“D组”被解释成两个实验。

同时规划“同训练资源预算”与“同推理执行预算”两种比较。SFT没有RL rollout，但仍有示范生产成本；OPD有学生rollout与教师前向；环境执行、CPU与失败重试不能因训练token相等就视为等价。

固定held-out涵盖研究 / 数据来源 / 任务族、公开与私有评测隔离、工具协议和version。模型对公开airway的预训练熟悉度单独报告；从该研究变体观察到的收益不能被写为跨研究或临床泛化。

异质 GRPO：难度、奖励与长度分别控制

同一题采样G条轨迹：A_i=(R_i−mean(R))/(std(R)+ε) 二元reward、独立同分布采样且单次成功概率p时： P(组内奖励有差异)=1−p^G−(1−p)^G G=8：p=0.5约99.2%；p=0.01或0.99约7.7%

数字为概率公式推导，不是本任务成功率。相关采样 / 环境噪声会破坏独立假设；多级progressive reward也不服从二元公式。组内标准化消除部分尺度差异，但不会自动平衡科学任务难度、梯度方向或学习机会。

异质来源训练影响本文方案
难度 / 全对全错组零方差组不提供相对信号按task-family / 难度采样，统计有效组；动态过滤与固定预算分别比较
奖励语义与噪声组内标准化可能放大不可靠微小差异schema分数与科学分数拆开；verifier version固定；环境故障单独标记
轨迹长度 / 工具时间loss权重、信用稀疏、长尾等待记录action tokens、观察、尝试时长；同任务预算对照；截断不混为模型EOS
训练 / 采样策略差异policy lag、精度 / mask / routing偏差行为logprob和逐动作版本；同步先验证，再对lag与校正做消融

DAPO、Dr. GRPO和GSPO改变不同对象，不能写作统一的“改进GRPO”。前沿RLDS / KnowGPO / SAPO / SAMPO的证据和算法同名差异沿用研究地图02；科学任务D组应选一个与失败机制匹配的方法，固定implementation，再检验收益。

步骤信用不能凭人工想象“正确步骤”赋值。可验证中间artifact / 反事实继续执行能提供更客观依据，但需要额外环境成本及独立校准。最终科学成功仍单独验收，防止学会刷格式分或提前停止。

长度与动作预算：模型上下文不是免费工作区

本文初始规划两层请求：短任务最多8,192输入 / 4,096输出token、24次动作；长任务最多24,576输入 / 8,192输出、64次动作。数值是预算设定，不是已观察分布；sum=32,768满足所选Dense config的原生最大位置规格。多轮每次请求都检查上下文上限，总轨迹action tokens另计，不能把单次max_new_tokens当完整任务成本。

Harness负责压缩长stdout、保留重要错误和artifact引用；memory压缩也要保留供体 / 样本 / 对比与当前脚本状态。统计分析结果应保存在文件，再以hash / 精简观察回填，不把整张gene表塞进prompt。科学可审计性来自artifact，不能只依赖会话摘要。

组大小初选G=8；prompt batch、gradient accumulation和microbatch在容量测量前不冻结。DP决定独立数据副本；TP / PP / CP不能都乘到独立样本batch里。环境wall-time / CPU内存 / verifier超时没有实测依据，当前为待冻结项。

GPU-hours是资源单位，不能在缺少单价时换成金额；“reserved”与“active”要选择固定口径并分别保留。固定128卡只给资源上限，没有墙钟时长就没有GPU-hours结果。Little定律与显存容量估算见容量与成本。

为什么工业规模不能省掉小范围协议校准？

如果样本映射或scorer错误，大规模RL只会更有效地放大坏reward。协议校准与模型集群是不同工作，CPU科学复算也不能由更多GPU替代。

如果D组比C组好，怎样才可以归因？

固定基模、任务来源、训练 / 推理预算、harness与verifier，分别改信用或采样；检查有效组、目标量和policy lag。一次同时改多项不能识别单个机制贡献。
