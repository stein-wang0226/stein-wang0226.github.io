把一次语言预测走成可检查的数据流

相关原论文 / 官方资料：Transformer。

decoder-only LLM 接收 token ID，经过多层表示变换，在每个位置输出下一个 token 的分布。训练把已知文本作为条件同时计算多个预测；推理把新生成 token 回填，继续下一步。理解两者共享哪些计算、保存哪些状态，是阅读新架构的起点。

先修：矩阵乘法、softmax 与链式法则。本文默认稠密、causal、pre-norm decoder；不含 cross-attention。原始 Transformer 是 encoder-decoder，本章的现代 decoder 示例依据固定 Llama 实现。[1][8]

  • 形状：\(B\)为序列数，\(S\)为长度，\(d\)为hidden size，\(V\)为词表大小。
  • 层内尺寸：\(H\)为query heads，\(d_h\)为head dimension，\(f\)为FFN宽度，\(L\)为block数；基础例取 \(d=Hd_h\)。
  • 矩阵约定：行向量，\(X\in\mathbb R^{B\times S\times d}\)右乘 \(W\in\mathbb R^{d\times d_{\rm out}}\)。

从 ID 到 logits：各步读写什么

对象形状/作用易错点
token ID[B,S] 整数；查 embedding 表整数大小不表示语义距离；token 不是单字/单词的固定单位
embeddingE[V,d] 是可训练参数；查表后得到 X查表产生的 X 是激活，不能和参数表的内存混算

单 head 的 score 是每个 query 对各个 key 的匹配强度，value 是实际被加权读取的内容。输出仍保留 S 个位置，Attention 没有把整句压成一个向量。FFN 在同一层逐位置共享参数；位置之间的新信息交换主要来自 token mixer。

Causal mask 决定允许使用的证据

本节固定一条序列、一个 head，省略 batch/head 轴：输入激活 \(X\in\mathbb R^{S\times d}\) 右乘三组可训练投影 \(W_Q,W_K,W_V\in\mathbb R^{d\times d_h}\)，其中 \(d_h\) 是该 head 的维度。\(Q,K,V_{\rm val}\in\mathbb R^{S\times d_h}\) 分别是 query、key、value；这里 \(V_{\rm val}\) 是 value 矩阵，不能与词表大小 \(V\) 混用。\(A\in\mathbb R^{S\times S}\) 是注意力概率，\(M\in\mathbb R^{S\times S}\) 是加性 mask，\(O\in\mathbb R^{S\times d_h}\) 是该 head 的输出，还未拼接 heads 或作输出投影。

\(i,j=0,\ldots,S-1\) 是零基位置索引：行 \(i\) 对应 query，列 \(j\) 对应 key。\(QK^\top\) 的每项是这对位置的内积 score，除以 \(\sqrt{d_h}\) 后加 \(M\)；softmax 对每个固定 \(i\) 沿 \(j\) 归一，允许访问的位置至少有一个。加性 \(M_{ij}=0\) 表示不改变 score，\(-\infty\) 表示屏蔽；下方另列的可见矩阵用 1 表示允许、0 表示屏蔽，不是可直接加到 score 的 \(M\)。

\[ Q=XW_Q,\quad K=XW_K,\quad V_{\rm val}=XW_V,\qquad A=\operatorname{softmax}_{j}\!\left(\frac{QK^\top}{\sqrt{d_h}}+M\right),\quad O=AV_{\rm val}. \]
\[ M_{ij}=\begin{cases}0&j\leq i\\-\infty&j>i\end{cases},\qquad \text{四位置的可见矩阵}= \begin{pmatrix}1&0&0&0\\1&1&0&0\\1&1&1&0\\1&1&1&1\end{pmatrix}. \]

逐步例：位置1只可读取位置0和1。若其两个可见score为[0,0]，softmax权重为[0.5,0.5]；两个value为[2,4]，输出为3。屏蔽位置即使value为100，也不进入加权和。Attention按key轴归一，不按query轴归一。

缩放抑制维度增加时内积尺度增长；它不能保证实际 Q/K 范数稳定。mask 沿 score 的最后一维控制可见 key。位置 i 看得到自身，是因为它要预测位置 i+1；若同时让它看到目标 token，就泄漏了答案。padding、文档边界、prefix-LM 和 FIM 的 mask 需要另外定义。[1] §3.2

实现中的布尔 mask 与浮点 mask

有的接口以 True 表示允许，有的表示屏蔽。浮点 mask 常以 0/负无穷相加；布尔张量的语义必须对照 API。整行没有可见 key 时 softmax 可能产生 NaN，padding query 的处理要和 loss mask 分开。packed 样本还要防止跨样本 attention。

科学 Agent 阅读实验说明时，上下文内的每个位置也受同样约束。能读到文本不代表具备文件权限、事实验证或完整长期记忆；这些由Harness和Agent 系统处理。

一个 block 如何保留旧表示并加入新信息

此处恢复 batch 轴：\(X\) 是本 block 的输入，\(U\) 是 Attention 支路输出与旧输入相加后的中间表示，\(Y\) 是 FFN 支路更新后的 block 输出，三者都是 \([B,S,d]\)。RMSNorm 逐位置沿 \(d\) 轴归一；Attention 包含各 head 的拼接与输出投影，FFN 也投影回 \(d\)，因此两处加号都是同形状逐元素相加。下一 block 接收 \(Y\)，第二个支路读取的是 \(U\)。

\[ U=X+\operatorname{Attention}(\operatorname{RMSNorm}(X)),\qquad Y=U+\operatorname{FFN}(\operatorname{RMSNorm}(U)),\quad X,U,Y\in\mathbb R^{B\times S\times d}. \]

加法要求形状一致。残差提供旧表示的直通路径，模块输出可改变表示；它不是绕过整个模型。Norm 控制进入模块的尺度，FFN 提供通道上的非线性容量。训练稳定性和 mHC 等前沿残差在残差与归一化章展开。

# 教学伪代码；行向量约定，不是完整可运行框架
x = embedding(ids)                         # [B,S,d]
for block in blocks:
    x = x + attention(norm1(x), mask, positions)
    x = x + mlp(norm2(x))
logits = final_norm(x) @ output_weight     # [B,S,V]
# embedding 与 output_weight 是否 tied 由模型配置决定

固定源码中的 LlamaDecoderLayer 依次执行 input_layernorm、self_attn、第一次 residual、post_attention_layernorm、MLP 和第二次 residual。可以按函数名对应上述式子；post_attention_layernorm 的名称不代表整个 block 使用 Post-Norm。[8] L268起

Teacher forcing、shift 与目标 mask

相关原论文 / 官方资料：Transformer。

训练样本中的历史来自真实数据，称为 teacher forcing；并不意味着每步调用一个外部教师模型。causal mask 让多个位置可以同时训练，反向传播仍跨层和允许的历史路径。推理阶段历史来自模型自身，因此错误会进入后续条件分布。

输入 tokens： [BOS, 读取, 文件, EOS]
位置 logits：    0     1     2    3
监督配对：    logits[0]→读取，logits[1]→文件，logits[2]→EOS
loss = CE(logits[:, :-1], labels[:, 1:])
# API 内部已 shift 时，调用者不要再 shift
# labels 与 attention_mask、loss_mask 的含义各不相同

先从一条序列的条件概率开始：\(x_{1:S}\) 是长度 \(S\) 的真实 token 序列，\(x_i\) 是第 \(i\) 个目标，\(x_{<i}\) 是其之前的真实前缀；\(p_\theta\) 是参数 \(\theta\) 定义的概率模型。这里目标位置 \(i=1,\ldots,S\) 使用一基记号，与 mask 节的零基 query 位置不同；代码中的 logits 位置须按 shift 对齐。链式法则将联合概率拆为条件概率乘积，\(\prod\) 表示连乘，log 是自然对数；\(\ell_i\) 是单目标负 log-prob，单位为 nat。

扩展到 batch，\(b=1,\ldots,B\) 索引序列，\(x_{b,i}\) 与 \(\ell_{b,i}\) 是该序列的目标和单目标损失。固定 \(m_{b,i}\in\{0,1\}\) 表示是否监督这个目标，分母 \(N_{\rm valid}=\sum_{b,i}m_{b,i}>0\) 是有效目标数，不是输入 token 总数。\(L\) 是有效目标的平均标量损失；它与前文表示 block 层数的 \(L\) 重名，仅在本节表示损失。以下对全部已对齐的 batch/目标位置求和：

\[ \begin{aligned} p_\theta(x_{1:S})&=\prod_{i=1}^{S}p_\theta(x_i\mid x_{<i}),\\ \ell_i&=-\log p_\theta(x_i\mid x_{<i}),\\ -\log p_\theta(x_{1:S})&=\sum_{i=1}^{S}\ell_i,\\ \ell_{b,i}&=-\log p_\theta(x_{b,i}\mid x_{b,<i}),\\ L&=\frac{\sum_{b,i}m_{b,i}\ell_{b,i}}{\sum_{b,i}m_{b,i}}. \end{aligned} \]

下面固定一个已对齐目标位置，\(z\in\mathbb R^V\) 是词表 logits 向量，\(z_j\) 是词表项 \(j\) 的分数，\(p_j\) 是其归一概率，\(y\) 是正确目标 ID，\(\ell\) 是单 token 损失。\(j,k=0,\ldots,V-1\) 都遍历词表，\(k\) 仅作分母求和索引；它们不再是 query/key 位置。softmax 沿词表轴归一，\(e\) 是自然常数；\(\mathbf1[j=y]\) 在目标项为1，其余为0。恢复 batch/位置下标后，\(z_{b,i,j},p_{b,i,j}\) 分别是该位置的词表分数与概率，\(y_{b,i}\) 是正确目标 ID；以下偏导固定 mask，并把各位置 logits 当作独立变量，不是模型参数 \(\theta\) 的总梯度。

logits \(z\) 经softmax得 \(p_j=e^{z_j}/\sum_k e^{z_k}\)。正确目标为 \(y\) 时，单token损失 \(\ell=-\log p_y=-z_y+\log\sum_k e^{z_k}\)，其梯度为 \(\partial\ell/\partial z_j=p_j-\mathbf1[j=y]\)。对上面的平均损失，有 \(\partial L/\partial z_{b,i,j}=(m_{b,i}/N_{\rm valid})(p_{b,i,j}-\mathbf1[j=y_{b,i}])\)。被mask位置的直接logit梯度为0，但它仍可作为后续目标的条件。这把“提高目标概率”接回可计算的梯度。

可复算例：三个监督目标概率为[0.5,0.25,0.5]，平均NLL为 \((\log2+\log4+\log2)/3\approx0.9242\)。若中间目标的mask为0，分子和分母同时移除它，损失为 \(\log2\approx0.6931\)；条件历史仍包含该token。有效目标数为0的batch需要显式跳过或拒绝，不能直接除以0。

mask 掉用户输入的 loss 仍需要读取它，并可通过它提供的条件影响后续目标。SFT 常只监督 assistant 的动作或输出；CPT 文档通常监督更多位置。loss mask 不能充当访问权限，也不能阻断所有相关前向计算。详见CPT 数据与 mask。

四类状态决定四种不同成本

相关原论文 / 官方资料：SwiGLU；PyTorch FSDP API。

类别生命周期主要数量因子
参数跨请求共享，训练会更新矩阵形状、层数、专家数；tied 参数只计一次
训练激活用于本次 backward，或通过重计算恢复batch、序列、hidden、保存策略
请求 KV/递归状态跟随特定历史与权重版本KV heads、长度、层数、精度；递归状态另算
梯度与优化器训练更新与恢复使用可训练参数、状态精度、分片策略

相同权重可以服务很多请求，每个请求通常有自己的历史状态。KV 来自当前权重对指定 token 的计算，不能在权重改变后无条件复用。训练常关闭增量 cache；训练的内存压力也不能直接由推理 KV 推出。

忽略 bias/Norm，MHA Attention 约 4d² 参数；普通两矩阵 FFN 为 2df，三矩阵 SwiGLU 为 3df。总量再乘实际层数、加入 embedding/head 与其他模块。这是规格推导；不同 head dimension、共享权重和 MoE 会改变公式。

先检查不变量，再设计性能对照

  • 因果与边界：修改未来token不改变此前logits；packed样本不可跨边界读取。
  • 对齐：shift只执行一次；padding不计目标；attention mask与loss mask分别检查。
  • 实现一致性：关闭dropout，对比full forward和逐步KV解码，记录精度与允许误差。

以上是待执行的模型检查协议；本轮仅验证博客内容与排版。

任务评测要另看 held-out loss、生成质量、工具格式、长依赖和科学任务成功率。低 CE 不等于统计设计正确。以科学 Harbor 任务为例，模型既要生成合法脚本，也要保留配对供体和正确 contrast；最终由独立 verifier 验收。

自测：为什么训练同时预测，推理仍逐 token？

训练已经知道每个位置的历史，mask 可以并行计算所有条件预测。推理时下一个输入取决于本步采样结果，普通 AR 生成的这条依赖不能靠 batch 消除。投机解码通过候选与验证改变执行方式，但目标分布保持需要额外条件。
