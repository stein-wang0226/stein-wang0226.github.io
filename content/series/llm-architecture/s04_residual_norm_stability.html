读式约定：\(F\) 是 Attention/FFN 等残差分支，\(N\) 是归一化函数；\(J_F,J_N\) 是输出对输入的 Jacobian，\(I\) 是单位矩阵，\(\nabla_x L\) 是损失对表示的梯度。层号用 \(\ell\)，\(x_0,x_L\) 为首末层表示；\({}^\top\) 为转置。Norm 式的 \(g,b\) 是逐维可训练缩放和偏置，\(\varepsilon\) 为防止除零的常数，\(\odot\) 为逐元素乘法。

稳定性来自一条完整数值路径

相关原论文 / 官方资料：Transformer。

深层网络既要传递表示，也要把梯度送回前层。残差、Norm、初始化和优化器共同控制尺度；任一机制的局部性质都不能独立保证大模型训练稳定。前沿残差改变信息读取方式，需要连同激活保存、通信和数值误差评估。

先修：decoder block与链式法则。基础结论来自归一化论文和固定实现，前沿机制的具体报告见本主题的前沿残差机制。

Pre-Norm 与 Post-Norm 的梯度路径

相关原论文 / 官方资料：LayerNorm。

固定单 token，\(x,y_{\rm pre},y_{\rm post}\in\mathbb R^d\) 是输入和两种替代布局的输出列向量，\(d\) 为隐藏维度；\(N,F\) 都保持此维度。\(J_F,J_N,J_{\rm pre},J_{\rm post}\in\mathbb R^{d\times d}\) 分别为函数输出对输入的局部 Jacobian，括号注明求值的输入点，\(I\) 为 \(d\times d\) 单位矩阵。按链式法则，Pre-Norm先归一再进入F，而直接相加的x导数为单位矩阵；Post-Norm对相加后的所有分支再作用同一个Norm Jacobian。

\[ \begin{aligned} y_{\rm pre}&=x+F(N(x)),\\ J_{\rm pre}&=I+J_F(N(x))J_N(x),\\ y_{\rm post}&=N(x+F(x)),\\ J_{\rm post}&=J_N(x+F(x))(I+J_F(x)). \end{aligned} \]

深度递推中 \(\ell=0,\ldots,L-1\) 索引残差子层，\(x_\ell\) 是入表示，\(J_\ell=\partial x_{\ell+1}/\partial x_\ell\)；\(x_0,x_L\) 是首末表示。原式沿用 \(L\) 同时记总层数和标量损失：下标/乘积端点中的 \(L\) 是层数，\(\nabla_x L\) 中的 \(L\) 是损失。方向例中的 \(c,a\) 是标量，\(\mathbf1\in\mathbb R^d\) 是全1向量。

\[ \nabla_{x_\ell}L=J_\ell^\top\nabla_{x_{\ell+1}}L,\qquad \frac{\partial x_L}{\partial x_0}=J_{L-1}\cdots J_1J_0. \]

方向例：LayerNorm对所有分量同时加常数不敏感，\(N(x+c\mathbf1)=N(x)\)，所以 \(J_N(x)\mathbf1=0\)。Pre-Norm中该方向仍可经显式残差传播。取 \(F(x)=ax\)，Post-Norm的输入均值方向则经Norm被消去。它解释路径差异，不意味着任意损失、方向或完整网络都不衰减。

Pre-Norm 的残差分支给出了显式 I 路径，但完整 Jacobian 仍可能因其它项放大/衰减。Post-Norm 的所有路径经过 Norm 的 Jacobian。Xiong 等在均值场与初始化条件下分析了输出附近梯度和 warm-up，并报告其任务中的 Pre-LN 实验；不能推成“所有 Pre-Norm 都不需要 warm-up”。[6] On Layer Normalization

现代模型可能采用 residual scaling、额外 Norm、深度相关初始化、多路残差与融合 kernel。阅读 config 时需找出真实的运算顺序，不能只按参数名称判断。

RMSNorm 保留均值，主要调整幅度

相关原论文 / 官方资料：RMSNorm。

\(i=1,\ldots,d\) 遍历单个 token 的隐藏坐标，\(x_i\) 是其分量；\(\mu,\sigma^2\) 是沿这 \(d\) 个坐标求出的均值和总体方差，分母为 \(d\)，不是 batch 数或样本方差的 \(d-1\)。\(g,b\in\mathbb R^d\) 是逐维缩放/偏置，\(\mathbf1\) 是全1向量，\(\varepsilon>0\) 与平方统计量同尺度。LN 表示 LayerNorm；RMSNorm 不减均值，只按坐标平方均值缩放。

\[ \mu=\frac1d\sum_i x_i,\quad \sigma^2=\frac1d\sum_i(x_i-\mu)^2,\qquad \operatorname{LN}(x)=g\odot\frac{x-\mu\mathbf1}{\sqrt{\sigma^2+\varepsilon}}+b,\quad \operatorname{RMSNorm}(x)=g\odot\frac{x}{\sqrt{\frac1d\sum_i x_i^2+\varepsilon}}. \]

数值例：\(x=[1,3]\)，取scale=1、bias=0，教学例忽略epsilon。LN均值2、方差1，输出[−1,1]；RMS的平方均值5，输出约[0.4472,1.3416]。两者都规范幅度，只有LN显式中心化。实际epsilon必须保留以处理零向量。

RMSNorm 不显式减均值，计算较简洁；它不是 BatchNorm，也不意味着所有激活标准正态。ε、γ、统计累积精度和输出精度都影响行为。固定 Llama 源码先转 FP32、求平方均值、用 rsqrt，再转回输入 dtype；这说明低精度主干仍可能保留高精度统计。[6] RMSNorm[8] L53–67

# 摘录自固定 Transformers v4.57.1 LlamaRMSNorm；Apache-2.0
input_dtype = hidden_states.dtype
hidden_states = hidden_states.to(torch.float32)
variance = hidden_states.pow(2).mean(-1, keepdim=True)
hidden_states = hidden_states * torch.rsqrt(variance + self.variance_epsilon)
return self.weight * hidden_states.to(input_dtype)

机制选择/混合的轴需要保存不能由名称推出

AttnRes 对此前层表示进行加权读取；full 与 block 版本在历史状态保存上不同。mHC 约束 residual mixing 为近似双随机矩阵：理想矩阵是置换的凸组合，谱范数不超过 1；它只控制该混合部分，F、pre/post 路径和有限次 Sinkhorn 的误差仍存在。原式、固定来源与 Single-Pass 实现口径见机制证据页。

因此本文分析建议：既看 gradient/loss，也看保存激活、重算、PP 传输和约束误差；不能把减少某个映射的 traffic 改写成整个训练时间同比下降。
