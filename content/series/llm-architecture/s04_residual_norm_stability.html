稳定性来自一条完整数值路径

深层网络既要传递表示，也要把梯度送回前层。残差、Norm、初始化和优化器共同控制尺度；任一机制的局部性质都不能独立保证大模型训练稳定。前沿残差改变信息读取方式，需要连同激活保存、通信和数值误差评估。

先修：decoder block与链式法则。基础结论来自归一化论文和固定实现，前沿机制的具体报告见研究地图第07章。

Pre-Norm 与 Post-Norm 的梯度路径

Pre-Norm：y = x + F(N(x)) ∂y/∂x = I + J_F(N(x)) J_N(x) Post-Norm：y = N(x + F(x)) ∂y/∂x = J_N(x+F(x)) [I + J_F(x)] 深层反向传播包含各层 Jacobian 的连乘

Pre-Norm 的残差分支给出了显式 I 路径，但完整 Jacobian 仍可能因其它项放大/衰减。Post-Norm 的所有路径经过 Norm 的 Jacobian。Xiong 等在均值场与初始化条件下分析了输出附近梯度和 warm-up，并报告其任务中的 Pre-LN 实验；不能推成“所有 Pre-Norm 都不需要 warm-up”。[6] On Layer Normalization

现代模型可能采用 residual scaling、额外 Norm、深度相关初始化、多路残差与融合 kernel。阅读 config 时需找出真实的运算顺序，不能只按参数名称判断。

RMSNorm 保留均值，主要调整幅度

LayerNorm(x) = γ ⊙ (x−mean(x))/√(var(x)+ε) + β RMSNorm(x) = γ ⊙ x/√(mean(x²)+ε) 归一化轴通常是单个 token 的 hidden 维度；不是 batch 统计

RMSNorm 不显式减均值，计算较简洁；它不是 BatchNorm，也不意味着所有激活标准正态。ε、γ、统计累积精度和输出精度都影响行为。固定 Llama 源码先转 FP32、求平方均值、用 rsqrt，再转回输入 dtype；这说明低精度主干仍可能保留高精度统计。[6] RMSNorm[8] L53–67

# 摘录自固定 Transformers v4.57.1 LlamaRMSNorm；Apache-2.0
input_dtype = hidden_states.dtype
hidden_states = hidden_states.to(torch.float32)
variance = hidden_states.pow(2).mean(-1, keepdim=True)
hidden_states = hidden_states * torch.rsqrt(variance + self.variance_epsilon)
return self.weight * hidden_states.to(input_dtype)

AttnRes 与 mHC 读取不同对象

机制选择/混合的轴需要保存不能由名称推出
普通残差当前流固定相加当前表示与反向所需激活不需要梯度/尺度管理
Attention Residuals历史层/深度表示full 或 block 历史摘要替代 token Attention 或检索全部历史 token
mHC多路残差之间的映射多路流与映射信息整个非线性网络天然不爆梯度
Gated Residual模型定义的元素/流门控对应多路状态与 gate和双随机约束或深度 softmax 等价

AttnRes 对此前层表示进行加权读取；full 与 block 版本在历史状态保存上不同。mHC 约束 residual mixing 为近似双随机矩阵：理想矩阵是置换的凸组合，谱范数不超过 1；它只控制该混合部分，F、pre/post 路径和有限次 Sinkhorn 的误差仍存在。原式、固定来源与 Single-Pass 实现口径见机制证据页。

因此本文分析建议：既看 gradient/loss，也看保存激活、重算、PP 传输和约束误差；不能把减少某个映射的 traffic 改写成整个训练时间同比下降。

把结构、配方和故障来源拆开对照

先固定数据、token、主干和精度，再分别改变 Norm/残差；各方案需要有合理学习率与初始化，而不是用未经调参的单点证明胜负。等 token 与等总计算预算都要记录。对深度选择机制还要测激活占用、重算与 optimizer step 时间；此处为待执行设计。

一次 loss spike 的归因可沿“样本/mask → 逐层激活 → QK/gate → 梯度 → optimizer → 通信/恢复”排查。坏数据、数值溢出和同步错误产生的表象相似；恢复 checkpoint 时要保留 optimizer、scheduler、RNG 与数据游标，避免换状态后将不可比结果当作修复成功。

自测：RMSNorm 为什么不能消除所有训练不稳定？

它主要规范局部输入尺度，没有固定所有矩阵范数、QK 最大值、非线性 Jacobian、optimizer 更新和数据分布。它是配方的一部分，局部归一化不等于全网稳定证明。
