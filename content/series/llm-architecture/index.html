先理解模型怎样计算，再理解新结构改变什么

相关原论文 / 官方资料：Transformer。

LLM 架构可以拆成六个问题：token 怎样成为表示，位置之间怎样交换信息，每个位置怎样做非线性变换，信息怎样穿过深度，历史怎样保存，以及这些选择怎样影响训练和服务。本系列从可追踪的张量出发，逐步连接最新公开机制。

  • 先完整算一遍：Transformer 前向推导按 embedding → Norm → Attention → FFN → logits / loss 展开，再对照 prefill 与缓存解码。
  • 再拆开理解：Attention缩放/RoPE→FFN/MoE→残差梯度→递归状态。
  • 最后比较前沿：残差流与LatentMoE→DeepSeek/Qwen/Kimi等家族→DeepSeek缓存账本，都在本页继续阅读。
  • 先修：矩阵乘法、概率与反向传播；每个算例先列输入和假设，再展示中间量、输出及检查。

读完应能做到

  • 解释计算：说出一个block的输入输出、mask、shift与四类状态。
  • 写出推导：Attention尺度、RoPE相对位置、残差Jacobian与外积/delta更新。
  • 比较机制：分开参数、激活、KV/state、派发通信与服务等待。
  • 判断证据：区分规格推导、作者实验、受控消融与独立复现。
