历史保存、历史选择与计算实现分别优化什么

相关原论文 / 官方资料：GQA；MQA；FlashAttention；PagedAttention。

Attention 的查询仍是“当前位置读哪些历史表示”。MHA/MQA/GQA 改变 query 与 KV 的共享关系；MLA 压缩历史表示；SWA/稀疏检索限制读取集合；FlashAttention 改变精确计算的 IO；PagedAttention 改变状态分配。这些可以组合，但不产生同一种复杂度或质量保证。

先修：QKV 与 causal mask。本文 B 为并发序列数、T 为保存的历史 token 数、L 为采用该机制的层数、Hq/Hkv 为 query/KV heads、dh 为每个 K/V head 的宽度。K/V 宽度相同只是本节基础假设。

为什么点积要除以 \(\sqrt{d_h}\)

本节 \(q,k\in\mathbb R^{d_h}\) 是单头 query/key 列向量，\(\ell=1,\ldots,d_h\) 索引分量，\(s\) 是内积 score，\({}^\top\) 为转置，Var 表示方差。随后 softmax 的 \(s_j,p_i\) 分别是候选 \(j\) 的 score 和候选 \(i\) 的概率，\(i,j\) 遍历同一候选 key 集合，归一轴是候选轴；Jacobian 是概率对这些 score 的偏导，\(\mathbf1[i=j]\) 是相等指示。

先用可计算的近似解释尺度：假设query和key各分量独立、均值0、方差1，且两者相互独立。每项 \(q_\ell k_\ell\) 的均值为0、方差为1；求和 \(d_h\) 项的方差变成 \(d_h\)。

\[ s=q^\top k=\sum_{\ell=1}^{d_h}q_\ell k_\ell,\qquad \operatorname{Var}(s)=d_h,\qquad \operatorname{Var}\!\left(\frac{s}{\sqrt{d_h}}\right)=1. \]

未缩放的score会随维度变大，使softmax更尖。其Jacobian为 \(\partial p_i/\partial s_j=p_i(\mathbf1[i=j]-p_j)\)，接近0/1的概率会让许多导数变小。缩放缓解该初始化尺度问题；真实Q/K不一定独立或单位方差，还需Norm、初始化与数值监控。

后面的 RoPE 段落用 \(p\) 表示位置，不再表示 softmax 概率，并在该段重新定义。

两候选例：\(d_h=4\)，score为[2,0]。未缩放权重为[0.8808,0.1192]；除以2后为[0.7311,0.2689]。value为[2,4]时输出分别约2.2384、2.5379。缩放改变读取分布，不能省略后再声称与原Attention等价。[1] §3.2

MHA、MQA、GQA：写入头和读取头可以不同

相关原论文 / 官方资料：RoPE；GQA；MQA。

机制共享关系KV 存储/投影边界
MHAHkv=Hq，每个 query 对应一组 KV独立 KV 较多表达容量与内存都较大
MQAHkv=1，所有 query 共享一组 KVKV 存储显著减少query 仍多头；质量影响取决于训练
GQA1<Hkv<Hq，每组 query 共享 KV在 MHA/MQA 之间折中checkpoint 转换通常需 uptraining
MLA保存 latent KV 与位置相关分量，再恢复/吸收投影依 latent、RoPE 与实现算字节不能套用单一 Hkv 缩减比

MQA 和 GQA 原论文讨论了内存带宽与质量取舍，GQA 包含从 MHA checkpoint uptraining 的配方；它们没有证明任意模型减少 head 都无损。固定 Llama 源码中 Q 投影到 Hq·dh、K/V 投影到 Hkv·dh；eager 路径的 repeat_kv 为计算展开 head，不意味着持久缓存也必须保存展开后的副本。[2][8] L159–220

从形状推导缓存字节

相关原论文 / 官方资料：RoPE。

每层的K为 \([B,T,H_{\rm kv},d_K]\)，V为 \([B,T,H_{\rm kv},d_V]\)，\(d_K,d_V\) 分别为 key/value 的每头宽度。\(M_{\rm KV}\) 是全部 \(B\) 条等长历史、\(L\) 层的缓存总字节，不是 attention mask；\(b\) 是 byte/元素，区别于并发序列数 \(B\)。元素数分别乘每值字节 \(b\)，再累加层数；\(M_{\rm KV}/(BT)\) 是每条序列每个历史 token 的 byte/token。宽度相同时得到熟悉的系数2：

\[ \begin{aligned} M_{\rm KV}&=BTLH_{\rm kv}(d_K+d_V)b,\\ M_{\rm KV}&=2BTLH_{\rm kv}d_hb\quad(d_K=d_V=d_h),\\ \frac{M_{\rm KV}}{BT}&=2LH_{\rm kv}d_hb. \end{aligned} \]

小形状例：单请求、3个token、2层、2个KV头、每头宽4、每值2B，则K与V各有48个元素，各96B，总192B。query头数量不直接出现在持久KV式中，已经由KV共享关系决定。

这是状态容量推导，排除分页、workspace、权重和复制；TP的本地布局也可能复制KV头。70B/32K及GB/GiB的完整预算放在服务容量章统一维护。

长上下文不同机制要逐层加总：full KV 随 T 增长，SWA 可按实现截到 window，recursive state 按 state shape 算；训练 SWA 并不保证服务只分配 window 大小。量化还要加 scale、零点、对齐和高精度例外。容量表和完整预算见部署第03章。

MLA 的关键是保存比完整多头 KV 更窄的 latent；RoPE 的位置相关部分常需单独处理，以免破坏投影吸收。DeepSeek V4.1 又使用 CED、CSA2 与缓存共享，其报告的 890 B/token 属于特定压缩/组共享口径，不是所有 MLA 的常数。V4.1 分项推导与排除项保留为具体案例。

RoPE 让内积包含相对位移

相关原论文 / 官方资料：RoPE。

将head的分量两两配对。对其中一对使用频率 \(\omega\)，位置 \(p\) 对应角度 \(p\omega\)。二维旋转保持长度，旋转矩阵的转置等于反向旋转；两次旋转的角度可以相加。

以下 \(q_i,k_j\) 只取一个二维分量对，\(i,j\) 是 token 的逻辑位置；\(\omega\) 的单位是弧度/位置，\(\alpha,\beta\) 是旋转角度，\(R\) 是 \(2\times2\) 旋转矩阵。撇号表示旋转后的向量，\(j-i\) 是相对位移；这里的 \(\alpha,\beta\) 与优化器参数无关。

\[ R(\alpha)=\begin{pmatrix}\cos\alpha&-\sin\alpha\\\sin\alpha&\cos\alpha\end{pmatrix}, \]
\[ \begin{aligned} R(\alpha)^\top&=R(-\alpha),\\ R(\alpha)R(\beta)&=R(\alpha+\beta). \end{aligned} \]
\[ \begin{aligned} q'_i&=R(i\omega)q_i,\quad k'_j=R(j\omega)k_j,\\ (q'_i)^\top k'_j&=q_i^\top R(-i\omega)R(j\omega)k_j\\ &=q_i^\top R((j-i)\omega)k_j. \end{aligned} \]

数值例：令 \(q=k=(1,0)^\top,\omega=\pi/2\)。相同位置的旋转后内积为1；相差一个位置为0；相差两个位置为−1。将两个位置一起平移一个位置，差值不变，内积仍相同。实际head使用多组频率，不能由这一个周期例子推出任意长距离无损外推。

旋转本身编码绝对位置，QK 内积中的相对旋转取决于 j−i。多频率二维对子让模型处理不同距离；通常作用于 Q/K，不能笼统说把位置向量加到所有输入。不同实现的 interleaving、partial rotary、频率与 scaling 必须与 checkpoint 一致。[3]

把最大位置调大只允许计算更长位置；未见过的频率/距离仍会产生分布变化。插值、频率缩放与长上下文训练解决不同问题。长上下文验收应包含位置敏感检索、多针冲突、依赖链和真实任务，不能只用一个 needle 成功率证明普遍能力。

Cache position 与逻辑 position 为什么要分开？

cache_position 决定状态写到哪里，position_ids 决定位置编码。padding、prefix 复用、分页、截断和 SWA 可能使物理槽位与逻辑位置不同。复用相同 token prefix 还要求 position、mask、adapter、权重和精度兼容。

局部窗口与稀疏检索改变可见历史

路线每步主要读取保留什么需验证的能力
Full attention所有允许历史通常完整 KV精确多项召回与 O(T) decode 访问
SWA附近 window局部 KV；可能另有全局层/sink远程信息能否通过混合层传递
稀疏 indexer选出的 top-k 历史/压缩块候选索引与被查询表示indexer 漏召回、选择成本与梯度
压缩历史摘要/latent/压缩块压缩 state 或 KV不可逆信息损失与恢复机制

少读历史不等于少存历史；索引仍可能依赖完整候选状态。局部层与全局层交替也不能简单按局部比例推算端到端速度。新架构的 indexer、压缩组与层计划应回到固定模型配置，分别核算。

FlashAttention 和 PagedAttention 的优化对象

相关原论文 / 官方资料：FlashAttention；PagedAttention；SGLang / RadixAttention；vLLM official docs。

FlashAttention 通过分块和 online softmax 在 SRAM 中累积输出，避免将大规模 score/概率矩阵反复写入 HBM；原算法保留 dense softmax attention 的数学计算。它没有把 full attention 变成线性计算，也不能自动缩小所有 KV。不同融合顺序与浮点格式仍可能导致数值差异。[4]

完整分块算例：不保存全部权重，怎样得到同一个输出

输入：一个宽度1的query \(q=1\)，三个允许读取的key为 \((0,\log2,\log4)\)，value为 \((1,2,4)\)；\(\sqrt{d_h}=1\)，所以score就是key值。本例只演示单query的online softmax，未运行GPU kernel。

整行计算的权重为 \((1,2,4)/7\)，输出 \((1+4+16)/7=3\)。现在把前两个候选放进第一块，最后一个放进第二块。维护三个累计量：最大score \(m\)、相对该最大值的指数和 \(\ell\)、加权value和 \(n\)，最终输出 \(n/\ell\)。这里 \(m\) 是数值稳定用的最大值，区别于loss mask。

更新式中 \(J\) 是本次新块的候选索引集合，\(j\) 遍历其中的 key，\(s_j,v_j\) 是该候选的 score/value；撇号表示更新后的累计量。\(a\) 是旧基准到新最大值基准的指数缩放系数。多维 value 时 \(n,n'\) 是同维向量，本例是标量；至少一个有限可见 score 才能得到正的 \(\ell\) 并最终归一。

\[ \begin{aligned} m'&=\max(m,\max_{j\in J}s_j),\quad a=e^{m-m'},\\ \ell'&=a\ell+\sum_{j\in J}e^{s_j-m'},\\ n'&=an+\sum_{j\in J}e^{s_j-m'}v_j. \end{aligned} \]
处理阶段最大值 \(m\)指数和 \(\ell\)加权和 \(n\)
第一块：(0,log2)log21/2+1=3/2(1/2)×1+1×2=5/2
第二块：log4；旧量缩放1/2log4(1/2)×(3/2)+1=7/4(1/2)×(5/2)+4=21/4
最终归一化不再更新\((21/4)/(7/4)=3\)，与整行计算一致

可复核点：换最大值时必须同时缩放 \(\ell\) 和 \(n\)，不能把两块分别softmax后直接平均。分块省去了完整score/概率矩阵的持久写回，所有允许的QK与AV计算仍要执行；数学等价也不要求不同浮点kernel逐bit相同。

PagedAttention 把逻辑 KV 映射到非连续物理块，改善变长请求的碎片与共享；prefix cache 再复用兼容前缀的计算。存储分页不改变 causal mask，命中前缀也没有降低从零 prefill 的内在计算。具体 vLLM/SGLang 调度和源码在部署第01章维护。

判断一个“提速”：先写清它改变的是算术次数、HBM IO、持久状态、物理碎片、共享命中、网络传输还是调度等待，再比较相同模型、精度、长度和负载。

对照方案与自测

相关原论文 / 官方资料：GQA。

本文建议：固定 checkpoint 时先比较 full forward/KV 解码的一致性，再测同长度同并发的 TTFT、ITL 和峰值内存。改变 MHA/GQA 或窗口属于结构变更，应单独训练或使用有依据的转换配方；不可把未适配模型的质量下降当成机制本身上限。所有这些对照尚未执行。

自测：为什么 GQA 省 KV，却不把全部 Attention 计算同比减少？

query head 仍有 Hq 个，每个仍要与允许的历史计算 score 并聚合 value。K/V 投影与保存量减少，读取可以共享，但 softmax/query 计算、输出投影与 FFN 仍存在；最终收益还受 kernel 和带宽限制。

自测：RoPE为什么有相对位置性质，仍需要长上下文训练？

相对性质来自旋转矩阵乘积，说明内积如何依赖位移；更长位移对应训练外的频率/距离组合，正确代数不保证模型在新分布上的质量。
