阶段角色：先得到能够执行协议的策略

SFT 的交付目标是稳定行为。Base 可能知道过滤 CSV 的代码，却不会稳定遵循工具 schema、检查产物或在错误后恢复。行为训练把知识转成可执行动作；反馈来源和更新参数方式是两个不同维度。

RFT 要写全名：Rejection sampling Fine-Tuning 是筛选后做监督学习；Reinforcement fine-tuning 是 grader 驱动的强化学习。两者不能仅凭缩写混用。[24] [25]

角色 mask：不拟合观察，仍利用观察

user: Clean sample.csv and write out.csv.          # context
assistant: inspect_csv(path="sample.csv")           # target
tool: 3 rows, 1 empty value                         # context
assistant: filter_csv(input="sample.csv",
                      output="out.csv")            # target
tool: Wrote 2 rows to out.csv                       # context
assistant: Cleaned CSV written to out.csv.          # target

设序列为 \(x_{1:T}\)，\(m_t=1\) 表示该位置是需要学习的 assistant 输出，\(m_t=0\) 表示只作条件或 padding。本例保留工具输出参与后续预测，损失为：

\[ L_{\mathrm{SFT}}=-\frac{\sum_{t=1}^{T}m_t\log p_\theta(x_t\mid x_{<t})}{\sum_t m_t}. \]

把后续动作隐藏状态写成 \(h_t=f_\theta(x_{<t})\)，动作损失 \(\ell_t=-\log p_\theta(x_t\mid h_t)\) 的梯度仍含：

\[ \nabla_\theta\ell_t =\left.\partial_\theta\ell_t\right|_{h_t} +(\partial_\theta h_t)^\top\nabla_{h_t}\ell_t. \]

\(\theta\) 为模型参数，\(t\) 为预测位置，\(x_{\lt t}\) 为其前缀；\(h_t\) 在此是由模型算出的隐藏表示。\(\partial_\theta\ell_t|_{h_t}\) 固定该表示只对输出分支求导，第二项通过表示生成链路反传；\(\partial_\theta h_t\) 是表示对参数的 Jacobian，转置后把表示梯度映射回参数空间。

算例：两个观察 token 的 mask 都为0，后面两个动作 token 的概率分别为0.5、0.25，则平均 loss 为 \(-(\log0.5+\log0.25)/2\approx1.040\)。模型需要根据观察决定过滤条件；移除观察、更改 Attention 或对中间状态 detach 会改变这条计算链，单独设置目标 mask 不会。

片段保留为条件本例监督准入检查
system/user/schema是否模板与推理一致
assistant 调用/参数是是工具可执行、参数合法
stdout/error是否真实输出、关键错误未截断
recovery/final是按动作质量筛选恢复有效，完成声明符合产物
reward/隐藏答案否否只留在审计与 evaluator

该 mask 是教学选择。Midtraining 也可以用相同 token loss；阶段区别还在数据分布、训练预算和 checkpoint 用途，不能从 loss 名称反推阶段。

轨迹准入：最终成功不等于每个动作都值得模仿

  • 保留真实错误条件：失败观察可帮助学习恢复；过度筛掉它们只剩理想流程。
  • 筛选动作目标：最终成功前的误删、乱试或规则绕过不应自动成为正例。分别登记“保留的上下文”和“监督的动作”。GLM-5 公开了动作回合筛选。[3]
  • 重放与去重：固定环境检查工具、文件、停止条件；按任务族、仓库、难度和轨迹簇控制重复。
  • 继承来源切分：同仓库、同解法、教师来源与近重复簇隔离，不能在末端随机逐条切分。
  • 检查截断：目标、观察、结束标记分开计数；长样本不能把“未完成”学成“完成”。

Qwen3-Coder-Next 的验证轨迹与跨 scaffold 实验提醒我们，数据质量和执行协议覆盖要一起管理。训练 loss 降低后，仍须在未见错误恢复任务上验证。[2]

拒绝采样：把搜索得到的可靠路径转成标签

覆盖反例：10个易题各采样10次、每题9次成功；10个难题各采样10次、每题1次成功。留下全部成功候选后，两类原任务各占50%，训练轨迹却变成90%易题。可按任务配额采样，并报告被丢弃路径和总采样成本。

DeepSeek-R1 的路径是 cold-start SFT → 推理 RL → 拒绝采样及其他数据 SFT → 后续 RL；R1-Zero 展示 Base 直接 RL 的另一分支。SFT 可以出现在 RL 后。[13]

偏好与教师阶段：交接反馈接口

  • 偏好对：chosen/rejected 必须来自同任务、可比较的条件。CSV 标签依据文件结果；口吻自信不构成正确性。
  • 离线蒸馏：教师预先写好的答案或轨迹可直接进监督池。
  • OPD：先取得学生状态，再向教师请求同 prefix 的分布或评分。完整词表 KL 需要兼容词表及概率；最终答案 API 或少量 top logprobs 不能冒充完整分布。
  • 能力回归：多教师要定义任务路由、冲突与支持范围，检查合并学生的旧能力和教师调用成本。

DPO 的完整推导在后训练偏好节；OPD 的局部梯度与 V4/Ultra 信号分歧在教师主讲节。这里的任务是确认接口与阶段产物，而后继续看本页的训练交接。
