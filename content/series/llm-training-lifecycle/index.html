先看链路：能力、行为与反馈如何接起来

预训练获得通用知识和生成先验；CPT／Midtraining 调整领域、结构与交互分布；SFT 让模型模仿可靠行为；RL 通过实际结果改进决策。每一步都要说明起始权重、输入数据、优化目标、输出 checkpoint 和验收条件。

最关键的术语修正：CPT 描述“从已有权重继续训练”，Midtraining 描述训练链路中的准备阶段，SFT 描述监督训练方法。Midtraining 内可以对 trace 使用 assistant-only loss；看到相同 loss，不能推断它们是同一阶段。RFT 则必须写全名：拒绝采样微调与强化微调是两种方法。
  • 原理：目标与 mask→数据混合权重→轨迹准入→反馈/验收→LoRA、AdamW、Muon与分片。
  • 复习：先能区分输入 token、目标 token、更新次数与实际成本；再用各节算例和诊断表检查理解。
  • 先修：因果 LM、矩阵乘法与反向传播；必要推导在本页展开。

训练知识地图：阶段是一条轴，技术是另一条轴

顺着阶段读，理解数据和目标怎样变；横向读技术，理解同一目标怎样高效实现。优化器、并行、精度和恢复贯穿多个阶段。先确定下面第一列，再选择对应的目标、预算和执行方法，能避免把“用了LoRA”误当成一个新的训练阶段。

阶段数据 → 目标预算与超参数执行与验收重点
Pretrain通用语料 / 代码 → LM、FIM参数与token分配；LR、batch、数据混合、schedule大规模并行、吞吐、恢复；同分布loss与分项能力
Midtrain / CPT领域、长上下文、仓库与轨迹 → 混合目标新增token、回放、mask、长度课程状态兼容；固定下游SFT检验增量与遗忘
SFT / 偏好示范、验证轨迹、偏好对 → CE / DPO等有效目标token、epochs、全参或adapter模板、角色与loss mask；独立执行、过拟合与回归
RLVR / Agentic RL策略rollout + 环境反馈 → 策略目标group、采样温度、长度、clip、更新次数生成 / 训练 / verifier协作；成功率、策略滞后与成本
OPD / 自蒸馏学生状态 + 教师概率 / 反馈 → 蒸馏目标教师覆盖、信号接口、系数与混合比例同状态概率对齐；无教师终评、保留能力与教师成本

横向技术的主讲位置：Scaling Law → 实验阶梯 → μP / WSD；SGD → AdamW → Muon及成本对照；训练框架、并行、状态分片与性能瓶颈。具体RL与OPD推导在后训练主题集中展开，本页保留阶段交接和适用判断。

学习组织参考 Stanford CS336（2026） 的基础→系统→Scaling→数据→对齐顺序，以及 Smol Training Playbook 的小实验、配方选择和训练诊断流程；下文的论断与数字仍引用对应原论文。

Pretraining文档 / 代码 token；预测后续 token，部分配方含 FIM通用 Base、tokenizer、数据与训练状态留出损失、通用能力、代码 / 数学、多语言和长上下文
CPT / Midtraining已有 Base；领域与通用回放，结构上下文、QA、masked trace领域或 Agent Base；配比、角色目标与回归报告固定下游 SFT 的最终增量；并行监测原有能力
SFT / 拒绝采样 RFT可靠示范、采样后通过验证的路径；目标动作交叉熵能遵循协议的策略；模板、工具 schema 与监督来源工具调用合法性、独立任务成功率、错误恢复与泛化
DPO / RL偏好对或策略 rollout；相对偏好 / reward偏好策略或结果驱动策略；参考模型、奖励和采样状态独立 verifier、多维能力、成本与失败分布
OPD / 最终交付学生状态上的教师信号；可汇总多个专家统一学生模型及推理 / 环境配置检查专家能力保留、教师支持范围、同预算终评

权重文件不能单独定义一个可复现的 Agent。Chat template、工具名称与参数、停止标记、最大上下文、环境镜像、verifier 版本和生成预算，都可能改变同一 checkpoint 的结果。

4 个学习环节

用同一个 CSV 清洗任务贯穿文档、代码变更、轨迹、监督目标、reward 与最终产物验证。

  • 数据和目标分别核算：文档、变更、轨迹提供不同条件；mask 与桶权重改变实际监督贡献。
  • 初始化和预算价值分开：固定 SFT 检验起点贡献，额外成本对照检验预算投向。
  • 均值和分项都验收：平均持平可以掩盖长上下文或常识退化。[6]
  • 方法和状态对应：能写 LoRA 梯度、AdamW 偏差修正、Muon 更新对象与分片账本。
  • 交付可追溯：训练阶段可分叉回流；checkpoint、模板、环境、数据与验收证据一起保存。
