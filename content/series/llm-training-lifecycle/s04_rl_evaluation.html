把结果接回更新，把验收留在更新之外

RL 的阶段价值是让当前策略尝试任务，再按结果调整行为。本节聚焦训练与交付的交接；PG、PPO/GRPO、奖励信用与异步校正的推导由后训练主题统一主讲。

行为策略提供采样分布；old 策略定义更新代理目标；reference 控制漂移；current 是正在更新的模型。它们可能起初相同，职责仍须分别记录。把 reference log-prob 填进行为概率字段会改变目标。

CSV 算例：验证产物和约束

# sample.csv                     # correct out.csv
id,value                         id,value
1,7                              1,7
2,                               3,0
3,0

checks = {
    "path": output.has_expected_path,
    "header": output.header == expected.header,
    "rows": output.rows == expected.rows,
    "input_unchanged": input_hash_after == input_hash_before,
}
reward = int(all(checks.values()))

“0”是合法值：若策略用真假判断过滤，可能误删第3行；只检查文件存在会给错解满分。期望结果属于 evaluator，不能喂给策略。正式数据还需覆盖空白、引号、换行、编码和容差。

  • 结果奖励：测试、文件或环境状态，可检查具体正确性；仍受覆盖不足影响。
  • 偏好/模型 grader：帮助性、交互质量等难以精确断言的信号；须登记版本与风格、长度偏差。
  • 成本约束：工具次数、时间、token、非法动作单列；鼓励少调用不能诱导提前停止。

奖励如何进入优势与动作信用，见环境、奖励与信用节。任务合同与独立 verifier 的完整设计在任务主题。

训练指标和交付指标各回答什么

训练侧说明交付侧还需验证
reward 均值上升当前评分目标更高独立 verifier 成功、隐藏断言、污染检查
loss/KL 下降目标拟合或分布接近任务能力、教师支持范围与旧能力
tokens/s 上升生产或计算速度更高有效轨迹率、全部尝试成本与同预算质量
平均分持平汇总指标未变各任务族、长任务、恢复能力和失败类型

配对算例：同100题，旧模型60题成功，新模型65题成功；若10题由失败变成功、5题由成功变失败，则差值为5个百分点。保留这15题的配对结果，才能分析增益来自哪里；两份总分看不到退化题。

  • 固定条件：模型 hash、scaffold、工具、镜像、模板、生成预算、温度、停止规则和 verifier。
  • 固定分母：任务失败、环境失败、超时、缺失分别计数；重跑规则先规定，原记录继续保留。
  • 分开不确定性：评测重复采样不能替代独立训练种子；任务 bootstrap 的区间不覆盖所有训练波动。
  • 保持独立：验证集可用于选择，最终测试集避免反复调参。来源族、仓库与解法近重复隔离。

Nemotron 每题3次/8次平均 pass@1 不能改称 pass@3/pass@8。有限样本 pass@k、配对区间与统计单位在独立评测节展开。

预算对照：初始化与额外投入分别检验

固定下游 SFT 只检验初始化贡献。判断 CPT 是否比更多 SFT 更值得，还需一组额外预算投向 SFT 的对照；输入 token、目标 token、FLOPs、GPU-hours 与教师/环境成本分别登记。

追问：训练 reward 高为什么仍可能不交付？训练 verifier 可能被投机或覆盖不足，还需独立任务、旧能力、成本与失败验收。

追问：评测多个采样种子能代替训练多个种子吗？不能。前者评估固定策略的采样波动，后者还覆盖参数学习与数据顺序的变化。

追问：只保存权重够吗？续训还需 optimizer/scheduler/RNG/数据位置；复现 Agent 终评还需完整执行协议。
