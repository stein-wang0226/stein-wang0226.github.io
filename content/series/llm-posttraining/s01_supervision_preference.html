SFT：目标 token、条件历史和样本权重

相关原论文 / 官方资料：Transformer。

令 hᵢ 是预测第 i 个 token 时的历史，mᵢ 是目标 mask。对 Agent，通常学习 assistant 的动作、参数、解释和结束标记；system / user / tool 内容作为条件历史。具体角色边界由真实 chat template 决定。

teacher forcing把示范前缀固定，条件概率连乘取负log后变成逐token交叉熵。令 \(N\) 为有效轨迹数，\(m_{ni}\in\{0,1\}\) 为监督mask，\(N_n\) 为第n条轨迹的有效目标数；仅对 \(N_n>0\) 的轨迹取平均。先排除无目标轨迹，再计数并重新索引，下式两种平均都在这个有效集合上计算；若整批没有目标，跳过该批更新，不用除零或把空轨迹的loss填0：

\[ \begin{aligned} N_n&=\sum_i m_{ni},\\ \ell_{ni}&=-\log\pi_\theta(a_{ni}\mid h_{ni}),\\ L_{\rm token}&=\frac{\sum_n\sum_i m_{ni}\ell_{ni}}{\sum_n N_n},\\ L_{\rm episode}&=\frac1N\sum_n\frac{\sum_i m_{ni}\ell_{ni}}{N_n}. \end{aligned} \]

两个分母并不等价。token-mean 使较长的目标轨迹拥有更多总权重；episode-mean 给每条 episode 相同权重，单 token 的权重随长度下降。长恢复链路与短成功路径混合时，要报告实际采用哪一种，不能只写“assistant-only SFT”。

符号：\(n\) 索引轨迹，\(i\) 索引预测位置，\(a_{ni}\) 是示范目标 token，\(h_{ni}\) 是它之前的可见历史，\(\theta\) 是模型参数；\(\ell_{ni}\) 是单位置负对数概率。下式的 \(z_{ni,v}\) 是词表项 \(v\) 的 logit，\(p_{ni,v}\) 是 softmax 概率；\(\mathbf1[\cdot]\) 为条件成立取 1、否则取 0 的指示函数。

mask算例：输入为“题面 → 工具动作 → 观察 → 修复动作”。两个assistant目标token的正确概率为0.5、0.25，则token平均损失为 \(-(\log0.5+\log0.25)/2\approx1.0397\)。题面和观察不进入分母，却仍被后续动作Attention读取。

\[ p_v=\operatorname{softmax}(z)_v,\qquad \frac{\partial L}{\partial z_{ni,v}} =\frac{m_{ni}}{\sum_{n',i'}m_{n'i'}} \left(p_{ni,v}-\mathbf1[v=a_{ni}]\right). \]

mask=0使该预测位置的直接CE梯度为零；观察的表示仍可能通过后续有监督位置的计算接收梯度。因此不能把mask解释成删除上下文、断开Attention或冻结对应embedding。

离线训练使用示范前缀，即 teacher forcing；推理使用学生自己的动作历史。学生一个错误工具参数就可能进入示范没有覆盖的状态，随后持续偏离。这是补恢复数据、在线 RL 和 OPD 的共同动机，但三者提供的目标不同。

恢复训练：保留学生失败历史，监督可靠纠正

相关原论文 / 官方资料：GRPO / DeepSeekMath。

教学任务：函数 mean([]) 应抛出明确的 ValueError，非空列表保持原行为。学生第一次只在调用方捕获除零，工具回报单元测试仍失败；教师读真实错误后在函数入口处理空输入，再运行回归。训练要区分“失败状态的上下文价值”和“失败动作是否值得模仿”。

ReTerm §3.1 明确只对教师恢复 token 做 SFT，学生失败历史提供上下文；§3.2 的 ReTerm-GRPO 是另一个在线优化分支。GLM-5 也讨论成功轨迹内部的不良动作筛选。这些证据支持精细监督，不能推成“所有失败 token 永远都不应训练”。[16] [22]

教师恢复需要可重放和终评：修复后的公开测试通过，不代表没有修改测试或破坏其他输入。监督准入应结合独立测试、文件变更范围和恢复轨迹质量；错误观察覆盖按任务族统计，不按“轨迹最终成功”一刀切。

拒绝采样 RFT：把搜索成本与数据偏移算进去

\[ P(\text{至少一个成功}\mid x)=1-(1-p_x)^K,\qquad \mathbb E[\text{保留全部成功的条数}\mid x]=Kp_x. \]

这里 \(x\) 是固定任务，\(p_x\) 是模型在该任务上单次成功的概率，\(K\) 是独立尝试次数；\(P(\cdot\mid x)\) 和 \(\mathbb E[\cdot\mid x]\) 都是在给定这道题的条件下计算，分别衡量“能否得到示范”和“得到多少示范”。

独立尝试假设下，\(K=4\)，容易题 \(p_x=0.8\) 约99.84%有成功候选，难题 \(p_x=0.1\) 只有34.39%。筛选后的训练分布因此更偏容易题；增加候选预算不等于覆盖已经均衡。

同样的 K 会让容易题贡献更多训练条数，难题可能完全消失。只保留每题一条减少条数偏移，却不能救回零成功题；补教师、调整难度、增加预算或放弃任务需要分别记录。弱 verifier 还会筛进投机解法。

报告候选总 token、执行与判分时间、通过率、去重率和最终监督 token。同样大小的 SFT 数据可能消耗完全不同的搜索算力；与 RL 比较时，仅对齐保留下来的数据量会隐藏差异。

偏好优化：从 DPO 到无需成对标签的 KTO

相关原论文 / 官方资料：DPO；PPO；GRPO / DeepSeekMath。

设 y+ 与 y− 是同一任务的偏好轨迹。DPO 将相对于参考策略的对数概率差转成偏好分类，标准离线版本没有每步环境探索。[12]

从KL正则最优策略到偏好分类

先对同一prompt \(x\) 的文本候选分布推导。简记 \(p_y=\pi(y\mid x)\)、\(q_y=\pi_{\rm ref}(y\mid x)\)、\(r_y=r(x,y)\)。参考策略在候选支持上概率非零，\(\beta>0\) 控制KL正则；优化期望reward并约束 \(\sum_y p_y=1\)：

\[ \begin{aligned} \max_p\ &\sum_y p_y r_y-\beta\sum_y p_y\log\frac{p_y}{q_y},\\ 0&=r_y-\beta\left(\log\frac{p_y^*}{q_y}+1\right)+\eta,\\ p_y^*&=\frac{q_y\exp(r_y/\beta)}{Z(x)},\\ r_y&=\beta\log\frac{p_y^*}{q_y}+\beta\log Z(x). \end{aligned} \]

第二行来自拉格朗日乘子的一阶条件；\(Z(x)\) 将候选概率归一化。Bradley–Terry模型用 \(\sigma(r(x,y^+)-r(x,y^-))\) 表示偏好概率。两候选的prompt相同，\(\beta\log Z(x)\) 相减消掉，再以可训练 \(\pi_\theta\) 参数化隐式reward：

符号：星号表示最优解；\(\eta\) 是约束“概率和为 1”的拉格朗日乘子，\(Z(x)=\sum_y q_y\exp(r_y/\beta)\)。\(\sigma\) 是 sigmoid；下面 \(u_+,u_-\) 是两候选相对 reference 的 log-ratio，\(z\) 是偏好分类 logit，区别于 SFT 的词表 logits。

\[ \begin{aligned} u_\pm&=\log\frac{\pi_\theta(y^\pm\mid x)}{\pi_{\rm ref}(y^\pm\mid x)},\\ z&=\beta(u_+-u_-),\\ L_{\rm DPO}&=-\log\sigma(z),\\ \frac{\partial L}{\partial z}&=\sigma(z)-1. \end{aligned} \]

完整偏好对：token 概率怎样变成 loss 和更新方向

输入：同一 prompt 的 chosen / rejected 各有两个回答 token，第二个包含结束边界。表内是各自真实历史下，已选 token 的条件概率；prompt 与 padding 不计入回答似然。教学取 \(\beta=0.2\)，reference 冻结，使用原始 DPO 的回答 log-prob 求和，不做长度平均。[12] §4、式7

两候选分别 teacher forcing；省略词表中其他 token
候选当前两个 token 概率参考概率回答似然与相对比
chosen \(y^+\)0.6、0.50.5、0.4\(\pi_\theta=0.30,\ \pi_{\rm ref}=0.20\)；比为1.5
rejected \(y^-\)0.4、0.250.5、0.4\(\pi_\theta=0.10,\ \pi_{\rm ref}=0.20\)；比为0.5
\[ \begin{aligned} \log\pi_\theta(y^\pm\mid x) &=\sum_{i=1}^{2}\log p_{\theta,i}^{\pm},\\ u_+&=\log1.5,\qquad u_-=\log0.5,\\ z&=0.2\log3\approx0.219722,\\ \sigma(z)&\approx0.554711,\qquad L\approx0.589309. \end{aligned} \]

\(p_{\theta,i}^{\pm}\) 是候选内第 \(i\) 个回答 token 在其前缀上的条件概率；\(c=\beta[1-\sigma(z)]\) 是该偏好对的梯度系数。概率均为无量纲，log 用自然对数，loss 的单位为 nats。

\[ \begin{aligned} c&\approx0.089058,\\ \frac{\partial L}{\partial\log p_{\theta,i}^{+}}&=-c,\qquad \frac{\partial L}{\partial\log p_{\theta,i}^{-}}=+c. \end{aligned} \]

因此梯度下降沿着提高 chosen 相对似然、压低 rejected 相对似然的方向走；这是对 log-prob 的局部导数，实际参数梯度还要经过 softmax 和共享网络，不能直接给概率加减 \(c\)。

把梯度再走到一次实际更新：三个二分类历史位置

仅为核对链式法则，第一位置由同一 logit \(g_0\) 给出 chosen 概率 \(p=\sigma(g_0)=0.6\)、rejected 概率 \(1-p=0.4\)；两候选第二位置历史不同，各有独立目标 logit \(g_+,g_-\)，概率为0.5、0.25。另一词的 logit 固定为0，三参数独立，\(\eta=0.1\) 为教学学习率。

链式法则给出 \(\partial L/\partial g_0=-c\)，\(\partial L/\partial g_+=-c(1-0.5)\)，\(\partial L/\partial g_-=c(1-0.25)\)；逐个执行 \(g'=g-\eta\,\partial L/\partial g\)。更新后 chosen 概率约为[0.602135, 0.501113]，rejected 为[0.397865, 0.248750]；第一位置两概率仍相加为1，重新计算同一对的loss为0.587872。

这是三参数二分类模型的一步SGD，不是实际LLM训练实验或推荐学习率；真实共享网络下不能保证 chosen 的绝对概率每步单调上升。

推导依赖偏好模型、参考支持和数据覆盖；\(\beta\) 的含义要与实现约定一致。交互Agent沿历史累加可控动作log-prob时，应明确采用的轨迹代理目标与环境协议，不能把工具观察当成模型采样token。

教学 chosen 是函数入口检查空输入且回归通过；rejected 是直接把所有异常吞掉、返回 0。标签应反映任务约束，而非回复更礼貌。Agent 的 log π(y|x) 只累计策略生成动作的概率，工具输出作为条件；不能把环境观察也当作模型选择。

方法反馈与关键机制参考模型使用时的边界
DPO [12]成对偏好，参考相对 log-prob 差需要离线覆盖和标签质量；β 与长度、概率和数据共同作用
SimPO [13]平均 token log-prob 作为隐式 reward，加入偏好 margin不需要长度归一化改变目标，不是简单删掉 DPO 的 reference
ORPO [14]chosen 的 SFT，加 odds-ratio 偏好惩罚不需要同时提升示范拟合和偏好差；其 odds 语义不同于直接 log-ratio
KTO [15]非成对 desirable / undesirable 标签，参考 KL baseline需要好坏样本比例和权重需要校准，不等于任意二值任务 reward 的在线 RL
\[ \begin{aligned} r_\theta(x,y)&=\frac{\beta}{|y|}\log\pi_\theta(y\mid x),\\ \Delta r_\theta&=r_\theta(x,y^+)-r_\theta(x,y^-),\\ L_{\rm SimPO}&=-\log\sigma(\Delta r_\theta-\gamma). \end{aligned} \]

SimPO 的 \(|y|\) 是回答的目标 token 数，\(\beta\) 缩放平均 log-prob，\(\gamma\) 是要求 chosen 超过 rejected 的偏好间隔；这里的 \(\gamma\) 不表示 RL 奖励折扣。\(\Delta r_\theta\) 是同题两候选的分数差。

新策略遇到静态偏好对没有出现的环境状态时，仍可能无法恢复。在线收集偏好可更新数据覆盖，但属于额外过程；不能由此认为离线 DPO 已完成 PPO / GRPO 的探索功能。偏好、执行正确性和成本最好分别报告。

追问：DPO的归一化常数为什么消失？同一prompt的两候选共享 \(Z(x)\)，reward相减时抵消；不同prompt不能这样相减。

追问：mask=0是否没有梯度？该预测位置直接CE为零，但作为后续条件的表示仍可能收到梯度。

强化 RFT：grader 必须对应任务意义

相关原论文 / 官方资料：PPO；RLHF / InstructGPT；GRPO / DeepSeekMath；DeepSeek-R1。

OpenAI Cookbook 用生命科学描述生成短答案，讨论 exact、fuzzy 和 model graders。这个案例说明 grader 的可用形态，不证明字符串相似就能判断科学正确；模型 grader 需要留出标注校准，不能只在训练答案上验收。[17]

教学代码任务更适合执行测试与变更限制：先判环境是否正常，再判补丁是否正确；错误类型、超时与基础设施故障分别记录。强化 RFT 是反馈循环的称呼，具体采用何种 actor/critic、ratio 或 baseline，要由实现文档说明，不从 API 命名推断。

RLHF、RLVR 主要区分反馈来源；PPO、GRPO 主要区分优化目标；异步训练描述执行系统。把它们分开，才能判断失败应该改标签、补数据、换算法，还是修运行环境。
