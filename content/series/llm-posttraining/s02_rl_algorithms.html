本章阅读路径：原理、变体、配方、诊断

  • 原理：轨迹概率 → 动作梯度 → baseline/GAE → PPO → GRPO。
  • 变体：逐项区分优势、ratio、裁剪、分母和采样。
  • 应用：论文配方 → 参数联动 → 训练诊断；数字连同条件一起记。

从最终成败到动作梯度，中间隔着信用分配

Agent episode 包含策略动作和环境观察。模型只控制动作；最后 reward 要转成哪些动作应增加或减少概率的信号，再决定用怎样的概率比、裁剪和分母完成更新。

先定义学习问题：模型能控制什么，目标又是什么

任务或 prompt \(x\) 来自固定任务分布，例如“修复这个仓库并通过测试”。环境有内部状态 \(s_t\)，模型收到观察 \(o_t\)，在动作前历史 \(h_t\) 上按 \(\pi_\theta(a_t\mid h_t)\) 采样可控动作 \(a_t\)。环境执行动作后产生奖励 \(r_t\)、新观察 \(o_{t+1}\) 和终止信号，再形成 \(h_{t+1}\)。动作可以是一枚生成 token，也可以是一轮工具调用；一段推导内须固定决策单位，不能把工具输出 token 混入策略动作。

MDP 的状态 \(s_t\) 包含决定环境转移所需的信息，但它未必完全可见。这里用完整已知交互历史 \(h_t\) 条件化：任务、过去动作与观察、已发生的奖励及时间 \(t\) 都可记入历史；actor 可以只读取其中的上下文字段。有限时域下同一观察在不同剩余预算处的价值可能不同，因此时间不能无故丢失。工具观察参与条件，不是模型选择的动作，policy mask 通常为 0。

每条轨迹有 \(T\) 次决策，\(t=0,\ldots,T-1\)。任务合同规定成功、失败、合法停止和预算耗尽是否真实终止；训练器暂停收集不自动等于任务结束。以下基础证明优化有限时域、从初始分布出发的折扣期望回报 \(J(\theta)=\mathbb E_{\tau\sim p_\theta}[R(\tau)]\)，其中 \(R(\tau)=\sum_t\gamma^t r_t\)。可将终止后补成吸收状态、奖励为 0 的有限长度记录。

前提：在本次 actor 求导时，任务/初态分布、环境转移机制和固定轨迹上的奖励不直接依赖 \(\theta\)；它们仍会因模型选择了不同动作而产生不同结果。策略可微、动作支持在所讨论参数邻域稳定，相关矩有限，并允许交换求导与求和/期望。主要推导采用离散动作；连续状态的轨迹求和改为积分，需要相应正则条件。若另加直接依赖 actor 的 KL loss，它的梯度须另计，不能混入这条“固定奖励”的证明。

关键问题：环境测试不能对模型参数求导，怎样把测试成败变成梯度？答案是对采样概率求导。沿用表中 \(\pi_t,P_t\) 的简记，先写出轨迹概率与折扣目标：

\[ \begin{aligned} p_\theta(\tau)&=p(h_0)\prod_{t=0}^{T-1}\pi_t P_t,\\ R(\tau)&=\sum_{t=0}^{T-1}\gamma^t r_t,\\ J(\theta)&=\sum_\tau p_\theta(\tau)R(\tau). \end{aligned} \]

REINFORCE：每个等号为什么成立

先固定一条轨迹 \(\tau\)。即使奖励由模型所选动作间接决定，在固定这条轨迹求导时，奖励 \(R(\tau)\)、初态分布和环境因子都不直接依赖 \(\theta\)。在正概率、稳定支持上，自然对数的导数给出 \(\nabla_\theta\log p_\theta(\tau)=\nabla_\theta p_\theta(\tau)/p_\theta(\tau)\)，因此可以乘回采样概率，把概率导数改写成期望：

\[ \begin{aligned} \nabla_\theta J &=\sum_\tau\nabla_\theta[p_\theta(\tau)R(\tau)]\\ &=\sum_\tau R(\tau)\nabla_\theta p_\theta(\tau)\\ &=\sum_\tau p_\theta(\tau)R(\tau) \frac{\nabla_\theta p_\theta(\tau)}{p_\theta(\tau)}\\ &=\sum_\tau p_\theta(\tau)R(\tau) \nabla_\theta\log p_\theta(\tau)\\ &=\mathbb E_{\tau\sim p_\theta}\! \left[R(\tau)\nabla_\theta\log p_\theta(\tau)\right]. \end{aligned} \]

依次使用：求导与轨迹求和可交换；\(\nabla_\theta R(\tau)=0\)；乘除同一个正的 \(p_\theta(\tau)\)；log-derivative 恒等式；最后按期望的定义收起概率加权求和。连续轨迹部分改为积分，而不是让环境对 actor 可微。接着展开 log 轨迹概率：

\[ \begin{aligned} \log p_\theta(\tau) &=\log p(h_0)+\sum_{t=0}^{T-1} [\log\pi_\theta(a_t\mid h_t)+\log P_t],\\ g_t&=\nabla_\theta\log\pi_\theta(a_t\mid h_t),\\ \nabla_\theta\log p_\theta(\tau) &=0+\sum_{t=0}^{T-1}(g_t+0) =\sum_{t=0}^{T-1}g_t,\\ \nabla_\theta J&=\mathbb E_{\tau\sim p_\theta}\! \left[R(\tau)\sum_{t=0}^{T-1}g_t\right]. \end{aligned} \]

乘积取 log 后变成求和；两个 0 分别来自固定初态和固定环境机制。梯度只穿过策略动作的概率，不穿过 shell、浏览器、verifier 或工具观察。这就是 score-function 估计，不要求环境测试可微。[80]

N 条独立轨迹如何成为梯度估计和负号 loss

令 \(\theta_0\) 是生成本批数据的固定策略参数，从 \(p_{\theta_0}\) 独立采样 \(N\) 条轨迹组成 \(\mathcal D\)。上标 \((m)\) 标识第 \(m\) 条，\(T^{(m)}\) 是它的决策数。用样本均值替换期望：

\[ \begin{aligned} \widehat{\nabla J}(\theta_0) &=\frac1N\sum_{m=1}^N R(\tau^{(m)}) \sum_{t=0}^{T^{(m)}-1}g_t^{(m)}(\theta_0),\\ \mathcal L_{\rm actor}(\theta;\mathcal D) &=-\frac1N\sum_{m=1}^N\sum_{t=0}^{T^{(m)}-1} \operatorname{sg}(R(\tau^{(m)})) \log\pi_\theta(a_t^{(m)}\mid h_t^{(m)}),\\ -\left.\nabla_\theta\mathcal L_{\rm actor}\right|_{\theta=\theta_0} &=\widehat{\nabla J}(\theta_0). \end{aligned} \]

每条独立轨迹的贡献都有同一目标梯度的期望，因此除以 \(N\) 的均值也是无偏估计；有限样本仍有噪声。loss 的负号使梯度下降对应目标上升，sg 保证回报只是固定权重。这个样本 loss 不是对所有 \(\theta\) 都等于 \(-J(\theta)\)：上面的期望对应关系在采样参数 \(\theta_0\) 处成立，多轮改参数后复用旧数据要另讨论PPO 局部代理。下一段把每个动作的整轨迹权重 \(R\) 换成 \(\gamma^tG_t\)，再可按baseline 证明换成 \(\gamma^t(G_t-b(h_t))\)。

为什么只用当前动作之后的奖励

动作 \(a_t\) 不可能改变已经发生的奖励。把初态折扣总回报拆成两部分：\(C_t\) 是当前动作之前的奖励和，\(G_t\) 是从当前步重新起算折扣的未来回报，空和 \(C_0=0\)：

\[ C_t=\sum_{k=0}^{t-1}\gamma^k r_k,\qquad G_t=\sum_{k=t}^{T-1}\gamma^{k-t}r_k,\qquad R(\tau)=C_t+\gamma^tG_t. \]

给定完整已知历史 \(h_t\)，过去奖励与时间已经确定，因此 \(C_t\) 是历史函数；即使 actor 的实际上下文没有输入全部奖励记录，也可按这份完整历史条件化。能删掉过去奖励，靠的是下面的零均值，而不是“过去奖励数值很小”。

score lemma：动作概率约分后为什么只剩零

令 \(c(h_t)\) 是不依赖当前动作的固定标量，\(a\) 遍历给定历史下稳定的动作支持。期望按该历史下的策略概率加权，不是把不同状态或动作等权平均：

\[ \begin{aligned} \mathbb E[c(h_t)g_t\mid h_t] &=\sum_a\pi_\theta(a\mid h_t)c(h_t) \nabla_\theta\log\pi_\theta(a\mid h_t)\\ &=\sum_a\pi_\theta(a\mid h_t)c(h_t) \frac{\nabla_\theta\pi_\theta(a\mid h_t)} {\pi_\theta(a\mid h_t)}\\ &=c(h_t)\sum_a\nabla_\theta\pi_\theta(a\mid h_t)\\ &=c(h_t)\nabla_\theta\sum_a\pi_\theta(a\mid h_t)\\ &=c(h_t)\nabla_\theta 1=0. \end{aligned} \]

这里先展开条件期望，再用 log 导数；正概率支持上的采样概率与分母约掉，历史标量可提出求和，最后用概率归一化。令 \(c(h_t)=C_t\)，再用全期望消去每步的过去奖励：

\[ \begin{aligned} \mathbb E[R(\tau)g_t] &=\mathbb E[(C_t+\gamma^tG_t)g_t]\\ &=\mathbb E[\mathbb E[C_tg_t\mid h_t]] +\mathbb E[\gamma^tG_tg_t]\\ &=0+\mathbb E[\gamma^tG_tg_t],\\ \nabla_\theta J &=\mathbb E\!\left[\sum_{t=0}^{T-1}\gamma^tG_tg_t\right]. \end{aligned} \]

这是有限时域折扣回报的精确形式，外面的 \(\gamma^t\) 不能随意省略。LLM终局奖励教学常取 \(\gamma=1\)，或算法另定义状态加权目标；应说明具体口径。工具观察参与下一历史，但不是策略生成的动作。

结论与问题：给每个动作的回报减去只依赖动作前历史的 baseline，可以保持 on-policy 策略梯度的期望，但不保证降低方差。这里 \(h_t\) 是完整已知历史，\(a_t\sim\pi_\theta(\cdot\mid h_t)\) 是当前离散动作，\(g_t=\nabla_\theta\log\pi_\theta(a_t\mid h_t)\) 是向量 score，\(G_t=\sum_{k=t}^{T-1}\gamma^{k-t}r_k\) 是按该策略继续采样的未来回报；\(b(h_t)\) 为奖励同单位的标量。无需引用前一条等式也能证明它为什么可减。前置定义可回到学习问题与score lemma / reward-to-go。[80]

在本小节中，\(\theta\) 是 actor 参数，\(t=0,\ldots,T-1\) 索引有限条决策，\(\gamma\in[0,1]\) 是固定折扣，\(r_t\) 是执行后的奖励。目标为 \(J(\theta)=\mathbb E_{\tau\sim p_\theta}[\sum_t\gamma^t r_t]\)，初态分布、环境机制与固定轨迹上的奖励不直接依赖 actor 参数。以下带 baseline 的等式针对这个初态折扣目标，保留外层 \(\gamma^t\)。

条件：固定历史、采样策略和本批所用 baseline 估计器后，baseline 不依赖当前动作；条件动作分布仍为 \(\pi_\theta\)。策略对 \(\theta\) 可微，在所讨论邻域具有稳定支持；期望和梯度可交换，相关一阶矩存在，讨论方差时还需二阶矩有限。若估计器随机，可条件化于独立训练数据得到同一证明；不能用本样本的动作或未来 reward 拟合一个相关 baseline 后，仅凭 detach 就声称无偏。

\[ \begin{aligned} \mathbb E[g_t b(h_t)\mid h_t] &=\sum_a\pi_\theta(a\mid h_t)b(h_t) \nabla_\theta\log\pi_\theta(a\mid h_t)\\ &=\sum_a\pi_\theta(a\mid h_t)b(h_t) \frac{\nabla_\theta\pi_\theta(a\mid h_t)} {\pi_\theta(a\mid h_t)}\\ &=b(h_t)\sum_a\nabla_\theta\pi_\theta(a\mid h_t)\\ &=b(h_t)\nabla_\theta\sum_a\pi_\theta(a\mid h_t) =b(h_t)\nabla_\theta 1=0. \end{aligned} \]
  1. 给定 \(h_t\)，用当前动作的采样概率展开条件期望；\(a\) 遍历该历史下的稳定动作支持。
  2. 在正概率支持上使用 \(\nabla\log\pi=\nabla\pi/\pi\)，采样概率与分母约掉。
  3. baseline 对所有当前动作相同，所以可提出动作求和；这里只对策略概率求导，不对 baseline 求导。
  4. 可交换求导与求和，再由每个固定历史下的概率归一化 \(\sum_a\pi_\theta(a\mid h_t)=1\) 得到零。

再用全期望：\(\mathbb E[\gamma^t b(h_t)g_t]=\mathbb E[\gamma^t\mathbb E[b(h_t)g_t\mid h_t]]=0\)。时间 \(t\) 已包含在历史中；对有限个决策相加，即得到带 baseline 的完整梯度：

\[ \begin{aligned} \nabla_\theta J(\theta) &=\mathbb E_{\tau\sim p_\theta} \left[\sum_{t=0}^{T-1}\gamma^t G_t g_t\right]\\ &=\mathbb E_{\tau\sim p_\theta} \left[\sum_{t=0}^{T-1}\gamma^t \bigl(G_t-b(h_t)\bigr)g_t\right]. \end{aligned} \]

统计条件与反传条件是两件事。actor 把回报、baseline 或估计优势作为固定权重；否则对 \((G_t-b)\log\pi_\theta\) 求导还会产生 baseline 分支的额外项，不再是此 score 估计。即使 actor/critic 共享 backbone，sg 也只切断权重路径；要保证上述期望，可以先冻结估计器再采集新 on-policy 数据，或采用满足条件独立的样本拆分。对同批样本拟合再冻结，不自动满足零均值证明的统计前提。

真实优势、MC 样本和近似 value：不能写成一个量

\(Q^\pi(h,a)\) 是在历史 \(h\) 执行动作 \(a\)，随后一直按同一策略 \(\pi\) 采样的期望未来回报；\(V^\pi(h)\) 按该策略的动作分布平均 \(Q^\pi\)，\(A^\pi(h,a)\) 是两者之差。它们的单位与回报相同，时间信息含在 \(h\) 中。critic 的 \(V_\phi\) 是参数 \(\phi\) 的近似预测，不是定义上的真值；\(\phi,\theta\) 区分职责，不要求共享 backbone 的参数完全不重叠。

\[ Q^\pi(h,a)=\mathbb E[G_t\mid h_t=h,a_t=a],\quad V^\pi(h)=\mathbb E_{a\sim\pi}[Q^\pi(h,a)],\quad A^\pi(h,a)=Q^\pi(h,a)-V^\pi(h). \]

\(G_t\) 是 \(Q^\pi(h_t,a_t)\) 的一个Monte Carlo 回报样本，不是它的数值真值。若 baseline 恰为真实 \(V^\pi\)，则 MC 优势样本的条件均值是正式优势；若使用本批固定的近似 \(V_\phi\)，则一般不是：

\[ \begin{aligned} \mathbb E[G_t-V^\pi(h_t)\mid h_t,a_t] &=Q^\pi(h_t,a_t)-V^\pi(h_t)=A^\pi(h_t,a_t),\\ \hat A_t^{\rm MC}&=G_t-V_\phi(h_t),\\ \mathbb E[\hat A_t^{\rm MC}\mid h_t,a_t] &=Q^\pi(h_t,a_t)-V_\phi(h_t)\\ &=A^\pi(h_t,a_t)+V^\pi(h_t)-V_\phi(h_t). \end{aligned} \]

最后一项说明 critic 误差改变了“优势估计”的条件均值；但它仍只是历史函数，因此满足 baseline 条件的完整 MC 回报减近似 value，仍保持此 on-policy 梯度的期望。这不等于任意 TD / GAE 都无偏：bootstrap 还用近似 value 替换了尚未采样的未来回报，误差来源不同。下一节继续说明两步 GAE 的固定目标与损失。

critic 为什么做 MSE：从平方展开到条件期望

固定历史 \(h_t=h\) 和生成回报的策略 \(\pi\)，把预测看作待选标量 \(c\)，而不是先假设网络一定能拟合真值。设 \(\mu(h)=\mathbb E[G_t\mid h_t=h]=V^\pi(h)\)，并假定 \(\mathbb E[G_t^2\mid h_t=h]<\infty\)。平方误差的条件期望为：

\[ \begin{aligned} \mathcal L_h(c) &=\mathbb E[(G_t-c)^2\mid h_t=h]\\ &=\mathbb E[G_t^2\mid h_t=h]-2c\,\mu(h)+c^2\\ &=\operatorname{Var}(G_t\mid h_t=h)+(c-\mu(h))^2,\\ \frac{d\mathcal L_h}{dc}&=2(c-\mu(h)),\qquad \frac{d^2\mathcal L_h}{dc^2}=2>0,\\ c^\ast(h)&=\mu(h)=V^\pi(h). \end{aligned} \]

第一步展开平方，用期望的线性性把固定 \(c\) 提出；补上再减去 \(\mu^2\)，得到“不可约回报方差 + 预测偏离条件均值的平方”。一阶导数为零时 \(c=\mu\)，正二阶导数保证它是唯一全局最小值。这证明的是固定分布、可自由选择预测值时的理想 MSE 目标，不保证有限样本、受限网络、优化未收敛或持续变动的策略能达到 \(V^\pi\)；也不证明它是梯度方差最优 baseline。

实际 critic 用 \(V_\phi(h_t)\) 对固定标签 \(y_t\) 回归，常取 \(\mathcal L_{\rm critic}=\frac12\operatorname{mean}_t(V_\phi(h_t)-\operatorname{sg}(y_t))^2\)。完整 MC 标签是 \(y_t=G_t\)；TD 标签包含冻结下一 value；lambda-return 标签可取 \(\hat V_t=V_{\rm rollout}(h_t)+\hat A_t\)。只有在标签条件均值确为 \(V^\pi\) 的口径下，上述最优预测才等于真实 value；近似 bootstrap 标签的 MSE 最优值首先是该标签的条件均值。

actor 的单决策 MC loss 项可写成 \(-\gamma^t\operatorname{sg}(\hat A_t^{\rm MC})\log\pi_\theta(a_t\mid h_t)\)。在生成该批数据的策略参数处，对这些固定权重项求负梯度并按轨迹聚合，其期望对应上述 on-policy 表达式；多轮改变参数后复用数据则需另外讨论代理目标。它不是对环境反传。critic loss 只对当前预测求导，标签停止梯度。共享 backbone 可以分别接收 actor 和 critic 两种参数梯度，但不通过 actor 的优势权重反传到 critic 标签。

比较的是梯度估计方差，不是回报平移

分析对象为 \(X_b=(G_t-b)g_t\)。固定历史下，减去常数不会改变标量回报的方差：\(\operatorname{Var}(G_t-b)=\operatorname{Var}(G_t)\)；但乘上与动作、回报相关的 score 后，\(X_b\) 的二阶矩会变。一个好的 baseline 通常降方差；任意 baseline 都不保证降方差，真实 value 也不一定是 score 加权意义下的最优值。

保留单步 Bernoulli 构造：\(p=\sigma(\theta)=1/(1+e^{-\theta})=0.25\)，成功奖励 2、失败奖励 0；单步 \(G_0=R\)，无后续环境随机奖励。成功 score 为 \(1-p=0.75\)，失败 score 为 \(-p=-0.25\)，真实价值 \(V=2p=0.5\)。以下都是精确枚举的解析教学值，不是训练实测。

进阶：固定历史、单步向量梯度的最优 baseline 为什么不一定是 V

固定历史 \(h_t=h\)，只分析这一决策的向量估计 \(X_b=(G_t-b)g_t\)，用协方差的迹（各参数分量方差之和）衡量波动。假定所需二阶矩有限，且 \(\mathbb E[\|g_t\|^2\mid h]>0\)；\(\|\cdot\|\) 是欧氏范数。零均值 baseline 证明使 \(\mu_X=\mathbb E[X_b\mid h]=\mathbb E[G_tg_t\mid h]\) 与 \(b\) 无关，因此只需最小化二阶矩 \(M_h(b)\)：

\[ \begin{aligned} \operatorname{tr}\operatorname{Cov}(X_b\mid h) &=\mathbb E[\|X_b\|^2\mid h]-\|\mu_X\|^2,\\ M_h(b)&=\mathbb E[(G_t-b)^2\|g_t\|^2\mid h]\\ &=\mathbb E[G_t^2\|g_t\|^2\mid h] -2b\,\mathbb E[G_t\|g_t\|^2\mid h] +b^2\mathbb E[\|g_t\|^2\mid h],\\ \frac{dM_h}{db} &=-2\mathbb E[G_t\|g_t\|^2\mid h] +2b\,\mathbb E[\|g_t\|^2\mid h],\\ \frac{d^2M_h}{db^2}&=2\mathbb E[\|g_t\|^2\mid h]>0,\\ b^\ast(h)&= \frac{\mathbb E[G_t\|g_t\|^2\mid h_t=h]} {\mathbb E[\|g_t\|^2\mid h_t=h]}. \end{aligned} \]

每种动作的回报被 score 平方范数加权，所以这个最优值一般不同于 MSE 的无 score 权重均值 \(V^\pi(h)=\mathbb E[G_t\mid h]\)。只有满足相应加权均值等于普通均值的条件时二者才一致。若分母为 0，score 几乎处处为零，此局部问题不需要选择唯一 baseline。[81]

\[ b^\ast =\frac{0.25\cdot2\cdot(0.75)^2+0.75\cdot0\cdot(-0.25)^2} {0.25(0.75)^2+0.75(-0.25)^2} =\frac{0.28125}{0.1875}=1.5. \]

本例 \(b^\ast=1.5\) 恰使成功与失败的梯度估计都为 0.375，故方差为 0；这是单步、确定性奖励构造的特殊结果，不能外推到一般任务。此式只最小化固定历史、局部单步的协方差迹，不宣称最小化完整多步 \(\sum_t\gamma^t(G_t-b(h_t))g_t\) 的方差；后者还包含跨步协方差。固定步的 \(\gamma^t\) 只是统一缩放，不给一般省略外层折扣提供理由。

对教学代码任务，最终测试全通过为 1、真实任务失败为 0；删测试文件不能算成功。将整条成功路径都加概率是粗粒度信用：它可能连带强化一次多余读取、错误补丁和后续恢复。细化信用要额外信息，而不只是改优化器。reward 的内容见第四章。

环境输出不是策略选择，因此通常不进入 policy loss 的 response mask。环境失败是否算任务失败也需先定义；不能让基础设施宕机的 rollout 变成模型“动作不好”的标签。

PPO 的分支交接：πold 采样并保存 reward、动作和 old log-prob；同一轨迹一份送冻结 value → TD / GAE → 固定优势，另一份送当前 actor 重算概率 → current / old ratio。优势不生成 ratio，二者在 min / clip 处汇合；critic 另对固定回报标签回归，reference KL 是独立设计项。完整数据与梯度路径见训练分支图。

PPO 与 GAE：学习一个状态价值来降低方差

相关原论文 / 官方资料：PPO；GAE。

PPO 用采样策略 πold 的 rollout 更新 πθ，critic 估计未来回报。GAE 将不同长度的 TD residual 混合，在价值误差与采样方差之间取舍。[1] [2]

完整 MC 不用 value 代替未来奖励，往往方差较大；TD 用冻结下一 value 替代尚未采样的后续，可能降低采样波动，但引入 bootstrap 误差。下面统一简记 \(V(h)=V_{\rm rollout}(h)\)，是生成估计时冻结的近似值，不是当前更新中的 \(V_\phi\)，也不自动等于真实 \(V^\pi\)。

先看 n-step 回报替换了哪段未来

从当前步 \(t\) 起，到第一个真实终止或收集片段边界还有 \(L\ge1\) 个决策；不跨真实终止。对 \(n=1,\ldots,L\)，前 \(n\) 步用真实采样奖励，其后接冻结 value：

\[ \begin{aligned} G_t^{(n)}&=\sum_{k=0}^{n-1}\gamma^k r_{t+k} +\gamma^n V(h_{t+n}),\\ A_t^{(n)}&=G_t^{(n)}-V(h_t). \end{aligned} \]

若 \(t+L\) 是真实终止，端点 value 取 0；若只是收集暂停且任务可继续，端点保留有效的冻结下一 value。\(n=L\) 只有在走到真实终止时才是完整 MC 回报减当前 baseline；暂停边界的 \(G_t^{(L)}\) 仍含 bootstrap，不能改叫纯 MC。边界合同见暂停与终止的对照。

相邻 value 抵消：n-step 优势就是 TD 残差和

在片段内写 \(\delta_j=r_j+\gamma V(h_{j+1})-V(h_j)\)，端点 value 按刚才的边界处理。以两步为例，中间的 \(+\gamma V(h_{t+1})\) 与 \(-\gamma V(h_{t+1})\) 恰好抵消：

\[ \begin{aligned} \delta_t+\gamma\delta_{t+1} &=r_t+\gamma V(h_{t+1})-V(h_t) +\gamma r_{t+1}+\gamma^2V(h_{t+2})-\gamma V(h_{t+1})\\ &=r_t+\gamma r_{t+1}+\gamma^2V(h_{t+2})-V(h_t) =A_t^{(2)}. \end{aligned} \]

一般 \(n\) 步同理：第二个 value 和的每项，除首项外，都与第一个 value 和的前一项相消，只留当前 value 和端点 bootstrap：

\[ \begin{aligned} \sum_{k=0}^{n-1}\gamma^k\delta_{t+k} &=\sum_{k=0}^{n-1}\gamma^k r_{t+k} +\sum_{k=0}^{n-1}\gamma^{k+1}V(h_{t+k+1}) -\sum_{k=0}^{n-1}\gamma^kV(h_{t+k})\\ &=\sum_{k=0}^{n-1}\gamma^k r_{t+k} +\gamma^nV(h_{t+n})-V(h_t) =A_t^{(n)}. \end{aligned} \]

有限 L 片段的 GAE：最后一项收齐剩余权重

\(\lambda\in[0,1]\) 控制多步误差的混合，不是权重衰减或到达率。有限片段不能只截断无限几何权重，否则总权重不为 1；前 \(L-1\) 个 n-step 优势用几何权重，最后的 \(A_t^{(L)}\) 收齐尾部：

\[ \begin{aligned} \hat A_t &=(1-\lambda)\sum_{n=1}^{L-1}\lambda^{n-1}A_t^{(n)} +\lambda^{L-1}A_t^{(L)},\\ (1-\lambda)\sum_{n=1}^{L-1}\lambda^{n-1}+\lambda^{L-1}&=1. \end{aligned} \]

代入 \(A_t^{(n)}=\sum_{k=0}^{n-1}\gamma^k\delta_{t+k}\)。一个 \(\delta_{t+k}\) 出现在所有 \(n\ge k+1\) 的优势中，把它收到的权重相加：

\[ \begin{aligned} \hat A_t &=\sum_{k=0}^{L-1}\gamma^k\delta_{t+k} \left[(1-\lambda)\sum_{n=k+1}^{L-1}\lambda^{n-1} +\lambda^{L-1}\right]\\ &=\sum_{k=0}^{L-1}(\gamma\lambda)^k\delta_{t+k}\\ &=\delta_t+\gamma\lambda\hat A_{t+1} \quad\text{（同一连续片段内部）}. \end{aligned} \]

方括号的有限几何和等于 \(\lambda^k\)；空和取 0、零次幂取 1，因此 \(L=1\) 和 \(\lambda=0/1\) 也成立。末端设置 \(\hat A_{t+L}=0\) 是停止优势递推，不等于清掉暂停边界的下一 value；该 bootstrap 已进入最后一个 \(\delta\)。令 \(d_t=1\) 表示真实终止，在不跨暂停边界的连续记录中可写回常见形式：

\[ \delta_t=r_t+\gamma(1-d_t)V(h_{t+1})-V(h_t),\qquad \hat A_t=\delta_t+\gamma\lambda(1-d_t)\hat A_{t+1}. \]

真实终止用 \(1-d_t=0\) 切断下一 value 与下一优势；收集暂停则须分别控制两路，见下方 \(b_t,c_t\) 开关。\(\lambda=0\) 只用一步 TD，\(\lambda=1\) 用片段内最长回报减 baseline：走到真实终止时是 MC，暂停时仍含端点 value。无限时域且收敛时才可使用无限几何混合；本章算例使用上面的有限公式。GAE 的 value 误差与 MC baseline 误差不是同一种替换，不能从baseline 零均值证明推出任意近似 GAE 无偏。[2]

旧策略采样，当前策略怎样复用数据

固定历史下，概率比只换当前动作的测度

固定一个旧策略访问到的历史 \(h\)，冻结 \(\pi_{\rm old}\) 和优势估计器。令 \(f(a)\) 是该历史下可积、在此比较中固定的动作函数，\(\rho(a)=\pi_\theta(a\mid h)/\pi_{\rm old}(a\mid h)\)。要求支持覆盖：凡当前策略概率非零的动作，旧策略概率也必须非零；若旧策略从未覆盖某个当前动作，就不能靠这个分母进行换测度。离散动作下逐项写出：

\[ \begin{aligned} \mathbb E_{a\sim\pi_\theta(\cdot\mid h)}[f(a)] &=\sum_a\pi_\theta(a\mid h)f(a)\\ &=\sum_a\pi_{\rm old}(a\mid h) \frac{\pi_\theta(a\mid h)}{\pi_{\rm old}(a\mid h)}f(a)\\ &=\mathbb E_{a\sim\pi_{\rm old}(\cdot\mid h)}[\rho(a)f(a)]. \end{aligned} \]

第二个等号只是乘除同一旧动作概率，最后按旧策略概率收起求和。actor 反传只通过当前分子，旧分母和采样优势都冻结；实际 \(\hat A_t\) 可以是有噪声的样本估计，不是对每个动作都已知的真优势。这条恒等式只处理给定旧历史的当前动作分布，没有把旧策略的历史访问分布变成新策略的，也没有重采样当前策略下的未来。PPO 据此构造局部代理目标；单步 ratio 没有完整校正状态访问分布，后续 min / clip 更不应被当作原始目标的精确换测度。[1]

\(\rho_t,\bar\rho_t\) 是决策 \(t\) 的原/裁剪概率比，\(\epsilon_{\rm low/high}\) 是相对 1 的无单位下/上幅度；clip 将数值限制到注明区间，min 取较小项。\(\mathbb E_{\rm old}\) 按旧策略数据平均，\(\hat A_t\) 在 actor 更新中固定，\(J_{\rm clip}\) 被最大化、loss 通常取其负号。接下来的 \(j(\rho,A)\) 是单样本代理项，\(\rho>0,A\) 简记该样本的比率与固定优势。

\[ \begin{aligned} \rho_t&=\frac{\pi_\theta(a_t\mid h_t)}{\pi_{\rm old}(a_t\mid h_t)},\\ \bar\rho_t&=\operatorname{clip}(\rho_t,1-\epsilon_{\rm low},1+\epsilon_{\rm high}),\\ J_{\rm clip}&=\mathbb E_{\rm old} \left[\min(\rho_t\hat A_t,\bar\rho_t\hat A_t)\right]. \end{aligned} \]

为什么clip要看优势正负

记 \(l_{\rm clip}=1-\epsilon_{\rm low}>0\)、\(u_{\rm clip}=1+\epsilon_{\rm high}\)，并取 \(0\le\epsilon_{\rm low}<1,\epsilon_{\rm high}\ge0\)。裁剪值 \(\bar\rho\) 在原比率低于下界时变成 \(l_{\rm clip}\)，高于上界时变成 \(u_{\rm clip}\)，区间内保持 \(\rho\)。关键不是“所有越界都截断”，而是乘上优势后，min 究竟选择哪一项：

\[ \begin{aligned} A\ge0:\quad \min(\rho A,\bar\rho A) &=A\min(\rho,\bar\rho) =A\min(\rho,u_{\rm clip}),\\ A<0:\quad \min(\rho A,\bar\rho A) &=A\max(\rho,\bar\rho) =A\max(\rho,l_{\rm clip}). \end{aligned} \]

正优势：乘上非负 \(A\) 不改变大小关系。下越界时 \(\rho<\bar\rho=l_{\rm clip}\)，min 选原比率；上越界时 \(\bar\rho=u_{\rm clip}<\rho\)，min 选上界，所以只有继续提高比率的上越界方向变平。\(A=0\) 时整个策略项为零。

负优势：乘上负 \(A\) 反转大小关系，所以 min 变成比率的 max。下越界时选 \(l_{\rm clip}A\)，不再继续奖励把比率压得更低；上越界时选原来的 \(\rho A\)，仍保留把该负优势动作比率拉回来的梯度。因此得到原分段式：

\[ j(\rho,A)= \begin{cases} A\min(\rho,1+\epsilon_{\rm high}),&A\ge0,\\ A\max(\rho,1-\epsilon_{\rm low}),&A<0. \end{cases} \]

clip限制继续奖励某个方向，不能保证KL上界。未采样动作、状态分布和多次参数更新仍会改变。reference KL、entropy项与critic loss另行定义，不由PPO这个名字自动决定。

λ 越小越依赖局部 value，越大越接近 Monte Carlo 回报；并非越大总是越好。critic 数据、更新频率和任务分布决定估计质量。Actor、critic、reference 和 reward model 是逻辑角色，是否各占一份模型或共享 backbone，由框架实现决定。

追问：baseline为什么不改变期望？历史固定时，baseline 乘 \(\nabla\sum_a\pi(a\mid h)=0\)；它须满足当前动作的统计独立条件，且在 actor 权重中停止梯度，后者不能替代前者。完整条件见baseline 证明。

追问：PPO区间外都没梯度吗？只截住正优势的上越界和负优势的下越界；反方向仍有梯度，clip也不是KL约束证明。

多轮 Agent 的 value 位置也要明确：是在动作前、生成 token 内还是回合后估值；tool observation 可以改变状态，但它的随机反馈不应被当成策略生成 token 逐个施加动作梯度。

RLOO 与 GRPO：用同题候选代替 learned baseline

相关原论文 / 官方资料：GRPO / DeepSeekMath。

对同一 prompt \(x\)，在固定采样策略和环境分布下条件独立地生成 \(G>1\) 条候选轨迹，得到回报 \(R_1,\ldots,R_G\)。本段证明中的 \(R_i=R(\tau_i)\) 使用同一回报口径，奖励过程也是轨迹的一部分；其他候选可估计同题 baseline，因此不一定要训练 critic。两种组优势为：

\(i,j=1,\ldots,G\) 遍历该题候选，\(R_i\) 是终评回报，\(\bar R,\sigma_R\) 是组均值和按分母 \(G\) 的总体标准差。\(A_i^{\rm RLOO},A_i^{\rm GRPO}\) 是两种候选优势，分母 \(\epsilon>0\) 是与回报同单位的稳定常数，区别于 PPO clip 幅度；无稳定项的教学值只用于非零标准差组。

\[ \bar R=\frac1G\sum_jR_j,\quad \sigma_R=\sqrt{\frac1G\sum_j(R_j-\bar R)^2},\qquad A_i^{\rm RLOO}=R_i-\frac1{G-1}\sum_{j\ne i}R_j,\quad A_i^{\rm GRPO}=\frac{R_i-\bar R}{\sigma_R+\epsilon}. \]

RLOO：用整轨迹 score 检查留一 baseline 的独立性

令 \(\tau_i\) 为第 \(i\) 条完整轨迹，\(\tau_{-i}\) 为所有其他候选轨迹，\(\mathcal D_i\) 为本轨迹的可控决策索引集合。记 \(g_{it}=\nabla_\theta\log\pi_\theta(a_{it}\mid h_{it})\)，整轨迹 score 为 \(S_i=\nabla_\theta\log p_\theta(\tau_i\mid x)=\sum_{t\in\mathcal D_i}g_{it}\)，留一 baseline 为 \(B_i=\frac1{G-1}\sum_{j\ne i}R_j\)。环境观察不进入 \(\mathcal D_i\)；候选优势不是某个 token 的即时奖励。

先固定题目 \(x\)，按完整轨迹概率归一化得到 score 零均值；再固定其他候选轨迹，条件独立性使 \(\tau_i\) 的分布仍为原采样分布：

\[ \begin{aligned} \mathbb E[S_i\mid x] &=\sum_{\tau_i}p_\theta(\tau_i\mid x) \nabla_\theta\log p_\theta(\tau_i\mid x)\\ &=\sum_{\tau_i}\nabla_\theta p_\theta(\tau_i\mid x) =\nabla_\theta 1=0,\\ \mathbb E[B_iS_i\mid x] &=\mathbb E_{\tau_{-i}\mid x} [B_i\,\mathbb E[S_i\mid x,\tau_{-i}]]\\ &=\mathbb E_{\tau_{-i}\mid x}[B_i\,\mathbb E[S_i\mid x]] =0,\\ \mathbb E[A_i^{\rm RLOO}S_i\mid x] &=\mathbb E[(R_i-B_i)S_i\mid x]\\ &=\mathbb E[R_iS_i\mid x] =\nabla_\theta\mathbb E[R_i\mid x]. \end{aligned} \]

这沿用可微、稳定支持、有限矩及固定环境/奖励的条件，等式在生成候选的采样策略参数处成立。它不只要求 baseline 公式“不写当前动作”，还要求固定题目后其他轨迹与本轨迹条件独立；相关生成、跨候选共享且未条件化的随机因素或依赖候选结果的筛选，不能直接套此证明。actor 将组权重停止梯度；之后用 PPO ratio / clip 多轮复用时，仍是另外的局部代理问题。[4]

含自身的组均值：有限 G 的缩放不能漏掉

组均值包含自己的 \(R_i\)，因此与本轨迹 score 相关，不能把它当作留一 baseline。先做纯代数展开，不需要把有限组均值近似成无限样本期望：

\[ \begin{aligned} R_i-\bar R &=R_i-\frac1G\left(R_i+\sum_{j\ne i}R_j\right)\\ &=\frac{G-1}{G}R_i-\frac1G\sum_{j\ne i}R_j\\ &=\frac{G-1}{G} \left(R_i-\frac1{G-1}\sum_{j\ne i}R_j\right)\\ &=\frac{G-1}{G}A_i^{\rm RLOO}. \end{aligned} \]

在刚才的条件独立、固定 \(G\) 与采样策略口径下，\(\mathbb E[\bar R S_i\mid x]=\frac1G\mathbb E[R_iS_i\mid x]\)，因此仅做组中心化的梯度期望为 \(\frac{G-1}{G}\nabla_\theta\mathbb E[R_i\mid x]\)，不是未经缩放的原始回报梯度。固定缩放可以显式补偿，但不能称“含自身 baseline 自动零均值”。

GRPO 再除以本组随机的 \(\sigma_R+\epsilon\)。标准差依赖自己的 \(R_i\)，与 \(R_iS_i\) 及组中心化权重相关，不能像固定常数一样提出期望；正的 \(\epsilon\) 只稳定分母，不恢复独立性。它进一步改变尺度和隐式任务权重，尤其奖励差很小的组可能被放大。GRPO 归一化不是原始 reward 梯度的通用无偏估计；具体效果须按 std 定义、筛选、mask 和聚合口径评价。

RLOO 用其他候选的均值避免自己的 reward 进入 baseline；GRPO 用组内中心化和标准差。它们节省显式 critic，却需要同一任务多次采样；单条长 episode 很贵时，省下的 critic 不能直接等价为总成本降低。[3] [4]

异质数据：标准化不能保证每个任务都有学习机会

下式只讨论同题 \(G\) 次独立、同成功率 \(p\in[0,1]\) 的 Bernoulli 终评；\(p\) 是单次成功概率，不是策略的完整概率向量。事件是组内至少一个成功且至少一个失败。

\[ P(\text{组内有成败差异})=1-p^G-(1-p)^G. \]

这是独立Bernoulli采样的补集：扣掉全成功和全失败。\(G=8\) 时，\(p=0.01/0.99\) 约7.7%，\(p=0.5\) 约99.2%；相关采样或连续奖励不适用这条二值模型。

每题除以自己的标准差还会改变隐式权重：微小但不可靠的奖励差也可能被放大。中心化只处理数值，不会消除任务梯度冲突或 completion bias。需逐域监控全零/全一组、奖励方差、有效动作 token 和错误类型。

先定义聚合图与公式的对象：\(i=1,\ldots,G\) 索引候选，\(t=1,\ldots,T_i\) 只遍历该候选有效策略 token，\(T_i>0\) 是其有效长度，\(\ell_{it}\) 在本节泛指已含优势、ratio、mask/正则的逐 token loss。\(T_{\rm fixed}>0\) 是预先固定的长度标尺，\(L_{\rm seq/token/fixed}\) 是三种替代聚合结果；padding 和工具观察不计入这些有效位置。

GSPO、CISPO、Soft SAPO：控制更新的对象不同

相关原论文 / 官方资料：PPO；GSPO；CISPO / MiniMax-M1。

本节仍用 \(i\) 索引候选、\(t\) 索引有效策略 token，\(a_{it},h_{it}\) 是目标动作与其历史，\(A_i\) 是固定候选优势。

GSPO 的 \(s_i\) 是 token log-ratio 平均后指数化的无单位几何比率，\(\bar s_i\) 是裁剪值，\(J_{\rm GSPO}\) 是候选平均代理目标。

CISPO 中 \(\rho_{it}\) 是 token 概率比，\(w_{it}\) 是裁剪后停止梯度的权重，\(A_{it}\) 是固定 token 优势；\(\ell_{it}\) 在 CISPO 重新表示 log-prob，不同于上节逐 token loss。mean 沿有效候选/token 聚合，具体权重与 clip 边界由原配方决定；sg 保留数值并阻断梯度。

\[ \begin{aligned} &s_i=\exp\!\left(\frac1{T_i}\sum_t\log \frac{\pi_\theta(a_{it}\mid h_{it})}{\pi_{\rm old}(a_{it}\mid h_{it})}\right),\\ &\bar s_i=\operatorname{clip}(s_i,1-\epsilon_{\rm low},1+\epsilon_{\rm high}),\\ &J_{\rm GSPO}=\frac1G\sum_i\min(s_iA_i,\bar s_iA_i). \end{aligned} \]

GSPO 在序列层裁剪长度归一化几何比率，缓解 token ratio 的不稳定和更新单位不一致。它不是完整轨迹 importance ratio 的乘积，也不保证对所有长程 off-policy 目标无偏。[7]

\[ \begin{aligned} w_{it}&=\operatorname{sg}(\operatorname{clip}(\rho_{it})),\\ \ell_{it}&=\log\pi_\theta(a_{it}\mid h_{it}),\\ J_{\rm CISPO}&\approx\operatorname{mean}_{i,t}[w_{it}A_{it}\ell_{it}]. \end{aligned} \]

\(\operatorname{sg}\) 表示stop-gradient；这是目标结构示意，具体边界与聚合见原配方。

MiniMax-M1 的 CISPO 在 clipped IS 系数上做 detach，再用 log-policy 梯度；不能把它描述为 PPO 的 min 两项裁剪。比率单位、权重边界和 token 聚合都需与报告一致。[8]

Soft SAPO 下式的 \(\rho,A\) 是固定样本的概率比与优势，\(f\) 是 ratio 的代理变换；\(\sigma(z)=1/(1+e^{-z})\) 是 sigmoid，\(u\) 是门控值。这里 \(\tau>0\) 是无单位斜率参数，不是前文轨迹 \(\tau\) 或生成温度；\(J\) 按原配方有效样本平均并最大化，正负优势可分别选择斜率。

\[ f(\rho)=\frac4\tau\sigma(\tau(\rho-1)),\quad J=\operatorname{mean}[f(\rho)A],\quad \frac{df}{d\rho}=4u(1-u),\quad u=\sigma(\tau(\rho-1)). \]

\(\sigma\) 是 sigmoid，\(u\in(0,1)\) 是门控值；此处 \(\tau>0\) 是门控斜率参数，区别于前面的轨迹 \(\tau\) 和生成 temperature。\(f(\rho)\) 是代理目标中的 ratio 变换，\(A\) 是固定优势。\(\rho=1\) 时 \(df/d\rho=1\)；\(\tau\) 越大，导数在远离 1 时衰减越快。正负优势可以选择不同的 \(\tau\)。

Soft Adaptive Policy Optimization 在远离 1 的 ratio 上平滑减弱梯度，而不是硬截断；正负优势可使用不同温度。原报告偏向对负优势采用更强抑制，但这是实验设置，不能宣称“soft”消除了所有偏差。缺失 A 或把 f 直接说成 log-prob loss 都会改变目标。[9]

GRPO 高频追问卡

1. 为什么 G 不能只背 8、16 或 64？

G 决定同题 baseline 的方差和二值 reward 出现混合成败组的概率，也近似线性决定 rollout 成本。DeepSeekMath 用 64、R1/DAPO 用 16、Dr.GRPO 与多个框架示例用 8，只能说明各自预算与任务选择。回答时给出 1-p^G-(1-p)^G，再说明极易/极难题更应调课程、动态采样或 reward，而不是无限加 G。

2. Global batch 到底按 prompt 还是 response 计？

两种口径都存在，必须写单位。若每步有 B 个 prompt、每题 G 条 rollout，则 trajectory batch 为 B×G。R1 的 32 prompts×16=512 trajectories 是一个 policy-update mini-batch；外层 8192 outputs 再拆成 16 批。micro-batch、DP 和 gradient accumulation 只是把 global batch 分摊到设备。

3. 为什么 GRPO 通常只做一个 inner epoch？

数据来自旧策略；重复更新越多，当前策略与 behavior policy 越远，importance ratio 长尾和 clipping 增加。单 epoch 用更多新 rollout 换取 on-policy 新鲜度。若多次复用，就要报告 ratio、clip fraction、ESS/接受率和 rollout correction。

4. KL β 为什么有时是 0.04，有时直接为 0？

DeepSeekMath 用 0.04、R1 用 0.001 锚定 reference；DAPO、Dr.GRPO、CISPO 在规则可验证推理中移除 KL 以减少探索限制。是否设 0 取决于 reward 是否可靠、是否需要保留通用能力和 reference 是否仍代表目标行为，而不是由“算法叫 GRPO”决定。

5. DAPO 为什么 clip low/high 用 0.20/0.28？

正优势低概率 token 很容易被标准 1.2 上界卡住，扩大 upper clip 给探索 token 更多上涨空间；lower clip 仍保持 0.2，避免负优势更新把动作概率快速压到接近 0。它主要针对 entropy collapse，不代表 upper 越大越好。

6. GSPO 的 clip 为什么只有 3e-4/4e-4？

GSPO 裁剪长度归一化 sequence ratio，GRPO 裁剪 token ratio，随机变量和数值尺度不同。Qwen 论文明确指出两者通常相差多个数量级；把 GSPO 的 0.0003 抄给 token-level GRPO 会造成完全不同的约束。

7. 为什么 Dr.GRPO 去掉 group std？

除以每题 std 会放大奖励差很小或本身噪声大的组，并产生题目难度相关权重。Dr.GRPO 保留中心化但移除 std scaling，同时用固定最大长度作 loss 分母，分别处理 difficulty bias 和 length bias。

8. Token-mean、sequence-mean 和固定分母怎么选？

Sequence-mean 让每条 response 总权重近似相同，长序列单 token 权重更小；token-mean 让每个有效 token 等权，长序列贡献更多总梯度；固定分母避免实际长度改变总尺度，但 padding/截断策略会进入目标。必须和任务希望按 episode 还是 token 加权一致。

9. Temperature=1 为什么常见，但不是默认真理？

Reasoning RL 需要足够探索，T=1 在 DeepSeek-R1、DAPO、Dr.GRPO 等公开配方中常见。若 base policy 太随机、格式脆弱或工具调用错误多，可降低 T 或先做 cold start；若组内输出高度重复，则同时检查 T、top-p、G、模板和 entropy，而不是只调一个参数。

10. 最大生成长度为什么是训练参数，不只是推理参数？

它决定可访问轨迹、截断 reward、loss mask、KV 容量和长短样本权重。突然扩长会改变训练分布；R1 和 MiniMax 都采用阶段式扩长。监控自然结束率、硬截断率、99 分位长度、重复循环和成功/token。

11. Dynamic sampling 会不会改变训练分布？

会。过滤全对/全错组提高有效梯度比例，却会削弱极易与极难题，并增加补采成本。必须记录 dispatch、生成、过滤、准入四层分布，给过滤前后难度和任务域占比。

12. 面试中如何在一分钟内讲完整 GRPO recipe？

按“数据→采样→奖励→优势→loss→优化→监控”回答：每题 G 条、T/top-p/最大长度；规则 verifier；组内中心化及是否除 std；ratio 单位、clip、KL、分母；global batch、LR、inner epoch；最后给有效组率、entropy/KL、ratio/clip、长度/截断和冻结终评。数字必须注明来自哪篇论文或哪个固定配置。
