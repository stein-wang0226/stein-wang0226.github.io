后续最值得独立展开的选题

选题独立文章应交付什么避免的误判
P0 · Harbor 任务质量与合成闭环任务 / 环境 / verifier 的合同，oracle、negative controls、审计与固定留出集；比较预算重分配和生成空间扩展把“更难”“更多”“能通过 oracle”直接称为有效训练数据
P0 · 长程 Agent 信用与异质 GRPO同基础策略、同工具和预算；改变信用方式，记录零方差组、verifier 分歧和逐域结果组内标准化已经平衡任务，或反思直接给出了真实因果贡献
P0 · 异步训练有效样本率完成顺序偏置、版本 lag、目标 token、MoE routing / kernel 对齐分别观测GPU 利用率增加就代表学习效率增加
P1 · 架构服务真实 Agent工具轮次、前缀命中、短轮返回、输入输出比、IO、队列和成功成本KV 某口径缩小就等于总成本同比缩小
P1 · GUI 与科学 Agent状态与恢复、确定性复现、数据划分、有效提交与科学正确性；绑定公开案例最终文件存在或自然语言解释流畅就代表任务完成
P2 · 优化器、深度和 kernelMuon 更新公式与正交化近似、数值精度、吞吐和等算力消融；loop / residual 路线分开对比从一则快讯或单一规模实验推断通用最优

本次完成前五个方向的机制综述和实验设计；Muon / loop / kernel 仍是后续选题，尚未完成独立数学与复现实验专题。新商用模型若没有公开结构和训练细节，只记录官方能力、版本和使用约束，不补猜测参数。

建议的维护节奏

每次快讯登记版本和来源；当一个方向出现不同团队的机制或可运行代码，再更新专题。每月复查 benchmark 与工具版本，过时结果保留快照并说明不可直接横比；每季度选择一个小规模实验，交付配置、原始轨迹、失败归因和成本，而不是只增加模型名称。
