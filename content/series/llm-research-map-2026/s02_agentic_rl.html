从算法名录转向四个设计维度

Agent RL的目标不仅要区分成功与失败，还要决定长轨迹的哪些动作学习、怎样处理过时采样、不同长度和难度如何计权。ARLArena把目标拆成advantage、ratio / clipping、loss aggregation和sampling / filtering，适合组织同预算比较。[16]

维度设计问题代表工作实现时记录
Advantage / 信用episode奖励怎样分配到token、turn、状态或知识条件GRPO；GiGPO；RLDS；KnowGPO；Single-Rollout SAPO奖励来源、分组、baseline、std与过程判断的误差
Ratio / clipping新旧策略比例在哪一级算，梯度怎样限幅PPO / GRPO；GSPO；CISPO；soft-clipping SAPO行为策略log-prob、目标策略、stop-gradient、clip范围
Loss aggregation按序列平均、全batch目标token平均还是常数分母原GRPO；DAPO；Dr. GRPO长短轨迹权重、有效mask、全局分母与多卡归约
Sampling / filtering哪些组、轨迹或token进入更新，付出了多少额外采样DAPO；SAMPO；CARM；异步staleness控制零方差组、过滤原因、lag、采样成本和剩余分布

换算法时若同时改了组大小、过滤、长度预算与loss分母，就不能把收益归因于算法名。PPO、DPO和GRPO基础推导仍见RL手册与训练链路第04章。

GRPO、GSPO、CISPO：三种不同的更新对象

GRPO：同题采样、组内比较

Aᵢ = (Rᵢ − mean(R₁…R_G)) / (std(R₁…R_G) + ε) ρᵢ,ₜ = exp(log πθ(aᵢ,ₜ | hᵢ,ₜ) − log πold(aᵢ,ₜ | hᵢ,ₜ)) surrogateᵢ,ₜ = min(ρᵢ,ₜ Aᵢ, clip(ρᵢ,ₜ, 1−εₗ, 1+εᵤ) Aᵢ)

这里展示最大化的clipped surrogate，省略KL项和聚合分母；训练代码若最小化loss要取负号。h包含合法历史，但优化mask通常只覆盖策略生成的动作 / 回复，不把环境返回当成策略动作。组内baseline省掉独立critic，却不自动获得步骤级信用。

DAPO调整上下clip范围、动态采样、token级聚合和超长处理；Dr. GRPO讨论reward std与长度归一化的偏差。三者应拆开查看。全batch目标token平均、逐序列平均和固定分母，会给长轨迹不同权重，不能统一标成一种“token loss”。[21] [22]

GSPO：长度归一的序列比例

sᵢ(θ) = exp[(1 / Tᵢ) Σₜ (log πθ(aᵢ,ₜ | hᵢ,ₜ) − log πold(aᵢ,ₜ | hᵢ,ₜ))] sequence surrogate = min(sᵢ Aᵢ, clip(sᵢ, 1−εₗ, 1+εᵤ) Aᵢ)

这是token ratio的几何平均，不是完整轨迹概率的连乘。多轮Agent必须说明T指response、turn还是episode及哪些token被mask；环境转移不能混进LM概率。GSPO提供稳定序列级更新的一种设计，没有证明它在所有Agent任务上最优。[20]

CISPO：限幅的是IS权重

J_CISPO ∝ Σᵢ,ₜ stopgrad(clip(ρᵢ,ₜ, lower, upper)) · Aᵢ,ₜ · log πθ(aᵢ,ₜ | hᵢ,ₜ)

概念式省略具体归一化与超参数。CISPO对importance weight限幅并stop-gradient，仍通过log-prob更新；它与PPO的min-clipped surrogate梯度不同。原始出处是MiniMax-M1，不能写成Kimi K2发明。[31]

异质数据：组内标准化为什么仍会不平衡

如果同题每次独立成功概率为p、组大小G，且reward只有0 / 1，则至少包含一个成功和一个失败、从而有非零组方差的概率为：

P(nonzero group variance) = 1 − pᴳ − (1−p)ᴳ G = 8：p = 0.5 → 99.21875% G = 8：p = 0.01 或 0.99 → 约7.7255%

以上是独立Bernoulli假设下的解析计算，不是实测数据；真实rollout相关、多级奖励和动态策略会改变有效组分布。

非常难与非常容易的任务都可能缺少学习信号。组内std归一化无法平衡学习机会，还可能把低幅噪声放大；除以每题std带来隐式任务权重。任务目标和梯度方向不同、长度和交互成本不同，也不会被一个z-score消除。DAPO的动态采样和Dr. GRPO的归一化分析分别针对其中部分问题。[21] [22]

需要按域 / 难度查看它能解释什么
成功率、零方差组、过滤率题目是不是极难 / 极易；过滤后训练分布怎样变化
有效目标token、长度、工具轮次、GPU / 环境时间长短任务的优化权重与计算投入是否一致
Verifier分歧、环境失败、未知失败标准化是否正在放大奖励噪声；坏题是否进入更新
逐域梯度贡献与能力回归混合目标是否冲突；总平均是否掩盖遗忘

建议先分层采样与校准verifier，再比较组内std、batch std及不除std的方案；所有方案同时报告新增采样成本。仅过滤零方差组可能造成课程和覆盖偏移，需要保留过滤前后的域分布。
