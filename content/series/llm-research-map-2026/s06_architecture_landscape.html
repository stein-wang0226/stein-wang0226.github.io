路由、残差与位置

文本与图像的路由correction bias分开更新，只影响选择，不替代原score混合权重；SwiGLU clamp为10。Single-Pass mHC扩为4路，以20步Sinkhorn处理混合约束，并使用上一block的input-mixing系数，融合pre-norm。报告的activation traffic 20d→10d只指该残差映射，不能写成总训练成本减半。Engram两个查表模块使用{2,3,4}-gram、8 hash heads和FP8，去掉原Engram的短卷积；推理host RDMA预取与RL rollout GPU驻留是不同放置策略。[1] §2.1、§2.4.1、§3.1–3.2

固定config登记YaRN factor 16、原始65536 / 最大1048576位置，普通RoPE theta 10000、压缩路径theta 160000，路由字段scoring_func=sqrtsoftplus。这些是发布checkpoint规格，不能反推所有训练阶段使用同一长度；其compress_ratios数组有43项，不将额外模块项算成43层主干。

训练配方、推理成本与证据缺口

v1报告45T多模态预训练，从64K开始直接稀疏训练、无dense warmup，34T时扩到1M；batch固定100.6M tokens，warmup 2000 steps，学习率2.6e-4保持到28T、cosine降至40T的2.6e-5、再保持到45T。二维linear矩阵用Muon，Q/K按head处理；RMSNorm等用AdamW，embedding / head / Engram用momentum与Sinkhorn。主KV的FP4 QAT发生在post-training，局部KV为FP8，不代表全模型训练或权重都是FP4。[1] §2.4、§3.1

DSpark是独立投机支路：3 blocks、窗口128、并行预测5位置；预训练主干完成后先冻结主干训练drafter，再在post-training联合训练但draft loss不回传主干。global缓存890 B/token由格式及共享计划推得，SWA、Engram、weights、workspace和恢复IO另计；bounded replay 128不是bit-exact。报告没有提供同预算隔离全部新模块的完整因果消融，也没有本章负载下的完整显存 / Agent成功成本。本章未执行模型实验。详细字节推导和恢复路径见缓存专例。

先理解四条历史访问路径

  • MLA：缩小每token的缓存表示，条目仍随历史增长。
  • GDN/KDA：将关联压入有限矩阵；global混合层仍保存KV。
  • DSA/QSA/MSA：保留可检索历史，减少本次读取候选；索引与gather另计。
  • SWA：直接读取窗口，远距离传播由多层结构与global层补充。

GDN → KDA：从整体遗忘到按通道控制

以下 \(q_t,k_t\in\mathbb R^{d_k}\)、\(v_t,o_t\in\mathbb R^{d_v}\) 均为列向量；\(t\) 为 token 位置，\(\beta_t\) 为修正幅度。\(A_t,I\) 是 \(d_k\times d_k\) 矩阵，\(\alpha_t\) 为标量保留系数，\(\boldsymbol\alpha_t\) 为 key 通道保留向量，Diag 将它放到对角线。\(S_t\in\mathbb R^{d_k\times d_v}\) 是递归状态，\(S_{t-1}\) 为上一位置的同一状态，输出 \(o_t=S_t^\top q_t\)。此处状态方向是架构主讲中 \(d_v\times d_k\) 状态的转置，读取方向也随之转置。

基础delta更新已在架构主讲展开。这里采用Kimi Linear的转置方向。GDN用标量遗忘；KDA将其扩成key通道的对角门控。[49] [48] §2–3

\[ \begin{aligned} A_t&=I-\beta_t k_tk_t^\top,\\ S_t^{\rm GDN}&=\alpha_t A_t S_{t-1} +\beta_t k_tv_t^\top,\\ S_t^{\rm KDA}&=A_t\operatorname{Diag}(\boldsymbol\alpha_t)S_{t-1} +\beta_t k_tv_t^\top. \end{aligned} \]

顺序算例：取 \(k=(1,1)/\sqrt2,\beta=1\)，对角gate \(D=\operatorname{Diag}(1,0)\)。只看旧状态的变换：

\[ A=\frac12\begin{bmatrix}1&-1\\-1&1\end{bmatrix},\quad AD=\frac12\begin{bmatrix}1&0\\-1&0\end{bmatrix},\quad DA=\frac12\begin{bmatrix}1&-1\\0&0\end{bmatrix}. \]

两者不同：先按通道遗忘再作rank-one修正，不能交换成另一算法。这里D含0用于展示代数差别，真实gate范围按实现限定。

K3的额外改动：log-decay下界−5与输出gate服务其chunk算法和数值范围；不能据此把KDA等同softmax Attention。有限状态的检索损失仍需global层与任务评测。[5] §2.1

3.8 的混合层与主干外查表

状态更新、GR 与 QSA 的分工

GDN的Q/K/V先短因果卷积，Q/K做L2 normalization；scalar decay保留旧状态，delta rule修正当前key对应的value，读取后经zero-centered RMSNorm与sigmoid输出gate。它把历史关联压进有限矩阵，不具备任意历史token的精确随机读取。QSA则保留global KV，由4 query index heads / 1 key head、head 128的indexer选择历史microblocks；未旋转key先平均池化再作partial RoPE，末尾不完整block补入main Attention。两条路径改变的对象不同。[45] §2.1

GR逐路RMSNorm，从全部4路预测elementwise read gate并平均得到module input；write gate每路为scalar，去掉mHC式的残差混合矩阵。GR融合并替代原pre-norm，不在图上再串联一个重复pre-norm。单个Layer 2的n-gram embedding增加查表容量，host prefetch降低等待的可能性，却仍受访问带宽与放置约束。[45] §2.2–2.3

配方与消融的实际条件

报告以Muon处理二维hidden矩阵；embedding、输出head、router及GR低秩投影保留AdamW，n-gram表使用不带weight decay的Adam，并重新拟合最优学习率 / batch。QSA在256K continued pre-training引入：先冻结主干，以dense Attention蒸馏indexer 1000 steps，LR 1e-3、每step 8×256K tokens，约2B tokens，再切换稀疏主干适配。报告测试1M能力不等于固定config默认上下文自动变成1M。[45] §2.1.2、§3

Attention消融用28层25B-A3B，400B tokens @4K + 80B @32K，固定每4层一个global槽，比较full、窗口128 SWA与GDN；GR另有25B-A3B / 560B对照。4倍optimal LR压力测试属于中等规模的特定设置，不能证明任何模型在4倍LR均稳定。7.6× prefill / 4.9× decode限QSA kernel：前者16K chunk / batch1，后者batch4 / next_n4，不是整个3.8的端到端速度。全部是团队消融，未独立重跑。[45] 图5–6、§2.2、§3

成本与未披露：递归state、QSA global缓存、indexer / gather、4路残差激活、51B host表和视觉encoder分别计量。当前读取报告未完整给出最终全部预训练token绝对数和视觉训练配方，不用相对预算或config补猜，也未得到同条件Agent成功成本。

序列状态、深度选择与专家并行

KDA为96 heads、head 128、conv 4，沿key通道先遗忘再delta修正，log-decay下界−5，读取经head-wise RMSNorm与full-rank sigmoid output gate。下界服务chunk算法的数值范围，不让它变成softmax Attention。K3 global采用NoPE MLA，512维latent缓存仍有token轴；K3.1 Gated DSA在其上加入32-head / 128维、top2048的indexer，固定config的RoPE维度0。NoPE通过KDA递归门控隐式表达顺序，不能再套一套未报告的YaRN。[5] §2.1 [47]

Block AttnRes沿深度读取embedding、已完成block summary与当前block partial sum：pseudo-query与RMS-normalized keys产生softmax权重，随后混合表示，避免固定累加全部历史层。K3以12层为一个AttnRes block，共8个（末块不满），加embedding最多9个summary来源；这个12层分组与4层Attention周期是不同分组。summary驻留、pipeline传输和partial sum仍有成本。[5] §2.2

Stable LatentMoE将routed专家的输入 / 输出维度缩到3584，而2 shared仍在7168完整宽度并行计算；routed聚合之后、up-projection之前插RMSNorm，才与shared输出相加。SiTU-GLU分别softcap gate线性因子和up分支，两个cap为4 / 25；QB按目标负载的score分位数更新expert bias，下一step生效、推理冻结。bias用于选择而不进入mixture weights，不能将“选择更均匀”等同为“所有专家同权重”。[5] §2.3

原生视觉与训练条件

MoonViT-V2为27层、约401M、patch14、12 heads，RMSNorm并去掉linear bias；从头以NTP训练，而非在完成文本模型后做单独对齐。图像和视频共享参数，分解帧内空间 / 帧间时间Attention并做temporal pooling，2×2 shuffle再将visual token缩至1/4，支持最高3584×3584输入。报告的from-scratch与SigLIP初始化比较限其预训练消融，不能泛化为任何视觉预训练都无用。[5] §2.4、图6

Per-head Muon拆分Q/K/V矩阵，与weight clipping和QB共同稳定训练；cosine warmup为总步数1%，weight decay 0.1。预训练8K→64K，cooldown 256K→1M。cosine / WSD对照固定minimum LR，但分别重新搜索最优peak LR和batch，不是直接共用同一超参；整体约2.5× scaling efficiency含架构、数据与配方的共同作用，不是KDA吞吐。部署量化将routed experts用MXFP4、激活MXFP8，shared、latent projections、router和Attention保留较高精度。[5] §2.5、§3.2–3.4

成本与未披露：KDA状态与逐token MLA / DSA缓存、AttnRes summaries、latent投影与EP通信都需另计。报告未披露完整预训练token绝对总量，K3.1新增global路径的全部受控消融也未给出；旧K3结果不重命名为K3.1结果。未做本地模型复现，继续推导见LatentMoE机制。

NVFP4 训练与后训练阶段

报告预训练20T，约15T侧重数据多样性、最后5T侧重质量；WSD先200B warmup到2.5e-4，最后5T按minus-sqrt降至2.5e-6，再做1M长度扩展。后训练依次SFT、RLVR、Multi-Objective OPD（MOPD）及MTP Boosting；Boosting冻结主干、只训练drafter以适应推理时草稿噪声，不将teacher带来的提升归因于Mamba。[33] §2.3–2.4、§3

失稳记录与服务数字的条件

第一次约8T失稳，团队定位local output gradient从FP32改BF16丢失MTP梯度，rollback到FP32后恢复；第二次约16T失稳原因未定，切BF16没有解决，提前anneal缓解。两个事件不能合并成“FP4导致所有失稳”或“高精度自动解决”。报告up-to 6×吞吐限GB200、8K输入 / 64K输出的最大吞吐设置：Ultra用TensorRT-LLM、对照用vLLM，并取有无speculation的最佳配置，非严格同runtime的架构因果测量。[33] §2.7、服务测量

文本、视觉与音频的汇入链路

视觉encoder为28层、24 local + 4 global、hidden1280、32Q / 8KV、head64、约681M，patch为2×16×16、merge2×2；local按row / column序列交替，周期global沟通跨区域，视觉塔以超过4T visual tokens的NTP训练。音频则先经24层tokenizer（12 SWA + 12 GA，hidden1024、约308M），得到20个RVQ codebooks、25Hz表示，再由6层约127M的patch encoder对每4 frames作局部双向Attention，拼接 / projection后为6.25Hz。两个音频阶段串联，视觉和音频与文本是并行输入分支。[56] §2.2–2.3

两阶段预训练、Muown 与 QAT

预训练先text再omni：Flash 48T = 26T text + 22T omni，Pro 30T = 27T + 3T，长度32K→256K，优化器AdamW。mid-training扩256K→1M，以Muown更新hidden矩阵，embedding / output head / router仍AdamW，并在该阶段引入MXFP4 QAT；随后较短SFT、大规模RL。mid-training优化器不能反写为全部预训练从头Muon，QAT也不能表述为全部算子FP4。[56] §3.1–3.2

成本与证据缺口：局部窗口KV与global KV、视觉 / 音频编码、RVQ token规则、drafter预测与target验证、QAT格式转换均需计量。当前报告整体能力与服务结果无法隔离单个模块贡献；未执行同target下drafter / QAT受控重跑，也未核实未发布固定config中的具体层序或norm细节。

这一家族特别适合研究同一主模型固定时，drafter、QAT与服务并发怎样改变接受长度和总成功成本；如果同时更换主干和后训练checkpoint，就只能评估系统整体。
