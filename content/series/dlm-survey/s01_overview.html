先解释模型在做什么，再给它分类

AR 按输出位置顺序生成；扩散按噪声状态迭代生成。训练时，AR 可以并行计算所有位置的 next-token loss；它的串行依赖主要出现在生成阶段。DLM 每轮可以预测多个位置，但仍需付出多轮去噪与状态重算的成本。

分类轴要问的问题可组合的选项
状态空间当前状态是什么？离散 token；连续 embedding；编码器 latent；两者联合
扰动核怎样破坏干净信息？mask 吸收；uniform 替换；连续高斯；所选概率路径
因子化哪些输出已经固定？全序列；块间 AR、块内去噪
预测对象网络输出什么？干净 token、噪声、score、VP v、FM 速度或离散后验
系统角色谁决定最终分布？独立生成器；AR 草稿器；统一模型内草稿与验证

因此“块扩散”和“连续扩散”可以同时成立；“预测范式”也不是与离散、连续互斥的第四流派。给一个新模型填完这五行，比背一个家族排名更有用。

四个 token 的生成算例

  • 潜在收益：多位置并行、可变填充顺序、编辑与补全接口。
  • 代价：去噪轮数、全局状态重算、块内相关性、训练与实际采样的差异。
  • 能力边界：双向可见不自动保证全局规划、事实正确或消除全部 reversal 错误；这些要通过任务实验验证。

路线演进，记机制而非型号

路线代表工作新增的能力或接口
离散概率建模D3PM → MDLM / SEDD → LLaDA / Dream转移矩阵 → 简化 mask loss 或分布比率 → 大规模训练与 AR 适配
块与缓存SSD-LM → BD3-LM / SDAR / Fast-dLLM固定前缀，当前块并行；训练 mask 和缓存规则要匹配
连续文本接口Diffusion-LM；COLA / TextLDM；ELF / LangFlow / Plaid；CADD / CCDDembedding、latent 与联合状态，分别处理离散解码误差
后训练d1、SPG、GDSD及偏好/轨迹方法界、路径和去噪器蒸馏，解决不同目标失配
服务协作DFlash、DSpark、AdaFlash；Nemotron / TiDAR并行候选与验证，或共享模型内两种模式

追问：DLM 一次前向能输出整段，为什么不一定快？输出的是一轮候选。还要数实际模型调用、每轮 token 数、前缀重算、验证和提交开销；单次调用也可能比 AR 单 token 调用贵。
