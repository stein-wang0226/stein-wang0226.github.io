本节符号：\(z_1\in\mathbb R^d\) 是文本的连续表示，\(\epsilon\) 为同维高斯噪声，\(z_t\) 为插值状态；此处 \(t=0\) 是噪声、\(t=1\) 是数据。\(u_\theta\) 为网络速度，\(\dot z_t\) 为路径速度，\(\|\cdot\|^2\) 为欧氏平方误差，CFM 为条件 Flow Matching。后面的 \(c\) 是给定上下文，\(v\) 是词表项；条件均值 \(\mathbb E[z\mid c]\) 与 token 概率 \(P(x=v\mid c)\) 是不同预测对象。

连续去噪之外，还要解决文本接口

连续语言扩散有两个学习问题：在连续状态上学习生成，再将状态转成离散文本。去噪 MSE 更低不自动意味着 token 更准确。

接口优势独有代价
Token embedding长度与位置直接对应embedding 几何与离散类别不等价，需要 rounding/概率头
Encoder latent能压缩或组织连续状态重建误差、额外 codec、先验与训练 latent 的分布差异
连续/离散联合连续状态与 token 相互提供条件两套扰动、噪声时间与跨模态条件需要对齐

线性路径：方向决定速度符号

本节固定噪声 t=0、数据 t=1。令 \(z_0=\epsilon\)、\(z_1=\operatorname{Enc}(x)\)，条件路径和监督速度为：

\[\begin{aligned} z_t&=(1-t)\epsilon+t z_1,\qquad \dot z_t=z_1-\epsilon,\\ \mathcal L_{\rm CFM} &=\mathbb E\|u_\theta(z_t,t)-(z_1-\epsilon)\|^2. \end{aligned}\]

取噪声 −1、编码值 3、t=0.25：\(z_t=0\)，条件速度为 4。Euler 教学步长 0.25 若使用此条件速度，下一状态为 1。真实推理不知道 z₁，网络学的是给定当前状态的平均条件速度；直线条件路径不保证实际边际流也是直线。

为什么 MSE 不能直接当 CE？

假设两个等可能 token 的 embedding 为 −1、1。平方误差最优预测是均值 0，它不对应任一原 token。离散 CE 的最优预测则为 (0.5,0.5)。两者都反映不确定性，但接口与采样行为不同。

\[\begin{aligned} \hat z_{\rm MSE}(c)&=\mathbb E[z\mid c],\\ p_{\rm CE}(v\mid c)&=P(x=v\mid c). \end{aligned}\]
  • 分类接口：输出词表分布并采样；最近邻和 argmax 是不同的确定性选择。
  • 解码器接口：从 latent 生成序列，解码器自身也有生成成本和误差。
  • 概率口径：连续终点的密度不是一个 token 的离散概率；argmax 单元上的积分通常才对应离散质量。
