把一次完整 forward 从输入算到输出

这是旧版完整前向示例的主讲位置。先沿训练链路走完每个张量，再手算一个小模型的中间值，最后对照 prefill、缓存解码和完整代码。旧版的训练、推理、参数与实现内容在这里接成一条线；原始页面源码完整保留供查证。

主体模型采用 bias-free MHA、相邻维配对 RoPE、Pre-RMSNorm、SwiGLU 和独立 LM head。它是便于推导的现代 decoder 示例；原始 Transformer 的 Post-LayerNorm、绝对位置编码和 encoder–decoder 结构需要分别辨认。

设 B 为 batch，T 为本次输入长度，S 为此前缓存长度，d 为 hidden，H 为 head 数，D=d/H 为每头维度，F 为 FFN 中间维度，V 为词表。完整PyTorch代码采用 d=32、H=4、D=8、F=64、V=97、层数2；逐步形状例和手算例使用各自明确列出的更小尺寸。

训练前向：整段输入怎样一步步变成 loss

固定一组贯穿全节的尺寸：B=2、T=3、d=4、H=2、D=2、F=8、V=5、L=2。B是样本数，T是输入token数，d是表示宽度，H/D是头数/每头宽度，F是FFN中间宽度，V是词表大小，L是层数。下方可运行代码采用更大的 d=32；计算顺序完全相同。

1. IDs → embedding → 第一个 Pre-Norm

取一个样本的输入ID为 [1,2,3]，另一个为 [2,4,1]。查表不做token之间的混合：每个整数选出一行可学习向量。每层有独立的Norm缩放参数，统计沿最后一维进行。

\(I\) 是 ID 张量，\(E\) 是 embedding 表，\(X_0=E[I]\) 是嵌入后的输入，\(X=X_{\ell-1}\) 是第 \(\ell\) 层的输入，\(U\) 是它经过第一次 RMSNorm 的结果。

\[ \begin{aligned} I&\in\{0,\ldots,V-1\}^{B\times T},\\ E&\in\mathbb R^{V\times d},\quad X_0=E[I],\\ X&=X_{\ell-1},\quad U=\operatorname{RMSNorm}_{\ell,1}(X). \end{aligned} \]

I为ID张量，E为embedding表，X₀和每层输入X均为 [2,3,4]；ℓ从1到L索引层。U是归一化结果，形状仍为 [2,3,4]。后面的QKV投影接收U，残差保留原始X。RMSNorm和RoPE的逐项定义见本节下方公式。

2. 三组投影 → 拆头 → 旋转Q/K

\(U\) 是上一节归一化后的输入，\(W_Q,W_K,W_V\) 是三个投影矩阵；\(\widetilde Q,\widetilde K,\widetilde V\) 是投影后、尚未拆头的张量，\(Q,K\) 是拆头后的 query/key，\(V_h\) 是拆头后的 value 张量（下标 \(h\) 表示头维，区别于词表大小 \(V\)）。

\[ \begin{aligned} \widetilde Q&=UW_Q,\quad\widetilde K=UW_K,\quad\widetilde V=UW_V,\\ Q&=\operatorname{splitHeads}(\widetilde Q),\\ K&=\operatorname{splitHeads}(\widetilde K),\quad V_h=\operatorname{splitHeads}(\widetilde V). \end{aligned} \]

按行向量右乘约定，W_Q/W_K/W_V各为 [4,4]；带波浪线的投影为 [2,3,4]。先reshape成 [2,3,2,2]，再交换序列/头维成 [2,2,3,2]。V_h是value张量，区别于词表大小V；splitHeads只重排维度，不新增参数。

对Q/K在位置p=0/1/2应用RoPE，得到Q_r/K_r，形状不变；V_h不旋转。RoPE是成对维度的线性旋转，不是给embedding加位置向量。同一内容向量的旋转内积引入相对位移；内容本身仍随上下文和层改变。

3. 打分 → 因果mask → softmax → 加权value

\(Q_r,K_r\) 是旋转后的 query/key，\(V_h\) 是上一节的 value 张量，\(D\) 是每头维度；\(S\) 是 query–key 打分矩阵，\(M\) 是因果 mask，\(A\) 是 softmax 后的注意力权重，\(O_h=AV_h\) 是每个头读取后的输出。

\[ \begin{aligned} S&=Q_rK_r^\top/\sqrt D,\\ A&=\operatorname{softmax}_{\rm key}(S+M),\\ O_h&=AV_h. \end{aligned} \]

S是每个头内的query–key分数，转置只交换最后两维；[2,2,3,2]×[2,2,2,3]得到 [2,2,3,3]。M在合法key处为0、未来位置为−∞，广播到各样本与头。softmax沿key维归一化，每个query的一行和为1。

T=3时的因果可见性：行是query位置，列是key位置
key 0key 1key 2
query 0可见屏蔽屏蔽
query 1可见可见屏蔽
query 2可见可见可见

A乘V_h：[2,2,3,3]×[2,2,3,2]得到O_h=[2,2,3,2]。A是“从哪些位置读取”的权重，O_h是读取后的表示，两者不是同一个张量。

4. 拼头 → 输出投影 → 两条残差与SwiGLU

\(O_h\) 是各头输出，\(\operatorname{mergeHeads}\) 沿头维拼回；\(W_O\) 是输出投影矩阵，\(X\) 是本层输入，\(H_{\rm mid}=X+O\) 是注意力残差，\(Z\) 是第二次 RMSNorm 的结果；\(W_g,W_u\) 是 SwiGLU 的门/上投影，\(G=\operatorname{SiLU}(ZW_g)\)，\(U_f=ZW_u\)，\(W_d\) 是下投影，\(\Delta_f=(G\odot U_f)W_d\) 是 FFN 输出。

\[ \begin{aligned} O&=\operatorname{mergeHeads}(O_h)W_O,\\ H_{\rm mid}&=X+O,\quad Z=\operatorname{RMSNorm}_{\ell,2}(H_{\rm mid}),\\ G&=\operatorname{SiLU}(ZW_g),\quad U_f=ZW_u,\\ \Delta_f&=(G\odot U_f)W_d,\quad X_\ell=H_{\rm mid}+\Delta_f. \end{aligned} \]

先将O_h变回 [2,3,2,2] 再拼成 [2,3,4]，右乘W_O=[4,4]。H_mid是第一条残差输出，Z是第二次Norm结果。W_g/W_u为 [4,8]，得到G/U_f=[2,3,8]；逐元素相乘后右乘W_d=[8,4]，得到Δ_f=[2,3,4]，才能与H_mid相加。

SiLU(z)=z·sigmoid(z)，⊙是逐元素乘法。FFN独立处理每个位置的通道；本层跨位置通信发生在Attention。L层各自重复以上运算，hidden形状始终为 [2,3,4]。

5. 最终Norm → LM head → 标签右移 → 标量loss

\(X_L\) 是最后一层输出的 hidden 状态，\(W_{\rm lm}\) 是 LM head 投影，\(Z_{\rm lm}\) 是 logit 张量，\(p_{b,t}\) 是样本 \(b\) 在位置 \(t\) 的下一 token 分布，\(I_{b,t+1}\) 是右移后的监督 token ID。

\[ \begin{aligned} Z_{\rm lm}&=\operatorname{RMSNorm}_{\rm final}(X_L)W_{\rm lm},\\ p_{b,t}&=\operatorname{softmax}(Z_{{\rm lm},b,t}),\\ \mathcal L&=-\frac1{B(T-1)} \sum_{b=1}^{B}\sum_{t=0}^{T-2}\log p_{b,t}[I_{b,t+1}]. \end{aligned} \]

W_lm=[4,5]，logits为 [2,3,5]；p_b,t是位置t预测下一个token的5类分布。对输入 [1,2,3]，位置0预测ID2，位置1预测ID3；没有额外标签时，位置2的logits不计入这次loss。两个样本各2个目标，总共4项平均得到标量。

PyTorch的Linear存储转置权重，因此head.weight为 [5,4]；这是存储约定差异。训练用真实前缀并行计算，不在每个位置采样再喂回。loss.backward()随后把梯度传回head、各block与embedding，optimizer.step()才更新参数。

完整数值算例：从两个token算到下一token的概率

教学假设：B=1、T=2、d=D=F=2、H=L=1，词表为[A,B,EOS]。输入[A,B]，embedding为x₀=(1,0)、x₁=(0,1)；Q/K/V/O和gate/up/down矩阵均取2×2单位阵，所有Norm的γ=(1,1)。为使手算聚焦计算链，本例单独关闭RoPE并令ε=0；各Norm输入非零。下方完整代码仍使用RoPE和ε=10⁻⁶。

LM head取行向量右乘矩阵 \(W_{\rm lm}=\begin{bmatrix}1&0&0\\0&1&0\end{bmatrix}\)。它把最终表示的两维作为A/B logits，EOS logit设为0。数值保留6位，计算过程不提前四舍五入。

\[ U=\begin{bmatrix}\sqrt2&0\\0&\sqrt2\end{bmatrix}, \quad Q=K=V_h=U,\quad S=\begin{bmatrix}\sqrt2&0\\0&\sqrt2\end{bmatrix}. \]

加mask后第一行只能读自己，A₀=(1,0)。第二行可以读两位置，A₁=softmax(0,√2)=(0.195570,0.804430)。下面跟踪第二个位置，完整算到预测输出。

输出解释：贪心会选B；按概率采样则仍可能输出A或EOS。若额外给定第二位置的监督目标为EOS，这一项NLL为 −log(0.160944586)=1.826695。这是人为指定的下一token目标；仅拿两token输入自移位，只能计算第一位置预测B的loss，不能凭空获得EOS标签。

复核条件：每行Attention权重和为1；第一个位置不读B；两条残差形状一致；词表概率和为1。修改B的embedding不应改变第一位置输出，却会改变第二位置输出。数值由标准库公式复算，不代表任何训练后模型的能力。

同一组参数的推理：prefill → 采样 → 缓存decode

恢复含RoPE的主例尺寸B=2、d=4、H=2、D=2、L=2。设prompt长度为3；缓存长度S只统计已经经过模型前向的token，刚采样出来的token还没有K/V。

环节输入与位置逐层Attention形状输出与缓存状态
PrefillID [2,3]；位置0/1/2Q/K/V [2,2,3,2]；scores [2,2,3,3]，用因果mask每层缓存K/V [2,2,3,2]；末位置logits [2,5]采样得到token3
第一次decode只输入token3：[2,1]；RoPE offset=3新Q/K/V [2,2,1,2]；拼历史后K/V [2,2,4,2]；scores [2,2,1,4]两条残差保持 [2,1,4]；head [2,1,5]采样token4；S=4
第二次decode只输入token4；offset=4scores [2,2,1,5]，输出context [2,2,1,2]head采样token5；S=5；继续到EOS或长度上限
\[ \begin{aligned} K_{\rm all}&=\operatorname{cat}(K_{\rm past},K_{\rm new}),\\ V_{\rm all}&=\operatorname{cat}(V_{\rm past},V_{\rm new}),\\ A_{\rm new}&=\operatorname{softmax}\! \left(Q_{\rm new}K_{\rm all}^{\top}/\sqrt D+M\right),\\ O_{\rm new}&=A_{\rm new}V_{\rm all}. \end{aligned} \]

cat沿序列维拼接；Q_new/K_new已用逻辑位置S旋转，V_new不旋转。随后拼头、W_O、第一条残差、Norm、SwiGLU、第二条残差与训练完全相同。各层分别保存自己的K/V；缓存不保存待生成token的“未来信息”。

为什么旧缓存可以复用：固定权重和位置规则、关闭训练随机性后，过去位置的因果表示不依赖未来token。整段执行[A,B]与先执行A、再带A的缓存执行B，应产生相同的B位置logits；下面代码同时验证单token和多token增量。

采样：给定温度τ>0，p=softmax(logits/τ)，再按配置进行top-k/top-p过滤并归一化。贪心直接取argmax；τ=0不应实际执行除零。常见repetition penalty对正logit除以ρ、对负logit乘以ρ，不能统一除以ρ，否则负logit反而上升；具体顺序与实现匹配。

单token、无padding且全部缓存合法时，可不另加因果mask；多token增量仍需限制每个query能见的key。全量重算的Attention为平方量级，单query读取历史为线性量级，但投影、FFN、权重读取和系统调度也占时间，不能据此给出固定整机加速倍数。

核心公式和代码对象逐项对应

Norm 的 \(\gamma\) 是逐维可训练缩放，\(\epsilon\) 防止除零，mean 沿 hidden 维平均，\(\odot\) 是逐元素乘法；\(N\) 在此为 Norm 函数。SwiGLU 式按列向量写，\(W_g,W_u\) 为 \(F\times d\)，\(W_d\) 为 \(d\times F\)，与代码的右乘转置权重等价。后面参数式的 \(N\) 改指参数元素数。

对象计算形状/条件
Q/K/V归一化输入分别乘投影矩阵[B,T,d] → [B,H,T,D]
RoPE每两个维度按位置频率旋转Q/K 旋转，V 不旋转；当前位置 S…S+T−1
scoresQKᵀ/√D，加因果约束再 softmax[B,H,T,S+T]；key 位置 ≤ query 位置
输出权重乘 V，拼头并投影[B,T,d]
SwiGLUSiLU(gate)×up，再 down两个 d→F 分支，一个 F→d

为便于对应残差路径，下式简记 \(N(x)=\operatorname{RMSNorm}(x)\)。

\[ \begin{aligned} \operatorname{RMSNorm}(x)&=\gamma\odot\frac{x}{\sqrt{\operatorname{mean}(x^2)+\epsilon}},\\ h&=x+\operatorname{Attn}(N(x)),\\ x'&=h+\operatorname{SwiGLU}(N(h)),\\ \operatorname{SwiGLU}(z)&=W_d[\operatorname{SiLU}(W_gz)\odot W_uz]. \end{aligned} \]

RMSNorm 不减均值；数值稳定依赖精度与 ε。Pre-Norm 提供残差梯度路径，不意味着无需 warmup。SwiGLU 无 bias 参数量为3dF，普通两矩阵 FFN 为2dF；同参数预算可把 SwiGLU 的 F 调小。

相邻配对 RoPE：缓存位置不能从零重启

\(p\) 为 token 逻辑位置，\(j=0,\ldots,D/2-1\) 为维度对编号；\(\omega_j\) 为弧度/位置的频率，\(c_j,s_j\) 为余弦/正弦，撇号表示旋转后的分量；\(x_{2j},x_{2j+1}\) 是第 \(j\) 对相邻维度分量。缓存节的 \(i\) 从 0 索引本次 query、\(j\) 索引历史与当前 key；\(\mathbf1\) 是可见性指示，层数用 \(L\)，标量训练 loss 也在其段落用 \(L\)。

\[ \begin{aligned} \omega_j&=10000^{-2j/D},\\ c_j&=\cos(p\omega_j),\quad s_j=\sin(p\omega_j),\\ \begin{bmatrix}x'_{2j}\\x'_{2j+1}\end{bmatrix} &=\begin{bmatrix}c_j&-s_j\\s_j&c_j\end{bmatrix} \begin{bmatrix}x_{2j}\\x_{2j+1}\end{bmatrix}. \end{aligned} \]

整段第4个 token 位置为3；先缓存3个 token 后继续输入时，offset 同样为3。缓存里的 K 已按原位置旋转，不重旋转。真实模型还可能采用半向量配对、不同 θ、部分旋转或位置缩放；加载权重必须匹配约定。

KV 缓存、因果 mask 与标签 shift

缓存复用已有 K/V。单 token decode 的 scores 是 [B,H,1,S+1]，整段是 [B,H,T,T]。对已处理的因果历史，旧表示不依赖未来，可直接复用；改写 prefix、位置、权重或上下文规则可能使缓存失效。

两 token 增量算例：已有位置0/1/2的缓存，再输入位置3/4。新 query3只读 key0…3，query4可读0…4。因而多 token 增量依然需要 mask；只有无 padding 的单 token decode 且缓存全为合法过去时，因果 mask 才可省略。

\[ \begin{aligned} M_{i,j}&=\mathbf 1[j\le S+i],\\ \ell_{b,t}&=-\log p_\theta(x_{b,t+1}\mid x_{b,\le t}),\\ L&=\frac{1}{B(T-1)}\sum_{b=1}^{B}\sum_{t=0}^{T-2}\ell_{b,t}. \end{aligned} \]

两种mask表示不要混用：这里的 \(M_{i,j}\) 是0/1可见性指示，对应代码里的布尔 allowed；前向公式中加到score的 \(M\) 则在可见处为0、屏蔽处为−∞。代码用 masked_fill(~allowed, -inf) 完成转换，不能直接把0/1矩阵加到score。已有3个缓存token、再输入2个时，两行allowed为[1,1,1,1,0]和[1,1,1,1,1]，只有第一行最后一个key被屏蔽。

代码里 labels 从 input_ids 复制，在 loss 中用 logits[:,:−1] 与 labels[:,1:] 做一次位移。不要预先位移 labels 后再切片一次。实际训练 padding/角色位置置 ignore_index，并按有效目标数归一化。

字节算例：头数和共享条件要明确

\[ M_{\mathrm{KV}}=2LBTH_{\mathrm{KV}}D\,b_{\mathrm{element}}. \]

2层、B=1、T=7、H_KV=4、D=8、FP32 4 bytes，K/V 共3,584 bytes。本例两矩阵均缓存 [1,4,7,8]。GQA 共享 KV 头但 query 头保持原数；repeat/broadcast 服务于计算，持久缓存按 H_KV 存。

  • 模型规格：Llama 3 8B 采用 GQA（32 query/8 KV），不是 MHA。32层、D=128、8K、BF16 未分片 KV 为1 GiB；80层70B、8 KV、同长度为2.5 GiB。
  • 共享：上述每请求账本未去重。服务系统可复用相同且兼容的 prefix；PagedAttention 改变存储管理，不改变注意力公式。
  • 成本：单次 Attention 从整段平方算术变为单 query 线性读历史；QKV/FFN、通信和排队另计，不能推出固定整机加速比。

模型配置参考 官方 8B config；来源规格与以上字节推导分开。完整容量/TP分片在服务主题。

参数账本与本例数量

\[ N=L(4d^2+3dF+2d)+2Vd+d. \]

本例 MHA 每层4d²，SwiGLU 3dF，两组 RMSNorm 2d；独立 embedding/head 共2Vd，最终 Norm 为d。代入 d=32/F=64/V=97/L=2，得到26,848参数。若 head 与 embedding 共享，少 Vd；GQA、bias、MoE 需另改公式。

完整 PyTorch：小模型、训练、缓存等价性与生成

复制下面一个代码块即可运行，需要 PyTorch。CPU 默认维度较小；不需要下载权重或数据。实现保留明确 mask 与缓存，未包含 padding、dropout、生产 fused kernel 或分布式训练。

import math
import torch
from torch import nn
from torch.nn import functional as F

class RMSNorm(nn.Module):
    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.eps = eps
        self.weight = nn.Parameter(torch.ones(dim))

    def forward(self, x):
        # FP32 统计，输出回到输入dtype；BF16/FP16仍有舍入。
        xf = x.float()
        y = xf * torch.rsqrt(xf.square().mean(-1, keepdim=True) + self.eps)
        return y.to(x.dtype) * self.weight

class SwiGLU(nn.Module):
    def __init__(self, dim, hidden_dim):
        super().__init__()
        self.gate = nn.Linear(dim, hidden_dim, bias=False)
        self.up = nn.Linear(dim, hidden_dim, bias=False)
        self.down = nn.Linear(hidden_dim, dim, bias=False)

    def forward(self, x):
        return self.down(F.silu(self.gate(x)) * self.up(x))

def apply_rope(x, offset, theta=10000.0):
    # x [B,H,T,D]；相邻偶/奇维配对，D须为偶数。
    T, D = x.shape[-2:]
    freq = theta ** (-torch.arange(0, D, 2, device=x.device).float() / D)
    pos = torch.arange(offset, offset + T, device=x.device).float()
    angle = pos[:, None] * freq[None, :]
    cos, sin = angle.cos().to(x.dtype), angle.sin().to(x.dtype)
    xe, xo = x[..., 0::2], x[..., 1::2]
    return torch.stack((xe * cos - xo * sin,
                        xe * sin + xo * cos), dim=-1).flatten(-2)

class Attention(nn.Module):
    def __init__(self, dim, heads):
        super().__init__()
        assert dim % heads == 0 and (dim // heads) % 2 == 0
        self.heads, self.head_dim = heads, dim // heads
        self.qkv = nn.Linear(dim, 3 * dim, bias=False)
        self.out = nn.Linear(dim, dim, bias=False)

    def forward(self, x, past=None, use_cache=False):
        B, T, C = x.shape
        q, k, v = self.qkv(x).chunk(3, dim=-1)
        q, k, v = [z.view(B, T, self.heads, self.head_dim).transpose(1, 2)
                   for z in (q, k, v)]
        S = 0 if past is None else past[0].shape[-2]
        q, k = apply_rope(q, S), apply_rope(k, S)
        if past is not None:
            k = torch.cat((past[0], k), dim=-2)
            v = torch.cat((past[1], v), dim=-2)
        scores = q @ k.transpose(-1, -2) / math.sqrt(self.head_dim)
        query_pos = S + torch.arange(T, device=x.device)
        key_pos = torch.arange(S + T, device=x.device)
        allowed = key_pos[None, :] <= query_pos[:, None]  # bool [T,S+T]
        scores = scores.masked_fill(~allowed, float("-inf"))
        probs = F.softmax(scores.float(), dim=-1).to(q.dtype)
        y = (probs @ v).transpose(1, 2).contiguous().view(B, T, C)
        return self.out(y), (k, v) if use_cache else None

class Block(nn.Module):
    def __init__(self, dim, heads, ffn_dim):
        super().__init__()
        self.norm1, self.norm2 = RMSNorm(dim), RMSNorm(dim)
        self.attn, self.ffn = Attention(dim, heads), SwiGLU(dim, ffn_dim)

    def forward(self, x, past=None, use_cache=False):
        delta, cache = self.attn(self.norm1(x), past, use_cache)
        x = x + delta
        return x + self.ffn(self.norm2(x)), cache

class TinyTransformer(nn.Module):
    def __init__(self, vocab=97, dim=32, heads=4, ffn_dim=64, layers=2):
        super().__init__()
        self.embed = nn.Embedding(vocab, dim)
        self.layers = nn.ModuleList([Block(dim, heads, ffn_dim)
                                     for _ in range(layers)])
        self.norm = RMSNorm(dim)
        self.head = nn.Linear(dim, vocab, bias=False)  # 本例不共享权重

    def forward(self, ids, past_kvs=None, use_cache=False):
        if past_kvs is None:
            past_kvs = [None] * len(self.layers)
        if len(past_kvs) != len(self.layers):
            raise ValueError("one cache per layer required")
        x = self.embed(ids)  # [B,T] → [B,T,d]
        caches = []
        for layer, past in zip(self.layers, past_kvs):
            x, cache = layer(x, past, use_cache)
            caches.append(cache)
        return self.head(self.norm(x)), caches if use_cache else None

torch.manual_seed(7)
model = TinyTransformer()

optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)

                       ids[:, 1:].reshape(-1))

torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
optimizer.step()

model.eval()
with torch.inference_mode():
    full, _ = model(ids)
    # 逐token缓存应与整段因果前向一致（浮点容差内）。
    past, chunks = None, []
    for t in range(ids.shape[1]):
        one, past = model(ids[:, t:t+1], past, use_cache=True)
        chunks.append(one)
    incremental = torch.cat(chunks, dim=1)
    torch.testing.assert_close(full, incremental, atol=2e-5, rtol=2e-5)
    # 多token增量也必须保持因果性。
    first, past = model(ids[:, :3], use_cache=True)
    rest, past = model(ids[:, 3:], past, use_cache=True)
    torch.testing.assert_close(full, torch.cat((first, rest), dim=1),
                               atol=2e-5, rtol=2e-5)
    # 生成：prefill一次，其后只送最新token，继续同一cache。
    generated = ids[:1, :3].clone()
    scores, past = model(generated, use_cache=True)
    for _ in range(4):
        next_id = scores[:, -1].argmax(-1, keepdim=True)
        generated = torch.cat((generated, next_id), dim=1)
        scores, past = model(next_id, past, use_cache=True)
    print("generated", generated.tolist())
