一条学习链：图像怎样变成 patch 表示，图文目标怎样产生梯度，视觉条件怎样进入 LLM，最后怎样验空间、视频与业务任务。架构原理在本页展开，型号和论文清单按需查看；面试前直接使用短答卡。

1. 核心链路：视觉表示→对齐→条件生成

1.1 从像素到 token：形状与预算

设图像经 processor 后为 H×W、C 个通道，patch 边长 P，H/W 可被 P 整除。一个 patch 展平为 CP² 维，经共享线性层变成 dv 维；等价于 kernel=stride=P 的卷积。加空间位置后由 encoder 让 patch 交互。

\[ \begin{aligned} N&=(H/P)(W/P),\\ X_{\rm patch}&\in\mathbb R^{N\times CP^2},\\ Z_0&=X_{\rm patch}W_p+E_{\rm pos},\\ W_p&\in\mathbb R^{CP^2\times d_v}. \end{aligned}\]
算例：224×224、P=14 得 16×16=256 patch；336×336 得 24×24=576。CLS 若存在再加 1；给 LLM 的 token 数还要扣掉被舍弃的 CLS，并应用 merge/resampler，不能直接把 encoder patch 数当最终长度。
  • CLS / pooling：汇总全局表征适合分类/图文匹配；patch 级输出保留空间条件，具体取层和归一化由 checkpoint 决定。
  • CNN / Swin：局部性与层级结构提供不同归纳偏置；全局 ViT 更灵活，但不是所有任务都更优。
  • 预训练目标：CLIP/SigLIP 对齐图文；MAE 重建 masked 图像；DINO 类自蒸馏学表示；SAM/SAM2 学可提示分割及视频记忆。它们不能用同一“视觉能力分数”代替。

来源：ViT、CLIP。

1.2 CLIP：为什么匹配对的相似度会上升？

\(i,j,k=1,\ldots,N\) 索引 batch 中配对图文；\(S,p,q\) 均为 \(N\times N\) 矩阵。\(p_{ij}\) 按行归一，\(q_{ij}\) 按列归一；\(\mathbf1[i=j]\) 为匹配对指示。\(\sigma(z)=1/(1+e^{-z})\) 为 sigmoid，SigLIP 的 \(b\) 是可训练 bias。

batch 有 N 个配对 (Ii,Ti)。双塔输出向量分别 L2 归一为 vi/uj，learnable scale a=exp(t) 相当于逆温度。相似度 Sij=a·viᵀuj，这里已经缩放一次，loss 中不要再除温度。

\[ \begin{aligned} p_{ij}&=\frac{e^{S_{ij}}}{\sum_k e^{S_{ik}}},\qquad q_{ij}=\frac{e^{S_{ij}}}{\sum_k e^{S_{kj}}},\\ L_{\rm CLIP}&=-\frac1{2N}\sum_i \bigl(\log p_{ii}+\log q_{ii}\bigr). \end{aligned}\]

每张图在行方向识别自己的文本，每段文本在列方向识别自己的图。将一行当分类 CE，logsumexp 的导数就是 softmax；因此两方向合起来的 score 梯度为：

\[ \frac{\partial L}{\partial S_{ij}} =\frac{p_{ij}+q_{ij}-2\mathbf1[i=j]}{2N}. \]
两对算例：S=[[2,0],[0,2]]。正确匹配概率 σ(2)=0.8808，双向平均 loss≈0.1269；每个对角 score 梯度≈−0.0596，非对角≈+0.0596。梯度下降会抬匹配 score、压不匹配 score，但总梯度还要通过 scale、向量归一和两个 encoder。
  • 负例：标准单正例 batch 每行有 N−1 个不匹配候选；重复 caption/近重复图像可能形成 false negative。
  • zero-shot 分类：将类别写成文本 prompt，编码后与图像比较；prompt 模板、类别描述和分布决定结果。
  • 能力边界：图文全局匹配可能忽略数量、属性、关系与长文本细节。更大 batch 也不保证所有场景更好。

1.3 SigLIP：省去 softmax，仍需管理负例

令匹配标签 yij∈{−1,+1}，score 变为 Sij=a·viᵀuj+b。每个 pair 用 logistic loss，bias 控制初始正/负类倾向。原论文常见聚合按 N 归一全部 pair；采样负例或改变聚合分母时，要一起改变权重并重新调参。

\[ \begin{aligned} \ell(y,S)&=\log(1+e^{-yS})=-\log\sigma(yS),\\ \frac{\partial\ell}{\partial S} &=-y\,\sigma(-yS),\\ L_{\rm SigLIP}&=\frac1N\sum_{i,j}\ell(y_{ij},S_{ij}). \end{aligned}\]
同一 pair：正例 y=1、S=2，loss≈0.1269、导数≈−0.1192；负例 y=−1、S=2，loss≈2.1269、导数≈+0.8808。负例的错误高相似度会受到较强惩罚；不需要计算所有候选共同的 softmax 分母。
比较轴CLIPSigLIP

负例与通信全局负例通常交换 embedding仍可交换负例；可分块累加，不等于无需跨卡

接口状态与计算主要取舍例子

“原生”不是精确定义。有些系统强调联合训练，有些强调统一词表/序列，有些强调端到端多模态能力。说明图像如何编码、在哪里融合、预测什么，才能比较；CoCa 还结合对比和 captioning 目标，不宜只归成普通 PaLI 式 E-D。

1.5 Connector：维度映射与信息预算

\(Z\in\mathbb R^{N\times d_v}\) 为视觉表示，\(W_1,W_2\) 分别为 \(d_v\times m,m\times d_L\)，\(b_1,b_2\) 为偏置；\(P_{\rm MLP}\) 是参数数，区别于 patch 边长 \(P\)。单头 query 式的 \(K(Z),V(Z)\in\mathbb R^{N\times d}\)，\(M\) 为 query 数；语言梯度式的 \(\theta_v,Z_v,Z_{\rm lang}\) 为视觉参数、视觉输出和语言侧条件表示。

MLP 对每 patch 独立映射，保持 N：dv→m→dL。可学习 query 通过 cross-attention 聚合变长视觉输入，输出 M 个语言条件 token。两者改变信息路径和预算，并非谁在所有任务都更优。

\[ \begin{aligned} Z_{\rm MLP}&=\operatorname{GELU}(ZW_1+b_1)W_2+b_2,\\ P_{\rm MLP}&=d_vm+md_L+m+d_L,\\ Z_{\rm query}&=\operatorname{softmax} \left(\frac{QK(Z)^\top}{\sqrt d}\right)V(Z),\\ Z_{\rm query}&\in\mathbb R^{M\times d},\quad Q\in\mathbb R^{M\times d}. \end{aligned}\]
参数与长度例：dv=1024、m=dL=4096 时两层 MLP 共 20,979,712 参数；576 个 patch 仍输出 576 个 token。若 query resampler 输出 64 个 token，语言侧长度缩小 9 倍，但它必须把细节汇入 64 个向量，还增加自身 attention 计算。
  • MLP：映射维度、非线性适配；保 token 适合细节，但长输入昂贵。
  • Q-Former / Perceiver：学固定 query 聚合；BLIP-2 与 Flamingo 的具体层结构/目标不同。
  • spatial merge：按相邻 grid 重组再投影，常见 2×2→1；保局部结构仍可能丢细节。
  • 判断：LLaVA-1.5 支持简单 MLP 是有力基线，不能据此宣布连接器全局最优。等 encoder、数据、LLM 与视觉 token 预算做对照。

来源：LLaVA-1.5、BLIP-2、Flamingo。

1.6 条件生成 loss：视觉标签被 mask，梯度仍能过去

图像 embedding、用户文本和历史观察组成条件 c，assistant 回答为 y。训练目标只在有效回答 token m_t=1 上计算 CE；视觉没有文本 label 不意味着 encoder 没有梯度，它通过后续回答对视觉条件的依赖接收反传，除非被冻结/detach。

\[ \begin{aligned} \ell_t&=-\log p_\theta(y_t\mid c,y_{\lt t}),\\ L&=\frac{\sum_t m_t\ell_t}{\sum_t m_t},\\ \nabla_{\theta_v}L &=\frac{\partial L}{\partial Z_{\rm lang}} \frac{\partial Z_{\rm lang}}{\partial Z_v} \frac{\partial Z_v}{\partial\theta_v}. \end{aligned}\]

分母条件：\(m_t\) 还要排除 padding、忽略标签和无效回答位置，且 \(\sum_t m_t>0\) 才能使用这份平均loss。无有效回答的样本应在准入/reduction前显式处理并计入拒收记录，不能除以0，也不能把它记成一次成功的零loss监督；跨样本或跨rank聚合时仍按声明的有效目标数计算。

1.7 分辨率、merge 与视频：逐项数 token

\(n_{\rm crop/thumb}\) 为裁剪图/缩略图数量，\(R\) 为每张 tile 边长（像素），\(r\) 为每空间轴的 merge 倍数；\(F\) 为视频帧数，\(N_f\) 为第 \(f\) 帧贡献的视觉 token 数。坐标式的 \(s_x,s_y\) 是 resize 比例，\(o_x,o_y\) 是原图 crop 偏移；坐标先统一到像素单位再逆映射。

tiling 将大图映到若干固定大小 crop，可能另加 thumbnail；native dynamic resolution 让 encoder 读可变 patch grid，并使用适配位置与 merge。二者都涉及 resize/padding/预算约束，动态不等于原图信息无损或无限分辨率。

\[ \begin{aligned} N_{\rm tiles}&=(n_{\rm crop}+n_{\rm thumb})(R/P)^2,\\ N_{\rm merge}&=(H/P)(W/P)/r^2,\\ N_{\rm video}&=\sum_{f=1}^{F}N_f+N_{\rm timestamp}. \end{aligned}\]
两个策略例，均不代表官方 processor 默认：672×336 图像切成 2 个 336px crop，加 1 thumbnail，P=14 且不压缩，给出 3×576=1728 patch。另一图 672×448、P=14，原 grid=48×32=1536，2×2 merge 后为 384。两边长翻倍后 grid token 四倍、全局 attention 的 score 数约 16 倍；window attention 和独立 crop 有不同成本。

M-RoPE：给 RoPE 的不同频率维度绑定时间、高、宽坐标，文本可令三坐标一致；分配比例按模型配置，不一定三等分。Qwen2.5-VL 还处理真实时间和动态帧率；Qwen3-VL 的交错时空与 DeepStack 需按具体报告理解，不等同 Qwen3-Omni。

  • 视频采样：均匀、变化/关键帧、分层检索各有遗漏；按任务时长、事件密度和预算选，不存在通用 32/64 帧最好。
  • 视频评测：分别测定位、先后、持续时间、因果和长程证据；needle 成功不能代替视频理解。
  • 服务账本：encoder 计算、语言 prefill、KV、timestamp 与 padding 分开；增分辨率并不只增加线性成本。

来源：Qwen2-VL、Qwen2.5-VL、LLaVA-OneVision。

1.8 MoE、grounding、幻觉与多模态 RAG

MoE 的新问题是模态负载。视觉和文本 token 的数量/分布不同，可能使路由不均。分别测每模态分派、容量/drop、通信、active/total 参数；更多总参数不直接推出更低总服务成本。基础路由推导见架构主讲。

grounding：输出 bbox 的文本数字、离散 bin 或回归值，需要注明坐标范围、原图/处理图、crop 偏移和逆变换。IoU=(交集面积)/(并集面积)；框格式合法与指到正确对象是两个检查。

\[ \begin{aligned} x_{\rm orig}&=x_{\rm crop}/s_x+o_x,\\ y_{\rm orig}&=y_{\rm crop}/s_y+o_y. \end{aligned} \]
坐标例：原图 crop 从 x=100 开始，crop resize 放大 2 倍，模型在处理图报 x=40，则原图 x=40/2+100=120。漏 crop offset 会在真实页面点击错误对象。padding 还需先减 padding。

逆变换顺序：若输出是归一坐标或离散bin，先按工具合同还原处理图像素，再减左/上padding，再除以resize比例，最后加原图crop偏移。补充二维复算：处理图像素为(40,30)，左/上padding为(8,6)，resize比例均为2，原图crop原点为(100,50)，得到原图坐标 \(((40-8)/2+100,(30-6)/2+50)=(116,62)\)。这是像素坐标教学例；GUI工具若使用窗口坐标、逻辑点或屏幕像素，还须另用窗口/显示缩放元数据映射，不能直接把原图坐标当点击接口。动作前也要确认截图时间、焦点与布局未过期。

视觉幻觉：物体、属性、关系分别评；POPE 的 yes/no 对象存在探测不能覆盖全部。数据去错、grounding 监督、分辨率与偏好训练可改失败率，但 CoT、自检、引用都不保证忠实。

展开 VCD 的正确对比对象与限制

VCD 中 \(v,v'\) 为原图/扰动图，\(z(v)\) 为词表 logits，\(\alpha\) 为对比分支权重；\(w,u\) 为词表项，\(M\) 为原图条件下最大 token 概率，\(\eta\) 为相对概率阈值，\(\mathcal A\) 为允许采样集合。ColPali 式的 \(q_i,d_j\) 则是同维查询/page patch embedding，\(N_q,N_d\) 为各自数量，内积再按每个查询 token 的最大匹配求和。

原 VCD 将原图 v 与噪声扰动图 v′ 的 logits 对比，抑制对视觉退化仍过强的先验；同时限制在原图概率足够大的候选中采样。不是单纯减“无图 logits”。

\[ \begin{aligned} \tilde z&=(1+\alpha)z(v)\\ &\quad-\alpha z(v'),\\ p_v(w)&=p(w\mid v),\\ M&=\max_u p_v(u),\\ \mathcal A&=\{w:p_v(w)\ge\eta M\}. \end{aligned}\]

扰动、α 与 plausible 阈值 η 改变解码，另增加图像分支推理；不能继承标准模型原分布或保证零幻觉。来源：Visual Contrastive Decoding。OPERA 与 DoLa 还有不同对象和假设，不宜写成视觉忠实的通用开关。

多模态 RAG：query→文本/视觉召回→重排→原页面与元数据→VLM→带证据回答。ColPali 的 late interaction 对每 query token 找最相关 page patch 后求和：

\[ S(q,d)=\sum_{i=1}^{N_q}\max_{j\le N_d}q_i^\top d_j. \]
两个 query token：与三个 patch 的相似度为 [0.8,0.2,0.1] 和 [0.1,0.7,0.6]，MaxSim=0.8+0.7=1.5。相关 patch 可不同，保细粒度匹配；它是检索分数，不能直接当回答正确概率。来源：ColPali。

3. 面试短答：重点与追问

Q1. CLIP 与 SigLIP 的本质区别？

短答：CLIP 行/列 softmax 区分 batch 配对，SigLIP 逐 pair logistic，无全局分母。两者都有负例、scale 与批次设计；SigLIP 全 pair 仍是平方工作量。

追问：写 score 梯度、bias、false negative 与分布式负例；本页推导。

Q2. LLaVA 的训练流水线为何分阶段？

短答：先适配视觉到语言接口，后用指令训练条件回答；冻结两端降低初期成本，但不是普适要求。1.5 的 MLP/数据 recipe 与 OneVision 的多输入迁移分开。

追问：label mask、模块梯度、纯文本回归；条件生成目标。

Q3. MLP / Q-Former / Resampler 怎样选？

短答：MLP 保 N、做逐 patch 非线性映射；query 模块聚合成固定 M，压语言预算但可能丢细节。任务、encoder、数据、M 和总时延决定选择。

追问：MLP 参数与输入长度分别怎么算；公式与 576→64 例。

Q4. 为什么高分辨率贵？

短答：边长翻倍 patch 四倍，全局视觉 attention 的 score 十六倍；LLM 还受视觉 token、prefill 与 KV 影响。tiling、window、merge/resampler 改成本与信息路径。

追问：processor 的 resize、crop、thumbnail、CLS、merge 都数清；长度算例。

Q5. Grounding 和 GUI 点击怎么验证？

短答：输出坐标合同，逆 resize/pad/crop 后落到原图，比较对象/IoU 或真实业务状态；格式合法不等于目标正确。

追问：归一单位、多个相似物体、异步布局和 TOCTOU；坐标链。

Q6. VLM MoE 为何不一定便宜？

短答：单 token 激活部分专家，总权重仍需驻留/分片，视觉 token 分布造成负载与通信，低激活量不直接等于低峰值显存或低时延。

追问：modality 分组路由、drop、EP 和低并发吞吐。

Q7. 视频时序与 M-RoPE 解决什么？

短答：时间/高/宽坐标进入不同频率块，编码空间与真实时间；采样可能遗漏事件，位置编码不会补回丢帧信息。

追问：不等分频率、时间戳、字幕开关、长程因果；视频预算。

Q8. 多模态 DPO/RL 与文本有什么不同？

短答：优化式可复用，但标签和奖励必须看共同图像与真实视觉/环境证据；图像/帧预处理改变访问状态和成本。

追问：物体/关系部分错误、reward hacking、文本能力遗忘与 teacher 费用。

Q9. 如何减少视觉幻觉？

短答：先区分物体、属性、关系和输入缺失，用数据/grounding/偏好/解码单轴对照；VCD 比较原图与扰动图并做候选限制，不能保证零幻觉。

追问：POPE 的覆盖、原图 plausibility、额外推理成本；机制与边界。

Q10. 多模态 RAG 为什么需要 patch 检索？

短答：细粒度 query 可对应不同页面 patch，MaxSim 聚合保局部匹配；还要把原页面和元数据交给 VLM，并独立验答案。

追问：文本/OCR/图像召回消融、来源引用、索引与权限。

Q11. 部署和微调 VLM 怎样评估收益？

短答：固定 processor/checkpoint，分 encoder、prefill、decode、KV 和缓存计时；量化/剪枝/分辨率扫 OCR、grounding、视频与纯文本回归。线上看任务成功、转人工、延迟和全部尝试成本。

追问：缓存键含图像内容与 processor，模型改变需失效；服务账本。

4. 实现：形状、mask 与可运行小例

4.1 CLIP / SigLIP、patch 与 connector

import torch
import torch.nn as nn
import torch.nn.functional as F
import math

def image_text_loss(image, text, log_scale, bias=None):
    # pooled features [N,D]; paired diagonal; scale applied once
    v, u = F.normalize(image.float(), dim=-1), F.normalize(text.float(), dim=-1)
    score = log_scale.exp() * v @ u.T
    n = score.size(0)
    if bias is None:  # CLIP
        target = torch.arange(n, device=score.device)
        return (F.cross_entropy(score, target) +
                F.cross_entropy(score.T, target)) / 2
    y = 2*torch.eye(n, device=score.device)-1
    return -F.logsigmoid(y*(score+bias)).sum()/n  # SigLIP, explicit /N

class PatchEmbedding(nn.Module):
    def __init__(self, channels=3, patch=14, dim=32):
        super().__init__()
        self.patch = patch
        self.conv = nn.Conv2d(channels, dim, patch, stride=patch)
    def forward(self, image):
        if any(x % self.patch for x in image.shape[-2:]):
            raise ValueError("processor must pad/resize to patch grid")
        return self.conv(image).flatten(2).transpose(1, 2)  # [B,N,D]

class MLPProjector(nn.Module):
    def __init__(self, visual_dim, llm_dim, hidden_dim=None):
        super().__init__()
        m = hidden_dim or llm_dim
        self.net = nn.Sequential(nn.Linear(visual_dim, m), nn.GELU(),
                                 nn.Linear(m, llm_dim))
    def forward(self, z):
        return self.net(z)  # [B,N,dv] -> [B,N,dL]

class QueryResampler(nn.Module):
    # one educational cross-attention block, not full BLIP-2 / Flamingo
    def __init__(self, dv, dl, queries=8, heads=4):
        super().__init__()
        self.query = nn.Parameter(torch.randn(queries, dl)*0.02)
        self.proj = nn.Linear(dv, dl)
        self.norm = nn.LayerNorm(dl)
        self.cross = nn.MultiheadAttention(dl, heads, batch_first=True)
        self.ffn = nn.Sequential(nn.LayerNorm(dl), nn.Linear(dl, 4*dl),
                                 nn.GELU(), nn.Linear(4*dl, dl))
    def forward(self, z):
        q = self.query[None].expand(z.size(0), -1, -1)
        kv = self.proj(z)
        q = q + self.cross(self.norm(q), kv, kv, need_weights=False)[0]
        return q + self.ffn(q)

输入接口：取 encoder patch 后投影，在 image 占位符处插入真实 embedding；同时扩展 attention mask/position 和 labels，视觉/用户部分设 −100。各模型的占位符、special token 与 processor 都需按 checkpoint 实现。

4.2 交错图文 mask：这是一个明确的教学合同

标准 decoder 可以全部 causal；下面的可选块策略允许同图像块内部双向、所有位置读此前内容。第二个图像仍能读第一个图像，不能一边实现下三角，一边声称“不同图像绝不互看”。不允许图像块覆盖未来回答。

def interleaved_mask(length, image_regions, device="cpu"):
    # half-open [start,end); True means visible
    mask = torch.ones(length, length, dtype=torch.bool, device=device).tril()
    previous_end = 0
    for start, end in sorted(image_regions):
        if not (previous_end <= start < end <= length):
            raise ValueError("overlap or invalid image region")
        mask[start:end, start:end] = True
        previous_end = end
    return mask

allowed = interleaved_mask(8, [(1, 3), (5, 7)])
# image_0 at [1,3), image_1 at [5,7); query=5 can see keys 1/2/6
# query=1 cannot see future text 3/4 or image_1

API 边界：上述 True=可见可用于相应 SDPA；nn.MultiheadAttention 的 bool mask 常表示 True=遮挡，传入前核对版本或取反。多层中所有图像 token 必须遵守相同未来文本隔离，避免间接标签泄漏。

4.3 有上限的 tiling：网格、形状与结果一致

def find_grid(width, height, max_tiles=12):
    if width <= 0 or height <= 0 or max_tiles < 1:
        raise ValueError("invalid image or budget")
    candidates = [(c, r) for c in range(1, max_tiles+1)
                  for r in range(1, max_tiles//c+1)]
    # teaching policy: aspect mismatch first, then fewer tiles
    return min(candidates, key=lambda cr:
        (abs(math.log(cr[0]/cr[1])-math.log(width/height)), cr[0]*cr[1]))

def tile_image(image, base_res=336, max_tiles=12):
    # floating CHW tensor; simple resize policy, not official AnyRes processor
    if image.ndim != 3 or not image.is_floating_point():
        raise ValueError("image must be a floating CHW tensor")
    _, height, width = image.shape
    cols, rows = find_grid(width, height, max_tiles)
    x = F.interpolate(image[None], (rows*base_res, cols*base_res),
                      mode="bicubic", align_corners=False)[0]
    pieces = [x[:, r*base_res:(r+1)*base_res, c*base_res:(c+1)*base_res]
              for r in range(rows) for c in range(cols)]
    thumbnail = F.interpolate(image[None], (base_res, base_res),
                              mode="bicubic", align_corners=False)[0]
    return torch.stack(pieces+[thumbnail]), (cols, rows)

image = torch.zeros(3, 336, 672)
tiles, grid = tile_image(image)
# grid=(2,1); tiles.shape=(3,3,336,336), 2 crops+thumbnail
# patch14: 3*576=1728; does not include later merge/CLS/special tokens

生产差异：这个例子按 aspect 选最少 tile，可牺牲高分辨率细节；resize 也可能变形。实际 processor 还需像素预算、padding、插值、crop 元数据、归一和 checkpoint 的拼接规则；原例“max_tiles=12 却输出 15 tiles”的结果已修正。

返回数量合同：此代码的 max_tiles 只限制网格crop数，pieces+[thumbnail] 固定再加一张缩略图，因此总返回张数至多 max_tiles+1，并非总张数至多 max_tiles。例中的2个crop返回3张；若下游限制包含缩略图的总数，必须预留这一张并检查返回shape，不能仅检查网格乘积。
