1. LLM：概率、张量与训练

Attention 是什么？复杂度为什么是平方？

软检索：Q 与 K 的点积得到匹配分数，按 key 轴 softmax 后加权 V。Q/K/V 分别是查询、匹配、内容，不要求表示相同。单头 score 为 [B,Sq,Sk]；密集 attention 算术约 Sq·Sk·d，训练通常 Sq=Sk=S。

追问：令 K=Q，未加 mask 的 QQᵀ 对称且半正定；softmax 后未必对称。FlashAttention 减少中间存储与 IO，平方算术仍在。张量与注意力推导。

为什么除以 √d？多头一定更强吗？

量级控制：零均值、单位方差且足够独立的 q/k 分量使点积方差约 d，除以 √d 后约为 1，减轻 softmax 饱和。多头在不同投影子空间并行聚合，再拼接投影；相同总宽度下切头不自动增加参数或保证质量。

追问：输入相关或范数改变时，方差假设不精确；列出 Q/K 归一化、温度与 head 数的独立消融。

MHA、MQA、GQA、MLA 怎样改变 cache？

共享与压缩是两种机制。MHA 每 query head 独立 KV；MQA 共享一组；GQA 分组共享。在相同 head dim 下 cache 比为 Hkv/Hq。MLA 从隐藏状态生成压缩 latent，并需考虑解耦位置分量及权重吸收；不能写成先完整算 KV 再必然压缩十倍。

追问：每 rank 的 KV 是否复制？latent、RoPE、量化 scale 分别占多少？物理状态账本。

三类 Transformer 架构、causal mask 与 label shift？

目标决定可见性。Encoder-only 常用双向 MLM；decoder-only 用 prefix 条件的 next-token；encoder-decoder 用 encoder 条件和 causal decoder。训练 decoder 时遮未来、padding 与 packed 样本边界；logits 在 t 对齐标签 t+1，框架内部已经 shift 时不要再 shift 一次。

追问：单 token cache decode 可只读历史；多 token decode 仍要三角关系。生成任务不必舍弃 encoder。完整可运行小模型。

RoPE 为什么含相对位置？是否保证长度外推？

旋转乘积：二维旋转满足 RmᵀRn=R(n−m)，因此 QmᵀRmᵀRnKn 的位置部分依赖相对位移，内容仍依赖输入。超训练位置可以计算角度，但不保证能利用长上下文；NTK、YaRN、LongRoPE 调整频率与扩展训练，需要短文本回归和不同证据位置评测。

追问：相邻配对和半维配对、position offset 与 checkpoint 是否匹配？ALiBi 是 score 距离偏置，learned absolute PE 需处理超表长度。

LN、RMSNorm、Pre/Post-Norm 和 DeepNorm？

归一化对象与残差位置分开。LN 按 token 的特征轴减均值再缩放；RMSNorm 不中心化。Pre 为 x+F(Norm(x))，Post 为 Norm(x+F(x))，梯度路径不同；DeepNorm 联合残差缩放与初始化支撑深层训练。BN 可用固定运行统计做 batch=1 推理，其训练统计与变长序列适配更困难。

追问：Pre 也可能需要 warmup；现代模型并非全用同一 Norm。链式法则与数值例。

SwiGLU 怎样计参数？MoE 如何训练？

SwiGLU 有三份矩阵：两个 d→m 分支逐元素相乘，再 m→d 输出，忽略 bias 约 3dm；普通两矩阵 FFN 为 2dm，因此等参数时调整 hidden width。MoE 为每 token 选 top-k 专家并加权，其总参数、激活参数和通信是独立账本。

追问：aux loss 与动态 router bias 的角色不同；选择 bias 不一定加入输出权重。检查容量、丢 token、max/mean 负载和 all-to-all。门控与路由。

Llama、Qwen、DeepSeek、Mistral 与 SSM 怎么比较？

冻结具体版本。比较 attention/KV、残差、FFN/router、位置策略、训练 token、active/total 参数和服务支持。Llama 2 小型号不是都用 GQA；Qwen 不同代有 dense、MoE、混合状态路线。SSM 以状态递推减少历史状态读取，但固定状态可能丢细节；质量取决于模型和任务。

追问：MTP 辅助预测目标与推理 drafter 如何连接？R1 的后训练不能当成 V3 的架构发明。固定家族报告。

BPE、WordPiece、Unigram、SentencePiece 与 embedding？

算法与工具分开。BPE 迭代合并频繁相邻符号，byte-level BPE 初始符号来自字节；WordPiece 使用子词词表及最长匹配，训练合并口径需核对实现；Unigram 从候选词表拟合概率再剪枝。SentencePiece 是支持 BPE/Unigram 的框架。token ID 索引 embedding 表，梯度更新被访问的行。

追问：特殊 token、byte fallback、中文切分率、词表扩大后的 LM head 成本；不同 tokenizer 的 loss/perplexity 不直接横比。

Temperature、Top-K、Top-P、重复惩罚与 beam？

明确变换顺序。正温度除 logits 后重归一；Top-K 留固定数量，Top-P 留累积质量达到阈值的最小排序前缀，必须保留首个跨阈值 token。greedy 取局部最大，beam 管多前缀分数；sampling 扩探索。常见 repetition penalty 对正 logit 除因子、负 logit 乘因子。

追问：τ=0 走 greedy；EOS、长度归一和约束改变 beam 选择。不存在所有任务统一的 0.7/0.9 默认最优值。

Pretrain、CPT、SFT、RFT 与 RL 的区别？

按数据与目标定义。预训练预测广泛语料；CPT 改变域或序列结构；SFT 模仿目标回答/动作；rejection fine-tuning 先筛成功轨迹再模仿；RL 优化采样行为的期望奖励。SFT 一样能学知识和偏好，RL 不是所有项目必需，也不保证超越教师或底座能力。

追问：assistant-only mask 是目标选择，prompt 仍影响后续激活和梯度。完整训练生命周期。

LoRA、QLoRA、DoRA、LoRA+、AdaLoRA 与其他 PEFT？

低秩更新：ΔW=(α/r)BA，参数为 r(din+dout)；常见 B=0 初始化使首步先更新 B。QLoRA 冻结量化基座，用 NF4、scale 再量化及分页优化器降低状态成本；DoRA 分离 magnitude/direction，LoRA+ 分别调 A/B 学习率，AdaLoRA 分配秩预算。

追问：prompt tuning 学输入向量，prefix tuning 学层级前缀，P-Tuning v2 使用深层 prompt。r、α、初始化和优化器共同影响更新；同 α/r 不保证跨秩等价。合并 adapter 要兼容量化与服务。

AdamW、Muon 等怎样选？训练 loss spike 怎么查？

方向、尺度、衰减：AdamW 保留一阶矩和梯度平方的二阶原点矩，经偏差修正按坐标缩放，独立做 weight decay。Muon 近似二维更新矩阵的 polar 方向，通常其他参数组仍用 AdamW；Lion 用动量/sign，SOAP 使用预条件基底。状态减少可能增加矩阵计算或通信。

追问：先排非有限数据、loss mask、梯度范数、精度 overflow、LR、恢复状态与数据突变；不把所有 spike 归 LR。逐步推导与原论文效率对照。

Warmup、cosine、混合精度、checkpoint 与 weight decay？

各管一件事。warmup 限制初期更新，cosine 平滑退火但不是唯一调度；BF16 指数范围较 FP16 大、尾数更短，FP8 依赖 scale/kernel 与高精度累加。checkpoint 重算换保存激活，开销看分段。L2 梯度进入 Adam 状态，AdamW 的 decoupled decay 不进入 m/v；系数按配方和参数组调。

追问：累积更新的有效 batch、clip 在 unscale 后、恢复 optimizer/scheduler/RNG；激活省一半不等于总显存省一半。

Scaling law、涌现、CoT、ICL、幻觉与遗忘？

拟合关系有条件。dense 训练常用 C≈6ND 近似；Chinchilla 的等比例扩 N/D 与约 20 token/参数来自具体拟合，不是普适比例。离散指标可制造“涌现”跳变。CoT/ICL 让条件和计算改变，未必忠实或增益；幻觉要用事实/上下文证据查。遗忘需混合回放、正则与旧任务回归共同测量。

追问：更多推理预算是否因选择器有效？小模型的长 CoT 是否增加错误？预训练与推理成本一起优化，不能把更低训练 loss 等同更强 Agent。

Scaling ladder、μP和WSD分别解决什么？

实验流程、跨宽度参数化、学习率时长安排。Scaling ladder先做小模型正确性与配方实验，再拟合多个规模/时长，留出更大规模检查外推。μP联合约定初始化、输出与分组LR，帮助小宽度超参数迁移；WSD允许从稳定训练主干分出不同预算的退火终点。

追问：μP不是Muon；换深度、优化器或数据不保证迁移。未完成衰减的长cosine中途点不等价于短预算终点，WSD分支的退火计算也应计费。推导、实验阶梯与适用条件。

2. RLHF 与偏好：信号、目标与分布

经典 RLHF 三阶段及四个模型的角色？

SFT→RM→策略优化：SFT 给可用起点；RM 从偏好对学排序；PPO 用奖励、value 和参考约束更新。actor 决策，critic 估回报，RM 评价回答，reference 定义偏移。它们可共享、offload 或预计算，模型数不能直接推出显存比例。

追问：RLHF 是反馈来源，PPO 是优化方法；DPO 可直接用偏好，规则奖励可省 RM。

Bradley–Terry、RM loss 与偏好噪声？

随机排序模型：P(w胜l)=σ(rw−rl)，对观察偏好作负对数似然。只确定分数差，共同平移不可识别；并不消除 scale、长度偏差或循环偏好。标注分歧用多标注、软标签、质量分层及校准处理，成对比较也有顺序偏差。

追问：评 pair accuracy、概率校准、领域/长度分组及 policy 新样本；绝对打分和 pair 标注没有通用的 80%/60% 一致率。

KL 惩罚比较谁？K1/K2/K3 怎样写才正确？

先写采样方向。若 a~p、u=q(a)/p(a)，则 −log u 无偏估 KL(p‖q)，(log u)²/2 是局部近似，u−log u−1 非负且在共同支持下同样无偏。换成 behavior 采样或丢失词表质量后需重新分析；单样本 log-ratio 可以为负。

\[ \begin{aligned} u&=q(a)/p(a),\\ K&=D_{\rm KL}(p\Vert q),\\ \mathbb E_p[-\log u]&=K,\\ \mathbb E_p[u-\log u-1]&=K,\\ \mathbb E_p[u]&=1 . \end{aligned}\]

这里 \(p,q\) 是同一候选集合上的两分布，\(a\sim p\) 为所采动作，\(u\) 为反向概率比，\(K\) 为 KL 标量；\(\mathbb E_p\) 按 \(p\) 加权平均，\(\Vert\) 分隔两个被比较的分布。共同支持和可积性是这些期望等式的条件。

追问：old/current 的更新 KL 与 reference KL 分开；不能直接对非负 K3 采样值普通反传就声称得到完整 KL 梯度。

DPO 怎样从 KL 正则目标推导？β 是反比吗？

三步：最优策略 π*∝πref·exp(r/β)；反解 r=βlog(π*/πref)+βlog Z；同 prompt 的偏好差消去 log Z，得 sigmoid 分类 loss。设 \(y_w,y_l\) 为同一 prompt 下的偏好/不偏好回答，\(\theta\) 是当前策略参数；β 在原目标控制 KL 正则强度；训练中又缩放 preference logit，不是“KL 的反比”或单一学习率旋钮。

\[ \begin{aligned} \ell_w&=\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\rm ref}(y_w\mid x)},\\ \ell_l&=\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\rm ref}(y_l\mid x)},\\ \Delta&=\ell_w-\ell_l,\\ L_{\rm DPO}&=-\log\sigma(\beta\Delta). \end{aligned}\]

\(x\) 为共同 prompt，\(y_w,y_l\) 为偏好/不偏好候选，\(\pi_\theta,\pi_{\rm ref}\) 为当前/冻结参考策略；\(\ell_w,\ell_l\) 为序列 log-ratio，\(\Delta\) 为两者差，\(\sigma\) 为 sigmoid，\(\beta>0\) 缩放偏好 logit。这里 w/l 是 winner/loser 标签，不是 token 位置。

追问：reference 支持、序列 log-prob 求和、label noise、长度与 chosen/rejected 同降。完整优化推导。

离线 DPO 是 off-policy RL 吗？在线 DPO 改了什么？

固定偏好数据训练：标准 DPO 不在每步访问环境；它的监督梯度针对离线目标，并非随时间产生“RL 梯度估计偏差”。问题是数据覆盖与 policy 分布失配。online/iterative DPO 刷新当前策略候选与标签，增加反馈成本，也需防选择偏移和遗忘。

追问：“只 SFT chosen”与偏好差目标不同，但不是必须用 RL 才能对齐。

IPO、KTO、SimPO、ORPO、cDPO 各改哪里？

沿目标与数据记：IPO 用平方目标约束偏好 log-ratio，非 squared hinge；KTO 用单条 good/bad 的效用目标；SimPO 用平均 log-prob 和 margin，省 reference；ORPO 将 SFT 与 odds-ratio 偏好项结合；cDPO/label smoothing 建模标签翻转噪声。不同命名实现仍需固定版本。

追问：无 reference 的新目标不自动继承 DPO 推导；偏好胜率、held-out 能力和长度变化共同验收。

Reward hacking、alignment tax 与模式坍缩如何诊断？

代理高分与真实目标分开。检查高分样本的长度/格式捷径，独立任务成功、OOD、旧能力、输出多样性与安全误拒绝。KL 只能限制偏移；长度惩罚、ensemble、更新 RM 各会改变目标，不能代替独立验收。

追问：β、LR、epochs、数据与 reward 版本单轴消融；没有所有训练都健康的 KL/clip/entropy 固定区间。

RLAIF、Constitutional AI、self-reward 与 rejection SFT？

反馈供应链：AI 可以按 rubric 产生偏好；Constitutional AI 用原则指导 critique/revision，并形成 AI 偏好训练；self-reward 由模型反馈形成迭代；rejection SFT 筛轨迹再模仿。judge 的错误、偏见、teacher 成本和测试泄漏都要记录。

追问：self-play 通常含对手/任务生成与交互，不能等同所有自采样训练。固定教师、审计反馈、保留独立测试，避免互相强化错误。

3. RL：梯度、优势、更新与参数

MDP、V/Q/A、Bellman 与 on/off-policy？

目标策略下的未来回报：Q 先执行给定动作，V 按策略平均 Q，A=Q−V。Bellman 把回报拆为一步奖励加下一状态价值。部分可观测时条件用历史或 belief。on-policy 使用近期自身 rollout 有限复用，off-policy 使用 behavior 数据并设计校正或 Bellman 更新；PPO 不是每 optimizer step 都重采样。

追问：terminal 与时间截断的 bootstrap 不同；πbehavior、πold、πcurrent、πref 四角色分开。

Log-derivative、REINFORCE 与 baseline 证明？

概率→log-prob：∇P(τ)=P(τ)∇log P(τ)，环境不依赖 θ 时只保留策略动作项；可用 reward-to-go 去除不受动作影响的过去奖励。给定历史且 b 不依赖当前动作，E[b∇logπ]=b∇Σaπ(a|h)=0，baseline 不改变期望；任意 baseline 不保证降方差。

追问：折扣目标的外层 γᵗ；actor 对固定优势停止梯度；含自身的 group mean 有有限样本相关性。逐步证明与图。

Actor-Critic、GAE、MSE value 与 λ？

TD 残差混合：δt=rt+γV(t+1)−V(t)，GAE 将未来残差按 γλ 加权。λ=0 是一步 TD；λ=1 在完整终局正确处理时得到 MC return−V，截断仍含 bootstrap。MSE 的最优预测是目标的条件均值，重尾/偏差目标下并不普适最好。

追问：critic 误差和样本方差分别测，PRM 与 critic 不是同一预测对象。两步算例。

TRPO 的保证怎样理解？PPO min 为什么要分正负？

局部代理：TRPO 在旧策略状态分布下用 action ratio，理论性能界和实际平均 KL 近似有差距；ratio 不自动校正状态访问分布。PPO 取 min，正优势裁过高 ratio 的收益，负优势裁过低 ratio 的收益，另一侧仍可有梯度。

追问：clip 不是硬概率范围或 KL 上界；ε=0.2 不能读成“每动作最多变 20%”。分段式与原图。

GRPO、RLOO 为什么省 critic？全同组怎样处理？

同题比较：GRPO 使用中心化/标准化组内奖励，RLOO baseline 排除自身。全同奖励中心化为 0；它表示没有相对信号，不会直接把“全错组吓得不探索”。同组 residual/std 相互约束，小 std 不能一概解释为优势必爆炸。

追问：std、ε、长度分母、样本均值包含自身分别改变何种估计？省 value 状态仍需支付 G 条 rollout。有限 G 算例。

DAPO、Dr.GRPO、GSPO、CISPO、SAPO 怎样背？

按改动位置：DAPO 改非对称 clip、动态采样、token 聚合、过长处理；Dr.GRPO 去 std、改长度分母；GSPO 先平均 token log-ratio 再 exp 成序列 ratio；CISPO 裁并 stop-gradient IS 权重再乘 log-prob 梯度；两类 SAPO 同名缩写需说论文全名。

追问：token 平均让长序列贡献更多 token，不能背成“避免长序列主导”；GSPO 几何平均也不等于完整序列概率乘积。公式对照。

RLVR、ORM、PRM 与 shaping 是否天然可信？

反馈轴：规则可验结果，ORM 评价终局，PRM 评价过程；规则也可能有泄漏、覆盖缺口和可利用捷径。potential shaping 在条件下可保持最优策略，任意 dense 奖励会改变任务。过程打分更密不意味着因果信用更准确。

追问：数值/状态合同可以有多种合法答案，RLVR 不限唯一字符串；开放任务也不必一律使用 PRM。

G、global batch、LR、clip、β、温度、长度、epochs？

先说单位：G 是同题候选数，batch 可能按 prompt/episode/token；micro-batch×累积×DP 只适用于相应样本单位。LR 与复用 epochs 影响偏移；clip 和 KL 独立；温度改 behavior；最大长度会截断解题。mini-batch 数不等于 epochs。

追问：可背数值必须一起背论文版本、模型和缺失项。六套数值配方与 12 道参数追问为唯一数值卡。

R1-Zero 与正式 R1 流程是什么？

两条研究路线分开。R1-Zero 从强 base 直接用结果/格式奖励 RL；正式 R1 使用冷启动 SFT、推理 RL、筛选并补通用 SFT、后续全场景 RL，另做小模型蒸馏。aha moment 是报告例子；不能推出任意模型不经 SFT 都能学推理。

追问：pass@1、pass@k、阅读性、混合语言、训练/推理预算；k1.5 的长上下文和 long2short 与 R1 不是受控对照。

DQN、A2C/A3C、DDPG/TD3/SAC 与 LLM 的关系？

旁支机制：DQN 用 target/replay 拟合 Bellman Q；A2C 同步、A3C 异步 actor-critic；DDPG 确定性连续 actor，TD3 用双 critic、延迟更新和 target smoothing；SAC 优化奖励加熵并 off-policy 回放。SAC 有离散变体，大词表 Q 估计困难不等于理论不可用。

追问：target 不是完全固定，replay 不自动无偏；DQN 单步例与速查。

4. Agentic RL：环境、信用与数据

Agentic RL 如何建模？工具观察算动作 loss 吗？

模型输出可控动作，工具产生环境观察。token 组成工具名/参数；状态含文件与服务，策略常条件于可见历史。system/user/tool span 不做策略动作 loss，但参与后续 attention。turn/token 粒度影响概率、折扣与信用，不靠解析文本标签猜来源。

追问：POMDP、invalid action、assistant-only mask、truncation；RLHF/RLVR 与 Agentic 是可组合的分类轴。

SFT、ToolRL、Search-R1、ReTool 各训练什么？

把动作接反馈：SFT 学轨迹格式与行为；ToolRL 按工具选择/参数反馈；Search-R1 把检索观察插入推理闭环；ReTool 以代码增强轨迹冷启动后在执行环境 RL。结果奖励可以强化工具调用，但零成功差异时无有效信号，也可能强化不用工具的捷径。

追问：仅成功奖励不一定抑制多余调用；要将调用成本、独立答案验收与训练 mask 写清。

终局失败时，中间成功步骤怎么分信用？

可用终局共享、turn baseline、PRM 或状态分组。三者估计对象不同：过程分不等于对最终成功的因果贡献，critic 有 bootstrap 误差；状态相似组需要核对是否可比，Graph/反事实方法需要额外假设。终局失败不说明每个动作都差。

追问：画一个“检索成功→错误工具参数→终局失败”轨迹，对照只改信用而不改数据的消融。

工具错误、稀疏奖励与 curriculum 怎么处理？

可控错误与基础设施故障分开。参数错可归策略，API 故障需重试/标签/环境治理；不能把所有失败都扣负分。按成功率/难度/horizon/工具组设计课程，混合老任务并冻结留出；重复采样和筛组会改变被训练的任务分布。

追问：重试是否幂等？工具预算/停止规则是否改变目标？长程并非总由 γ 折扣消失，γ=1 仍可能信用难。

SWE-RL、SWE-Smith、SWE-Gym 与评测泄漏？

训练来源与运行验收分开。SWE-RL 从 PR 内容构造代码编辑监督/奖励，不能概括为“PR 已合并=通过 CI 的实时 Agent”。SWE-Smith 通过仓库程序变异和执行反馈合成任务；Gym 提供可交互环境。按仓库/时间/任务族去重切分，隐藏测试不能进入 teacher 或工具输出。

追问：文字 diff 相似、编译、测试、语义功能是不同指标。商用代码 Agent 的未披露训练不从体验反推。

GUI / Browser Agent 的动作空间与冷启动？

可见性与执行合同：DOM/a11y 给结构与语义，截图给实际视觉但需定位；动作可为元素 ID、像素或归一坐标。SFT 演示先学合法动作，RL 用任务状态验收与环境恢复。UI-TARS/ShowUI 等数据路线应逐版本比较，不能宣称所有 GUI Agent 同一配方。

追问：截图 resize/裁剪坐标逆变换、界面异步变化、TOCTOU、点击成功但业务失败。

Async rollout、框架选型、entropy 与健康监控？

记录样本来源和队列偏移。异步叠计算可能提高利用率，但产生 policy staleness、快任务过采样与后端 log-prob 差异；prefix 需状态兼容。按算法、backend、multi-turn API、恢复与环境调度选 TRL/verl/OpenRLHF/NeMo RL，不按过时“不支持 vLLM”表格排名。

追问：reward/留出 success、entropy、有效组率、clip/KL、长度、工具失败、队列年龄与成功成本一起看。固定版本框架。

Self-improvement、用户模拟与 Agentic scaling？

先定义干预变量。自采样、对手、自生任务、模拟用户、筛选 SFT、RL 是不同流程；用户模拟的偏差会变成训练目标。分别扫模型规模、唯一任务数、每题采样、horizon 与更新量；报告同 token、同算力、同 wall-time 质量，不能写 G 越大训练必稳。

追问：反馈是否独立、旧能力是否回退、筛选后的难度分布；教师、环境和失败尝试都计成本。

5. VLM：视觉条件、空间与评测

ViT、Connector、LLM 的职责与三类融合？

表示→接口→预测：ViT 把 patch 编成特征，connector 投影或压成固定查询，LLM 条件生成。视觉 token 拼接占 decoder 序列；cross-attention 不占该自注意序列但仍存视觉特征并付交叉计算；统一离散视觉词表可以生成图像，但不是所有“原生多模态”的唯一方式。

追问：CLS/global pooling 与 patch 级输入，CNN/Swin 的局部偏置，encoder 是否提供细节。本页完整 VLM 主讲。

CLIP 与 SigLIP loss、zero-shot 分类及局限？

归一化与二分类：CLIP 用单位图文向量的温度缩放相似度，行/列 softmax 将对角线作配对标签；SigLIP 对图文 pair 用带 scale/bias 的 sigmoid。Sigmoid 无全局 softmax，负例访问仍可能跨卡通信，全部 N² pair 也不是 O(N) 总计算。zero-shot 用类名 prompt 的文本 embedding 匹配图像。

追问：false negative、温度、负例采样、计数/属性/空间关系。不能在 score 已除温度后再除一次。

LLaVA、BLIP-2、Qwen-VL、InternVL 训练与 connector？

具体流水线优先。LLaVA-1.5 两层 MLP 在冻结视觉编码器条件下做对齐/SFT；BLIP-2 Q-Former 压缩视觉条件；Qwen/InternVL 随版本改变 encoder、分辨率和训练阶段。MLP 保 token，query resampler 限预算并增加聚合，优劣按等预算任务测。

追问：阶段冻结策略、OCR/视频/纯文本混合、模态遗忘、视觉 label 不算 loss 是否仍有 encoder 梯度。

AnyRes、native resolution、merge、M-RoPE 与视频？

视觉长度由 processor 决定。tiling 独立编码 crop，native dynamic 编码可变 grid，spatial merge 减语言侧 token。M-RoPE 用时间/高/宽坐标给不同频率维度，分配不一定三等分。视频按真实时间戳、采样和 merge 算总长度，帧多不必更好。

追问：视觉 attention 和 LLM prefill 可能平方；分辨率翻倍 patch 数四倍。小时视频要测定位与时序，不只 needle。

Grounding、OCR、视觉幻觉与 VCD？

检查证据与坐标链。grounding 可用文本坐标/bin token/回归，需逆 resize/crop 并验 IoU；OCR 先排清晰度、语言、阅读序与标注，再做针对数据。幻觉分物体/属性/关系；VCD 对原图与扰动图 logits 作对比并限制 plausible token，不等于简单减无图 logits。

追问：POPE 只覆盖物体存在探测；引用、CoT 和自检都不保证视觉忠实。

VLM DPO / RL、MoE、GUI 与 VLA 的区别？

目标形似，条件不同。偏好对必须共享图像/问题并能判断视觉证据；RL verifier 要验坐标、数值或环境状态。MoE 管视觉/文本负载及通信；GUI 生成数字动作，VLA 还需连续控制/动作序列与物理反馈。Qwen3-VL 不等于 Qwen3-Omni，名字不能推出音频生成。

追问：OpenVLA/RT-2 的动作 token 与 flow 动作 head 接口、仿真到真实的误差和安全边界。

DINO、MAE、SAM/SAM2 与多模态检索？

视觉目标不同。DINO 类自蒸馏学表征，MAE 重建 masked 图像，SAM 是 promptable segmentation、SAM2 扩展视频与记忆。它们不是图文对比 loss 的同义词。多模态检索可用 pooled embedding 或 ColPali 的 query token→page patch late interaction，再把真实页面和元数据交给 VLM。

追问：检索 Recall 与生成视觉忠实性分别测；只压 patch 可能丢表格/小字。

VLM benchmark、部署与业务指标怎么对应？

按失败轴选：MMMU 学科推理，DocVQA 文档、ChartQA 图表，Video-MME 视频，POPE 物体幻觉；冻结 split、processor、分辨率、帧率、prompt 与思考预算。部署缓存需含图像内容、processor 与模型版本，量化/剪枝要测细粒度退化。

追问：线上任务完成、人工转接与延迟如何对应离线切片；不同论文分数不能构成“开源只差 1–2%”。

6. Agent：状态、工具与恢复

Agent、ReAct、Plan-and-Execute、Reflexion 与 ToT/GoT？

有观察反馈的控制循环。ReAct 交替行动和观察，计划执行先列依赖，Reflexion 用反馈更新文字记忆，ToT/GoT 展开/合并候选，PDDL 将形式化规划交给求解器。可组合，不要求把全部内部推理公开。搜索分支必须配独立环境状态。

追问：什么任务无需 Agent？同预算模型与 harness 的独立消融。搜索与停止。

短期/长期记忆、MemGPT 与 context 压缩？

context、持久事实、运行证据分开。近期原文与目标用于下一步，长期记录稳定事实/规则，日志和文件保留证据。MemGPT 用工具调度有限主 context 与外存，是 OS 启发的应用机制。摘要有损，要带来源/范围/版本并可重读文件；compaction 与新窗口重装是不同操作。

追问：时间衰退不自动删除稳定事实；冲突、撤回、权限、索引与缓存删除传播。真实源码链路。

Function calling、MCP、A2A 与工具 SFT？

协议不等于能力。function calling 是模型输出结构化工具请求，MCP 提供应用与工具/资源的连接协议，A2A 支持 agent 间任务协作。SFT 数据需含 schema、调用参数、工具观察与后续动作，按可信来源 span 打 label；Toolformer 类方法与人工/蒸馏轨迹路线不同。

追问：工具发现、schema 版本、认证、timeout、取消、结果大小及幂等键；协议接通不意味着模型会正确选工具。

并行工具、多 Agent 与失败恢复如何设计？

依赖决定并发。无依赖只读任务可并行，写同状态需合并协议/锁/隔离；投票和辩论可能相关犯错。调用记录请求 ID、状态、返回码、artifact、重试与提交点，恢复前查已经发生的副作用。摘要不是事务日志。

追问：task critical path 和总资源成本；多进程吞吐、rate limit、取消与 pending 状态。

Agent 安全、sandbox 与外部 prompt injection？

执行边界：工具文本按数据处理，可信策略检查工具/路径/参数，sandbox 控制实际资源与网络；细粒度权限与独立确认保护不可逆动作。prompt 过滤不能代替执行控制，容器也不自动覆盖所有权限与共享状态。

追问：TOCTOU、跨租户访问、攻击入口和 ASR 分母；正常任务成功和受攻击效用一起报。权限与评测。

LangChain、LlamaIndex、AutoGen、CrewAI、MetaGPT 怎么选？

选择接口与运维条件。比较检索/data connector、工作流编排、multi-agent 通信、持久状态、调试 trace、版本兼容、许可和升级成本；简单任务可直接 API 加状态机。框架名字不会决定模型能力或线上成功率。

追问：模拟工具故障恢复、长任务重启、流式与并发，证明选型满足具体合同。

Agent 数据飞轮、评测与线上监控？

日志先成为可审计样本。关联 task、policy、harness、工具/数据版本、预算、产物和 verifier；区分 schema 合法、执行成功与语义正确。成功/失败都采集，敏感信息去除后按任务族留出，人工/teacher 标签不进入独立测试。

追问：恢复率只在可恢复子集算；长轨迹是否真实提高成功。任务与独立评测。

7. RAG：索引、检索、证据与生成

RAG 与微调、长 context 的取舍？

可更新知识与参数行为分开。RAG 读取外部证据，微调改变模型行为/能力，长 context 能放更多材料但不保证有效利用。先测知识库覆盖，再测检索和生成；有引用入口不代表引用正确或答案被支持。原始 RAG 还有对检索文档做概率边际化的模型设计。

追问：gold evidence 替换检索结果的 oracle 对照怎样定位瓶颈？

Chunk、embedding、ANN 与 rerank 怎么选？

两阶段：bi-encoder 离线编码便于 ANN，cross-encoder 联读 query/document 精排；rerank 补不回候选外证据。chunk 按语义/表格/父子结构与预算切，长度和重叠需调参；embedding 固定 checkpoint、前缀、归一化、领域和语言。

追问：BGE/E5/GTE 家族不同版、MTEB 均分与目标检索差异；Faiss 是索引库，Milvus/Qdrant 等还有服务与运维接口。

BM25、cosine、hybrid 与 RRF？

精确词与语义互补。BM25 用 IDF、词频饱和和文档长度项；cosine 度量归一向量夹角。RRF 对每路排名求 1/(k+rank) 再加，未入榜贡献 0，避免原 score 尺度不可比；k 和召回数量都需冻结调参。

追问：先过滤权限/去重；两路 rank=(1,10) 与 (3,3) 怎样算？完整公式与算例。

HyDE、multi-query、Self-RAG/CRAG/Adaptive 与 Agentic RAG？

干预位置：HyDE 生成假设文档再检索，multi-query 增 query 覆盖；Self-RAG 学检索/critique token，CRAG 用检索质量判断再纠正，Adaptive 路由复杂度。Agentic 多轮读观察再查证。假设文本和反思不是事实，额外调用需证明收益。

追问：停止阈值、同预算多跳任务、搜索失败的 fallback；检索次数不是成功指标。

GraphRAG / LightRAG / HippoRAG 与多模态检索？

图是另一检索结构。GraphRAG 可做实体社区摘要，LightRAG 组织不同层级实体/关系检索，HippoRAG 借图传播关联；名称下的新版机制要固定来源。图关系必须追溯原文，实体消歧和更新很重要。多模态页检索还要保空间 patch 和原页面证据。

追问：全局总结与单跳事实不同，建图成本何时值得；图不能自动修复抽取错误。

增量索引、缓存、时效与多语言？

数据/空间版本化。content hash 和 chunk ID 定位变化，删除旧向量；换 embedding/模板常需重建空间并验证迁移。query/chunk/answer cache 含租户、权限、snapshot、模型和生成条件。时效权重按事实性质设置，旧而稳定的知识不应一律丢弃。

追问：撤回传播、过期答复、跨语言召回、搜索时间过滤与回滚。

RAGAS、Recall、MRR、nDCG 与业务验收？

分层有分母。Recall 看应找证据的覆盖，MRR 看首相关排名，nDCG 看分级相关排序；生成看支持率、引用准确、任务完成和成本。RAGAS 等 judge 指标需人工校准，不能代替真实验收。Lost in the Middle 要控制长度、干扰和位置。

追问：服务上线同时测新鲜知识、长尾、权限、延迟与失败；Dify/RAGFlow/LlamaIndex 用接口和可观测性选。

8. 推理与工程：账本、调度与质量

KV、PagedAttention、prefix 与 continuous batching？

计算、分配、复用与调度分开。cache 避免历史 K/V 重算；分页将逻辑 token 映射物理 block，减少预留浪费；prefix 复用需模型、token、位置和多模态状态兼容；continuous batching 每轮移出完成请求。都不保证所有负载加速或显存利用 100%。

追问：KV=2·L·Hkv·dh·物理槽数·bytes，TP 可能复制；GB/GiB 和 prefix 共享引用计数。完整服务主讲。

Chunked prefill、P/D 分离、并发与容量？

按请求阶段分资源。chunked prefill 允许长 prompt 与 decode 交错；P/D 分离用不同资源配置，新增 KV transfer 和队列。稳定系统 Little：平均在途数=到达率×平均驻留时间；不适用未稳定积压。按长度分布测 TTFT、ITL、TPOT、p95/p99 与 SLO goodput。

追问：70B 是否装得下不等于能满足百万 QPS；传输时间至少 payload/带宽还未含同步。

投机、Medusa、EAGLE、Lookahead 与 DLM drafter？

候选便宜才可能有收益。精确采样用 min(1,p/q) 接受，拒绝用归一化 (p−q)+，依赖共同协议；贪心 token 匹配是另一目标。Medusa 多头候选树，EAGLE 特征预测，Lookahead Jacobi 收集 n-gram，DLM 可做块草稿。接受率高仍可能 draft/verify 太慢。

追问：周期总时间/实际提交 token 与 AR 比；树、batch、tokenizer、温度、量化 target。概率校正证明。

INT4/8、FP8、NF4、GPTQ、AWQ、SmoothQuant、GGUF？

格式、算法、文件格式分开。整数位宽和浮点格式定义表示；NF4 是正态分位量化；GPTQ 用校准及二阶近似补权重误差，AWQ 用激活保护重要权重，SmoothQuant 以等价缩放迁移激活 outlier；GGUF 容纳权重与元数据。权重低位不意味 activation/KV/compute 同位宽。

追问：PTQ/QAT、粒度、scale、饱和、实际 kernel；质量与长上下文/工具格式退化，不能套通用 2×。

训练显存、DP/TP/PP/SP/EP、ZeRO/FSDP 与 offload？

每 rank 账本：参数、梯度、master、m/v、保存激活、通信/临时峰值分别算。16N bytes 是特定混合精度 Adam 状态近似。DP 分样本，TP 分层内矩阵，PP 分层，SP 分序列激活/操作，EP 分专家；ZeRO1/2/3 逐步分片状态/梯度/参数，FSDP 类全分片还需 all-gather。

追问：1F1B 与 interleaved 气泡受 micro-batch、stage 和通信影响；DeepSpeed、MCore、Accelerate/FSDP 按版本组合。配置与诊断参考。

长 context、Ring/sequence parallel、StreamingLLM 与 YOCO？

历史管理与信息能力分开。Ring 类跨 rank 移动 KV 计算 attention；SP 含不同切分实现，不能按名称统一。StreamingLLM 保 attention sink 与近期窗口，能持续执行但不会保完整无限历史。YOCO 等共享/cache 设计需按层结构算状态，压缩记忆可能丢信息。

追问：位置外推、首次扫描、长期证据召回、状态迁移与错误恢复。

torch.compile、CUDA/Triton、框架及低端部署怎么证明优化？

测真实 bottleneck。compile 可融合/减少 Python 开销，但动态 shape、编译时间、graph break 和内存也影响收益。kernel 要查访存/算术强度、正确性与目标硬件；端侧结合小模型、量化、蒸馏、cache 与路由。Swift/Llama-Factory/Axolotl 或服务框架按支持矩阵与恢复能力选。

追问：profiler 时间、warmup、batch、序列分布、同质量；单 kernel 加速不能直接乘成整段 Agent 加速。

稳定 CE 与 assistant-only SFT loss
import torch
import torch.nn.functional as F

def sft_loss(logits, labels):
    # logits [B,S,V]; labels [B,S], non-target=-100
    z = logits[:, :-1].float().reshape(-1, logits.size(-1))
    y = labels[:, 1:].reshape(-1)  # only when caller has not shifted
    keep = y != -100
    if not keep.any():
        raise ValueError("no supervised token")
    return F.cross_entropy(z[keep], y[keep])

def stable_softmax(z):
    z = z.float() - z.float().amax(dim=-1, keepdim=True)
    e = z.exp()
    return e / e.sum(dim=-1, keepdim=True)

追问：全部 −∞/NaN 行需在上游拦截；F.cross_entropy 内部已用稳定 logsumexp。不要 softmax 后再手算 log。

MHA / GQA 的 attention 与 mask
def attention(q, k, v, allowed):
    # q [B,Hq,Sq,D], k/v [B,Hkv,Sk,D]
    if q.size(1) % k.size(1):
        raise ValueError("Hq must be divisible by Hkv")
    repeat = q.size(1) // k.size(1)
    k = k.repeat_interleave(repeat, dim=1)
    v = v.repeat_interleave(repeat, dim=1)
    score = q.float() @ k.float().transpose(-2, -1)
    score = score / (q.size(-1) ** 0.5)
    # allowed [Sq,Sk] or broadcastable; True=visible
    score = score.masked_fill(~allowed, float("-inf"))
    if not allowed.any(dim=-1).all():
        raise ValueError("fully masked query")
    return (score.softmax(-1) @ v.float()).to(q.dtype)

追问：线性投影→[B,S,H,D]→transpose；输出合头与 Wo。显式 repeat 是教学开销，kernel 可直接支持 GQA。bool mask 在不同 PyTorch API 中语义可能相反。

RMSNorm、SwiGLU、RoPE 与 LoRA
def rmsnorm(x, weight, eps=1e-6):
    z = x.float()
    return (z * torch.rsqrt(z.square().mean(-1, keepdim=True) + eps)
            ).to(x.dtype) * weight

def swiglu(x, gate, up, down):
    return down(F.silu(gate(x)) * up(x))

def rope_adjacent(x, positions, base=10000):
    # x [B,H,S,D]; positions [S]; D even
    if x.size(-1) % 2:
        raise ValueError("D must be even")
    freq = base ** (-torch.arange(0, x.size(-1), 2,
                    device=x.device, dtype=torch.float32) / x.size(-1))
    angle = positions.float()[:, None] * freq
    c, s = angle.cos(), angle.sin()
    a, b = x.float()[..., 0::2], x.float()[..., 1::2]
    return torch.stack((a*c-b*s, a*s+b*c), -1).flatten(-2).to(x.dtype)

def lora(x, w, a, b, alpha):
    # w [out,in], a [r,in], b [out,r]
    return F.linear(x, w) + (alpha / a.size(0)) * F.linear(F.linear(x, a), b)

追问：LN 减均值、population variance；RoPE offset、配对模式与 dtype；LoRA 合并与 B=0 首步梯度。

DPO 与 PPO clipped policy loss
def dpo_loss(chosen, rejected, ref_chosen, ref_rejected, beta):
    # each [B], sequence logp summed over valid response tokens
    delta = chosen - rejected - (ref_chosen - ref_rejected).detach()
    return -F.logsigmoid(beta * delta).mean()

def ppo_policy_loss(logp, old_logp, advantage, mask, eps=0.2):
    ratio = (logp - old_logp.detach()).exp()
    adv = advantage.detach()
    gain = torch.minimum(ratio * adv,
                         ratio.clamp(1-eps, 1+eps) * adv)
    if not mask.any():
        raise ValueError("no action token")
    return -gain[mask].mean()  # token mean is an explicit objective choice

追问：value、entropy、reference KL 分开；PPO 不能对裁剪外一律清零。sample/token/固定长度平均都要写清。

GAE、group advantage 与 rollout 更新循环
def gae(reward, value, terminal, gamma=1.0, lam=0.95):
    # reward/value[...,:T]; value has T+1 entries including bootstrap
    out = torch.zeros_like(reward)
    acc = torch.zeros_like(reward[..., 0])
    for t in reversed(range(reward.size(-1))):
        cont = (~terminal[..., t]).to(reward.dtype)
        delta = reward[..., t] + gamma*cont*value[..., t+1] - value[..., t]
        acc = delta + gamma*lam*cont*acc
        out[..., t] = acc
    return out.detach()

def group_advantage(reward, eps=1e-6):
    # reward [prompts,G], population std by this teaching convention
    centered = reward - reward.mean(-1, keepdim=True)
    std = centered.square().mean(-1, keepdim=True).sqrt()
    return (centered / (std + eps)).detach()
  1. 冻结本批 old/behavior 信息，rollout 并保存动作 mask/log-prob/环境版本。
  2. 独立奖励，计算固定优势；真实 terminal 不 bootstrap，截断另处理。
  3. 有限 epochs/mini-batches 更新，监控偏移，随后同步权重并新采样。

追问：padding、多个拼接 episode 需额外边界；GAE 的 terminal 不能代替全部 valid mask。

Top-K / Top-P / temperature 与 KL 三种估计
def sample(logits, temperature=1.0, top_k=None, top_p=1.0):
    if temperature == 0:
        return logits.argmax(-1)
    if temperature < 0 or not (0 < top_p <= 1):
        raise ValueError("invalid sampling parameter")
    z = logits.float() / temperature
    if top_k is not None:
        if not (1 <= top_k <= z.size(-1)):
            raise ValueError("invalid top_k")
        cutoff = z.topk(top_k, dim=-1).values[..., -1:]
        z = z.masked_fill(z < cutoff, float("-inf"))
    values, ids = z.sort(descending=True, dim=-1)
    remove = values.softmax(-1).cumsum(-1) > top_p
    remove[..., 1:] = remove[..., :-1].clone()
    remove[..., 0] = False  # keep first token crossing threshold
    values = values.masked_fill(remove, float("-inf"))
    pick = torch.multinomial(values.softmax(-1), 1)
    return ids.gather(-1, pick).squeeze(-1)

def kl_estimators(logp, logq):
    logu = logq - logp   # samples drawn from p
    return -logu, 0.5*logu.square(), logu.exp()-logu-1

追问：重复 logit ties 使阈值 Top-K 可能留超过 K；若合同要求恰好 K，直接用 topk indices。检查非有限 logits、种子与采样变换顺序。

Online softmax、BPE、MoE router 与视觉实现检查

online softmax 的核心状态：旧 max m、归一总量 l、未归一输出 o；新块 scores s，m′=max(m,max s)，按 exp(m−m′) 重标旧 l/o，再加 exp(s−m′) 与对应 V，最终输出 o/l。初始 m=−∞、l=o=0，遮挡块需处理。

BPE：数相邻 pair→选最频繁→统一非重叠合并→更新词表，固定 ties、边界与特殊 token。router：算 score→top-k→归一 gate→按专家聚集→FFN→scatter 加权，另统计负载/容量。

追问：CLIP、patch、projector、mask、tiling 代码；手写 online softmax 不是高性能 FlashAttention 实现。

10. 评测与系统设计：合同、分母与交付

BLEU/ROUGE、学科/代码/指令 benchmark 怎样选？

测量对象优先。重叠指标不等同事实正确；MMLU/C-Eval/CMMLU 偏知识选择，GSM8K/MATH 偏数学，GPQA 偏高阶科学，HumanEval 用执行测试，IFEval 验约束。冻结版本、split、prompt、解析与预算，按业务错误类型补长尾测试。

追问：SuperCLUE/MT-Bench/AlpacaEval/Arena-Hard 不是单一同分母指标；Arena 人类偏好也非普适真值。

pass@k、pass^k、单次成功与不确定性？

尝试合同不同。独立同成功率 p 时，至少一次成功为 1−(1−p)^k，全部 k 次成功为 p^k。n 次中 c 成功时，不放回抽 k 次的 pass@k 估计为 1−C(n−c,k)/C(n,k)。相关失败、复用环境和预算改变解释。

追问：按 study/repo 组 bootstrap，配对模型对同一题比较；组合推导与例子。

LLM judge、人工评估、红队和污染？

冻结 rubric 和反馈来源。交换顺序、隐藏模型身份、长度控制、人工/规则校准，报告分歧与区间。标注指南含正负例，agreement 高不等于科学真值。红队定义攻击者权限/预算/成功标准；去 hash/近重复、按任务族切分，检测未命中不证明无污染。

追问：judge 被输出注入、teacher 读到测试解答、开放题多解、误拒绝与正常 utility。

Agent benchmark 与 cost-aware evaluation？

系统整体：SWE-bench 看仓库修复，WebArena 看网站状态，OSWorld 看桌面任务，GAIA 综合工具回答；harness 和环境版本是结果一部分。所有纳入尝试的 token、工具、wall/GPU 时间都记录，资源总量除成功数，成功为 0 时不能报告为 0 成本。

追问：不把父 span 与子调用重复计费，费用子集分母；Harbor 保存 artifacts 支持重评分。

Chatbot、企业 RAG、搜索/代码 Agent 怎样设计？

从合同到模块。先定用户/权限/任务成功与 SLO，拆数据、索引、context、模型路由、工具/sandbox、状态日志、验收和反馈；画依赖再并发，定义超时/取消/幂等与人工交接。RAG 定证据，代码 Agent 定环境/patch/test，聊天定会话隔离与容量。

追问：POC→MVP→生产各用冻结回归集、故障注入、负载测试与回滚；先算负载，再承诺 QPS。

推荐 + LLM、电商 VLM 客服、大小模型路由？

让每模块负责可验对象。推荐召回/排序用行为与目标标签，LLM 解释不能编造推荐依据；VLM 读取商品/票据，知识库给政策，工具查订单权限。小模型按置信/任务分流，大模型或人工处理难例；个人历史、图像和视频只在任务有收益时读取。

追问：校准、拒答、长尾/冷启动、费用和大小模型失败相关性；few-shot 按任务覆盖与去重选。

A/B、线上监控和训练数据回流？

随机化单位要匹配用户/会话。主指标定任务完成或业务目标，约束延迟、费用、安全与转人工；避免同用户跨组和反复看数停试。按任务/语言/难度监控漂移、投诉、失败和成本，再审计回流样本，不只训练成功案例。

追问：序贯检验/功效、配对离线回归、灰度回滚、共享 GPU 的推理与微调隔离。

11. 开放题：研究判断与项目复盘

架构、test-time scaling、数据/算力哪个更关键？

给条件与可证伪预测。先定短/长 context、任务类型和训练/推理预算；提出瓶颈假设，引用固定论文的同条件结果和退化项，再设计单轴对照。Transformer/SSM、统一/专用多模态各有 tradeoff，不能从一次榜单推 3–5 年必然格局。

追问：世界模型预测什么状态、用什么损失、如何验反事实行动？AGI 距离没有统一可检验数值。

合成数据、Agentic RL、具身与开闭源趋势？

分别说机会和瓶颈。合成可扩覆盖但可能复制错误/污染，Agentic RL 受环境、信用与 verifier 限制，具身受物理数据/控制与 sim2real 限制。开闭源比较还含许可、部署、隐私与供应商依赖；个性化必须有权限、纠正与删除机制。

追问：teacher 是否独立、生成/筛选成本、隐藏测试、身体/设备差异、旧能力回归。

如何讲一篇论文，避免只背摘要？

五段：问题与基线→目标/张量/数据→核心机制→同条件实验/消融→失败与下一项实验。把作者结果、自己的复算、实际复现和推断明确区分，未公布显存/费用就说缺失，不把峰值 FLOPs 当实测吞吐。

追问：改变一个设计为什么有收益？实验能否排除数据、token 与模型规模混杂？固定研究地图。

如何讲自己的项目、日常工作流与复盘？

背景→合同→方案→证据→反思。说清自己负责的模块、规模、版本、对照和实际结果；区分实现完成与实验未闭合。失败案例要给原始轨迹/脚本位置、定位证据和修正后检查，不能补不存在的 GPU 实测。日常 AI 使用说明人工判断点和质量验收。

追问：为何选该路线、最大的负结果、下一步最便宜的验证。个人项目材料见 My Work。

如何选方向、持续学习和反问团队？

问题驱动：先掌握一条完整任务→数据→训练→服务→评测链路，围绕项目补论文；用固定阅读记录和可运行小例积累。反问团队当前任务/基线、最紧迫技术瓶颈、评测与数据权限、部署约束和 mentoring；用答案判断实际职责和成长空间。

追问：自由探索题先定可验证小目标，再算数据与预算；不要用“最新模型一定更好”替代设计。
