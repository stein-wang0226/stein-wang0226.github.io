五条速览
  • 架构同时优化计算与状态：稀疏/线性注意力、KV 压缩、编解码分工与 MoE 容量要分别记账。MLA 压缩和稀疏选择解决不同问题。
  • Muon 已有大规模训练报告：重点是矩阵方向、参数分组和稳定性；论文收益绑定实验规模，不能作为通用加速倍数。
  • 「GPT-6 用 Loop Transformer」仍是传闻：公开可证的循环深度实证是 Huginn（arXiv:2502.05171）；OpenAI 未确认 Astra 架构。
  • RL 的增量在「修偏」：GSPO（序列级重要性，稳 MoE）、Dr.GRPO（去长度偏置）、Clip-Cov/KL-Cov（抗熵坍缩）。
  • 评测转向可执行交付与可靠性：小题集高分不能证明任务分布饱和；Terminal-Bench、Science、SWE 与交互任务各测不同能力。

DeepSeek-V4.1-Flash（DeepSeek，2026-09-10，MIT，含技术报告）FACT

多模态 MoE，骨干 552B、1M 上下文，原生图文输入、自回归生成；HF deepseek-ai/DeepSeek-V4.1-Flash 已开放权重（MIT）。核心是 Causal Encoder-Decoder（CED）：40 层 = 20 层因果编码器 + 20 层解码器，解码器全局 KV 由编码器末层隐状态投影而来，因而 prefill 仅激活 8B、decode 激活 16B，对输入密集的 agentic 负载显著降本。叠加 CSA2（Full/Reindex/Reuse 三静态模式跨层共享 KV 与 indexer）+ 分层稀疏 indexer + FP4 主 KV 缓存，每 token 全局 KV 压到 890B（约 V4-Flash 的 1/4）；SWA Bounded Replay 把持久化 KV 再降到约 1/8。另含 Single-Pass mHC、Engram 条件记忆（196B，token 查表稀疏访问）、DSpark 投机解码；MoE 为 1 共享 + 384 路由专家、每 token 激活 6 个。预训练 45T token（稀疏注意力 @64K，34T 处扩到 1M）；后训练沿用 SFT→RL→OPD，改动集中在 agent 任务/环境的大规模自动合成，并支持 1–100 连续可调推理强度。

来源：DeepSeek-V4.1 技术报告 PDF（51 页） · HF 模型卡 · DeepSeek 官方发布。基准「优于 V4-Pro / V4-Flash」为厂商自报 SELF-REPORT。

3.1 循环深度潜空间推理（Recurrent Depth）FACT

相关原论文 / 官方资料：Latent thoughts theory；Scaling up Test-Time Compute with Latent Reasoning: A Recurrent Depth Approach。

Huginn在 3.5B 参数、800B 预训练 token 的论文设置中研究循环块：共享权重，反复更新潜在表示。增加迭代会增加计算与延迟，参数量不随迭代数增长；能运行更深也不保证更深时质量单调提高。

与思维链（CoT）的本质区别
  • 循环深度：多次变换同一表示，计算中间状态不必变成文本 token。
  • CoT：生成更多可见 token，再把它们用于后续计算；可见文字也不自动保证推理忠实。
  • 验证：同时看质量、延迟、停止策略和数值稳定性。共享梯度、稳定/发散算例见循环模型推导。

04 优化器：Muon 与后 Adam 时代

Muon 是 2024–2026 最受关注的新型优化器，已从 NanoGPT speedrun 走进万亿参数生产模型。

4.1 核心思想 FACT

相关原论文 / 官方资料：Old Optimizer, New Norm: An Anthology。

  • 机制：对矩阵动量近似取 polar 方向，再做尺度匹配与衰减；有限 Newton–Schulz 迭代不是精确 SVD，也不是每个坐标更新幅度相等。
  • 分工：常见方案将隐藏层矩阵交给 Muon，embedding、输出头与一维参数交给 AdamW；具体矩阵切片按实现检查。
  • 复习：优化器主讲集中保留 AdamW 推导、Muon 方向反例、状态显存与论文对照。

4.2 规模化与工业落地 FACT

相关原论文 / 官方资料：Muon is Scalable for LLM Training；Kimi K2: Open Agentic Intelligence。

Moonlight：论文报告同等训练效果约 2× 计算效率，绑定其模型、数据及 compute-optimal 对照。单动量状态比 Adam 两矩状态少；峰值显存仍包括权重、梯度、激活与迭代临时矩阵。

Kimi K2：报告采用 MuonClip，用 QK-clip 处理大规模训练中的注意力 logit 不稳定。零 loss spike 是该次训练报告，不能推出所有 Muon 训练都稳定或都必须使用同一阈值。

Speedrun 五个历史里程碑 · 整体训练栈记录

NanoGPT speedrun 官方记录表中的可核验里程碑：Muon 谱系从 12.0min（2024-10-18）推进到 8.2min（2024-11-06）、3.142min（2025-01-13）；2026-01-04 的混合精度 Muon / Adam 交织方案为 1.878min，到 2026-08-30 的 ANVIL 优化器栈记录为 0.665min。后者是整套训练栈的结果，不应单独归因于 Muon。

10.1 蛋白 / 基因组语言模型 FACT

相关原论文 / 官方资料：On the Reliability of AI Methods in Drug Discovery: Evaluation of Boltz-2 for Structure and Binding Affinity Prediction。

蛋白表示：ESM-2/ESMFold 连接序列表示与结构预测；ESM-3 引入多轨表示；ESM C 研究序列表征。家族最大规模不能直接当作可下载 checkpoint 的规格。

基因组：Evo 2 的数据与上下文按碱基序列计数；一百万碱基是 1 Mb，不是万亿碱基。蛋白 token、残基与结构 codec 的长度不可混算。

科学反馈的解释边界
  • 功能理解：PFUA 研究交错工具推理；该任务上的文本推理局限不能推广为所有蛋白 CoT 无效。
  • 自纠错：Reflection Pretraining 研究 token 级自纠错，不能据此推出 CoT 不可能的普遍定理。
  • 拒答：按模型、提示和任务报告；当前协议下拒答不等于没有该领域知识。
领域 RL 何时有效：一条经验法则

Cao et al. 的研究提示检查任务余量、奖励保真度与策略容量。这是实验轴，不能当作三者相乘的定量规律或所有领域的固定瓶颈。

  • 校准反馈：检查与独立生物目标的相关性、反例和可利用漏洞。
  • 机制对照：同预算下分别改变策略、工具、奖励或训练信号。
  • 独立验收：区分代理指标、证据正确性与湿实验结果。

五个追问 · 判断新工作

新权重就是新架构吗？先核对 config 与基座，后训练也能改变行为。

激活参数少就便宜吗？还受通信、状态、batch 和实现影响。

效率翻倍可以直接部署吗？先核对等质量基线与计时边界，再测自己的负载。

榜单高分证明泛化吗？还需独立数据、预算控制和泄漏审计。

领域 RL 得分提高证明科学正确吗？只说明当前评分协议改善，还需独立验收。
